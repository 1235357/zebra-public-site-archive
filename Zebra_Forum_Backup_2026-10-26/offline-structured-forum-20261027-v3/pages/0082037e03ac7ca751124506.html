Hi Gordon.

The Big Windows RFID SDK - only contains the RFID components.

Unlike the Mobile Platform RFID SDK's (Android and iOS) the ScannerFramework is not included in the RFID SDK for Windows.
Rather the Scanner Framework for Windows - can connect to the other SSI connection.
I fthe uppper and lower Triggers are correctly configured - this can allow either RFID Tag transactions (Inventory/Read/Write/Etc.) as well as Barcode Scanning from the Imager on the RFD40 Premium+ Sled.
