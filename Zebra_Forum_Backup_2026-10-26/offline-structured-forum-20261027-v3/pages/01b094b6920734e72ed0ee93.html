Hi Everyone,

I am having a bit of trouble adding a WLAN Profile. Any help or pointers would be greatly appreciated. Thank you! 

srfidAddWlanProfile, getProtocol(), getPassword(): All seem to have the same affect 


The Objective-C Zebra iOS demo app (123Rfid_iOS_v_1_1_75) on the same device/reader connects to Wi-Fi just fine (scan, add profile, save, connect) and yes, before I start debugging I set the current Region and Maker sure than any Operation is not running.


Environment

  • Reader: RFD40 Premium (RFD4031)
  • Firmware: PAAFKS00-009-R00 (latest, I’ve tried multiple versions)
  • iPhone/iPad: iOS 18.0-18.5 (I’ve tried multiple iOS versions)
  • Xcode / Swift: Xcode 16.4, Swift 5-6 (I’ve tried multiple Xcode version and both Swift 5 and 6)
  • Zebra RFID iOS SDK: XCFramework (runtime log sometimes shows Zebra SDK Version: 1.1.35 and Symbol BT SDK version: 1.1.13)

What works

  • After establishing communication session succeeds.
  • Establishing ASCII/iAP succeeds (log: -[zt_AsciiProcotocolHandler initializeConnection] ProtocolConfig: echo off -> OK).
  • srfidWlanScanList Works fine I can get a list of network SSIDs
  • srfidGetWifiStatus  succeeds and returns (example):

I get logs like: 

{

  "2_4GHzAllowedChannelListMask" = 0x00000000000007FF;

  5GHzDFSAllowedChannelListMask = 0x0000000FFFF00000;

  5GHzNonDFSAllowedChannelListMask = 0x000001F0000F0000;

  ChannelListMask = 0x000001F0000F07FF;

  PreferredSSID = "";

  STATE = DISCONNECTED;

  WifiRegion = FCC;

  wifi = ENABLE;

}

 

What fails

Enabling Wi-Fi (even after ASCII OK):
getWifiStatus → 4  (RESPONSE_TIMEOUT), message=nil   // on first call occasionally

wifiEnable    → 6  (NOT_SUPPORTED), message=nil

Note: radio often already reports wifi = EN

  1. Adding a WLAN profile intermittently crashes inside the SDK:
    • Crash points I’ve seen:
      • ZebraRfidSdkFramework -[CommandAddWlanProfile setSSID:]
      • ZebraRfidSdkFramework -[CommandAddWlanProfile setPassword:]

• • CF string mutation underneath (-[__NSCFString setString:])


Simple Swift Example:

override func srfidEventCommunicationSessionEstablished(_ activeReader: srfidReaderInfo!) {
        let readerId = activeReader.getReaderID()

        DispatchQueue.main.async {
            let sdk = RFIDAPI.shared.sdk

            sdk.srfidStopInventory(readerId, aStatusMessage: nil)

            guard sdk.srfidEstablishAsciiConnection(readerId, aPassword: nil) == SRFID_RESULT_SUCCESS else {
                print("ASCII FAILED"); return
            }
            print("✅ ASCII OK")

            // Small delay avoids races seen in some SDK builds
            DispatchQueue.main.asyncAfter(deadline: .now() + 0.20) {
                // Status often shows ENABLE/DISCONNECTED
                var statusMsg: NSString?
                var info: srfidGetWifiStatusInfo?
                let st = sdk.srfidGetWifiStatus(readerId, wifiStatusInfo: &info, aStatusMessage: &statusMsg)
                print("getWifiStatus →", st.rawValue, statusMsg ?? "nil",
                      (info?.getStatusDictionary() as? [String:Any]) ?? [:])

                // Skip wifiEnable if already ENABLE (calling enable usually returns 6)
                // Build profile exactly like the demo: SSID (quoted) → Password → Protocol
                
                let ssid = "MYSSID"
                
                let profile = sRfidAddProfileConfig()
                profile.setSSID(ssid)                       // 1) SSID
                profile.setPassword("MyPassword")           // 2) Password (omit for open networks; use "No_Encryption")
                profile.setProtocol("WPA2_Personal_CCMP")   // 3) Protocol (match demo literals)

                print("DBG SSID:", profile.getSSID() ?? "nil")
                #warning("GRASH! -> 'profile.getProtocol()'")
                print("DBG Protocol:", profile.getProtocol() ?? "nil")
                #warning("GRASH! -> 'profile.getPassword()'")
                print("DBG PwdLen:", (profile.getPassword() ?? "").count)

                var msg: NSString?
                #warning("GRASH! -> 'srfidAddWlanProfile'")
                let add = sdk.srfidAddWlanProfile(readerId, srfidProfileConfig: profile, aStatusMessage: &msg)
                print("add →", add.rawValue, msg ?? "nil")

                if add == SRFID_RESULT_SUCCESS {
                    let save = sdk.srfidWlanSaveProfile(readerId, aStatusMessage: &msg)
                    print("save →", save.rawValue, msg ?? "nil")
                    let conn = sdk.srfidConnectWlanProfile(readerId, ssidWlan: ssid, aStatusMessage: &msg)
                    print("connect →", conn.rawValue, msg ?? "nil")
                }
            }
        }
    }

p.setSSID("SSID")
p.setProtocol("WPA2_Personal_CCMP")
