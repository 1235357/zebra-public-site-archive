Both ZD220 and ZD421 support the ZPL label format language. The label designed in ZPL for the ZD220 should work for the ZD421, but with different scale. As you've already pointed out, the printhead resolution of the ZD220 is 203dpi, while 300dpi for the ZD421. Because of the different resolutions, you will need to do the final adjustment when move from the ZD220 to ZD421. If you use the ZebraDesigner for Developer tool to design the label, it will be very simple and straight forward for making the adjustment with the tool when moving from one printer model to another.

The ZD421 is a Link-OS printer, while the ZD220 is a Link-OS Basic printer. If your application doesn't use the cloud-based printing, then you can use the ZD220 as a substitute for development. If your application requires the printer connection via the websocket (or weblink), then you need a Link-OS printer.
