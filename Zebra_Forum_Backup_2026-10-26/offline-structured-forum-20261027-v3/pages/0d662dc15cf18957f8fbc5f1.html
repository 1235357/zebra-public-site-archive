Hi. 

I am trying to use ZBI to extract data from a string which I am receiving on the serial port. I want to break the data into three fields and then reprint these on a label. The string is made up of {Field1}<HT>{Field2}{Field3}. I am trying to strip out the first part of that string up to the <HT>. However, I cannot find a way to search for this character. Can anyone advise if this is possible please and how I can do this? 

Thanks, Anthony.

There are a number of ways to achieve this, but if you are always searching for a known string to remove (<HT>), just replace that with "" (empty string) at its beginning and ending index positions. You can use the ZBI POS function to find the match and it will return an index (if found) or 0 (if not found).

There are some example programs in the manual that you can review for reference (starting at page 586):
ZPL II, ZBI 2, Set-Get-Do, Mirror, WML Programming Guide
