PLEASE NOTE - THIS IS NOT A ZEBRA SPECIFIC ISSUE - BUT A MICROSOFT AZURE DOCUMENTATION ISSUE- AND THERE ARE STEPS THAT CAN BE TAKEN.
 

++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++


As Per the Zebra ZIOTC Documentation on GitHub, as well as the correspondent GitHub for Microsoft Azure, 

a reference is made to a now Expired "Baltimore Root Cert" from this reference:
https://zebradevs.github.io/rfid-ziotc-docs/other_cloud_support/AZURE/cloud_instructions.html#create-device-self-signed-certificates

The Affected Microsoft Github as part of that Source Material:

https://github.com/Azure/azure-iot-sdk-c/blob/main/certs/certs.c

Both of these documents refer to a Digicert Baltimore Root Cert that expired on May 12, 2025. 

++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

Using this certificate material and signature - is likely to result in the AZURE connection for the ZIOTC definition based on the above steps - to not connect due to the Certificate Material is now expired.

Affected Platforms - Any that use IOT and connect to the Microsoft Azure via the steps outlined above. This can be the ZIOTC IOT connector on the FX-Series (and ATR7000), as well as the FXR90 (also IOT-based)  And for Scanning platform with the "IOT for Scanners (Windows / Linux) that also may leverage the Microsoft AZURE IOT platform.

++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

Using Google Gemini - you can locate the G2 cert from DigiCert as well as actions to take - as follows:
 

Actions to Take:
1 Update Root Stores: Ensure your operating systems, browsers, and application trust stores (e.g., Java, Kubernetes, Linux ca-certificates) are fully updated.
Quick Note as per V3.31.22 Firmware - where the Zebra Help Desk encountered this update / issue - the FX-Series readers have the up-to-date Certificate Store - that is compatible with these "Actions to Take".

2 Migrate to G2 Root: For services currently using Baltimore, transition to the DigiCert Global Root G2 or intermediate certificates.

https://knowledge.digicert.com/general-information/digicert-trusted-root-authority-certificates

3 Check Azure IoT/IoT Hub: Azure IoT hubs have migrated to DigiCert Global Root G2, so devices must have this new root installed to avoid connection failure

( This depends on the developer knowing how to navigate the Microsoft Azure environment to make these checks. )
