Hello, I'm printing some labels with czech characters "Č" and "Ř". There's no problem with Zebra Designer, but when I try print from zpl file, these characters print as "." or they won't print at all. I learned that I needed code page 1250, which is ^CI31, however the ZPL programing guide says "this value is supported only on Zebra G-Series printers." Is that means that I'm out of luck with Zebra ZT111?

This is a font issue. When using the ZebraDesigner tool, you have the choice to use the font on the printer. If you didn't make such choice, the ZebraDesigner tool will use the font installed on the Windows PC and sends the characters as image to the printer to print.

To print Czech characters, you need to make sure the desired font that has Czeck characters is installed on the printer. Check this article on how to install a font on the printer - Sending the Swiss 721 Font to the Zebra Printer
