Few points to take in consideration , USB to Serial adapter will not work for this process .
to use OPOS over RS232 you will need to set the MP7 to SSI host , edit corescanner config to point out the used port .
I done this setup in past see link https://zebra.my.salesforce.com/sfc/p/i0000000KxK7/a/6S00000029X4/_ljhL…

Since you need to use OPOS , any reason on not using USB cable and have MP7 set into IBM Table top ( default mode ) this will work straight out of the box .
