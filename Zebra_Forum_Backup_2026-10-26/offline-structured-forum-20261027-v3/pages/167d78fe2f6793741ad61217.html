This is the code I have to create the RFID bundle

 

private fun createRfidBundle(configuration: ScannerConfiguration): Bundle {
val pattern = configuration?.getRfidPattern()
val enabled = configuration?.wantsRfidCapability() == true && pattern.isNullOrBlank().not()
val barcodeParamListBundle = bundleOf(
"rfid_input_enabled" to if (enabled) "true" else "false",
"rfid_beeper_enable" to "true",
"rfid_led_enable" to "true",
"rfid_session" to "1",
"rfid_antenna_transmit_power" to 30,
"rfid_hardware_trigger_enabled" to "true",
"rfid_trigger_mode" to "0",
"rfid_filter_duplicate_tags" to "false",
"rfid_pre_filter_enable" to "true",
"rfid_pre_filter_tag_pattern" to pattern,
"rfid_pre_filter_target" to 1, //Session 1
"rfid_pre_filter_memory_bank" to 4, //Memory bank EPC
"rfid_pre_filter_action" to 0,
"rfid_post_filter_rssi" to -100,
"tag_RSSI" to true
)
 
return bundleOf(
"PLUGIN_NAME" to "RFID",
"RESET_CONFIG" to "true",
"PARAM_LIST" to barcodeParamListBundle
)
}

hi there:

 

1/ rfid_enable_tag_rssi: This parameter is specifically used to include RSSI (signal strength) information for each tag read. Setting it to "true" ensures that the RSSI values will be appended to the tag data output.

  • Other Parameters: The remaining parameters (rfid_input_enabled, rfid_enable_hardware_trigger, and rfid_enable_antenna) remain as before to enable RFID input and ensure proper operation of the RFID scanner.

Expected Output

When a tag is scanned, the output will include the following information:

  • Tag Data: The unique identifier of the tag (e.g., EPC or TID).
  • RSSI Value: The signal strength of the tag read. This is typically a negative value (e.g., -65 dBm), where a higher absolute value indicates a weaker signal.

2/ not a specialist but maybe a path below:

@Override
protected void onNewIntent(Intent intent) {
   super.onNewIntent(intent);

   if ("com.example.rfid.DATA_CAPTURED".equals(intent.getAction())) {

       String rssi = intent.getStringExtra("com.symbol.datawedge.data_rssi"); // Check if RSSI is included

       Log.d("RFID", "Tag Data: " + tagData);
       Log.d("RFID", "RSSI: " + rssi);
   }
}
