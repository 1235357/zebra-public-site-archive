Hello,

I am currently trying to automatically upload a dataWedge profile from my android mobile application to the dataWedge application via the Intent IMPORT_CONFIG 

My profile is in the folder raw inside the application and I copy it to the external directory available for my application (sdcard/data/com.myapplication.app/files). 

I enable logging for dataWedge and don't have any error when the profile is send and can't be seen inside the  datawedge application. 

Since Android restricted writing in external storage, i can't upload the file elsewhere (except if I missed something, I tried with asking READ_EXTERNAL_STORAGE and WRITE_EXTERNAL_STORAGE permission at runtime but nothing change , same with MEDIA permissions)

 

 private fun autoImportDataWedgeProfile() {

        val outFile = File(getExternalFilesDir(null), "dwprofile_profilename.db")
        outFile.setWritable(true, false)
        outFile.setExecutable(true, false)
        outFile.setReadable(true, false)

        resources.openRawResource(R.raw.dwprofile_profilename).use { input ->
            FileOutputStream(outFile).use { output ->
                exportFile(input, output)
            }
        }

        Log.e("DataWedge", "Profile copied successfully")
        importConfig()
    }

 private fun importConfig() {
        val bMain = Bundle()
        bMain.putString("FOLDER_PATH", getExternalFilesDir(null)?.path)
        val fileNames = ArrayList<String>()

        fileNames.add("dwprofile_profilename.db")

        bMain.putStringArrayList("FILE_LIST", fileNames)

        // send the intent
        val i = Intent()
        i.setAction("com.symbol.datawedge.api.ACTION")
        i.putExtra("com.symbol.datawedge.api.IMPORT_CONFIG", bMain)

        this.sendBroadcast(i)
    }

 

Maybe I missed something in the documentation but did anyone tried with the intent and have you succeed ? 

 

Thanks in advance for your help

Hi Jordan,

I have a workaround but not directly import .db profile:

1. export the profile into sdcard in JSON format using:
com.symbol.datawedge.api.GET_CONFIG
and you have to implement utils to covert android bundle into JSON object and write the raw string into .json file on sdcard

2. import the .json format profile:
you can read the .json file into JSON object and covert it back to android bundle. then you use 
com.symbol.datawedge.api.SET_CONFIG
to create profile by the android bundle.

you can reference to the methods:
DataWedgeHelper.getProfile()
DataWedgeHelper.configWithJSON()

in my open-sourced non-official sample code
https://github.com/ys2714/zebra-sdk-kotlin-wrapper

Hoping this can help.
