We have tried to submit an app to the Apple App Store that includes a version of the Link-OS iOS ZSDK_API.xcframework but Apple will not accept the build.

Apple gives us the following error:

ERROR: [altool.600001D4C1C0] [ContentDelivery.Uploader.600001D4C1C0] Validation failed (409) Invalid bundle structure. The “.app/Frameworks/ZSDK_API.a” binary file is not permitted. Your app cannot contain standalone executables or libraries, other than a valid CFBundleExecutable of supported bundles. For details, visit: Placing content in a bundle | Apple Developer Documentation (https://developer.apple.com/documentation/bundleresources/placing-content-in-a-bundle)  (ID: ad706a06-32ad-444e-8576-88d75b225132)

We downloaded the latest iOS ZSDK_API.xcframework, version 1.6.1158, but noticed it still contains the ZSDK_API.a binary file (https://www.zebra.com/gb/en/support-downloads/software/printer-software/link-os-multiplatform-sdk.html?downloadId=244e0a9e-642c-48ab-8625-0b19b8ef0847).

Do you have a version of the iOS ZSDK_API.xcframework that addresses this issue or have a timeline for releasing an update?

Hi Christopher,

The error msg shows the current issue is that the ZSDK_API.a file should not be included in the Framework folder of the project. Please move the ZSDK_API.a file to a lib folder in the Xcode project.

Please make the changes as suggested and resubmit your app.
