I have a customer who uses both MC9090 and VC5090 with AppCenter. Users in a DC have discoverd that if they tap the desktop screen fast enoughon warm or cold boot (CE5), they can launch things like IE and My Computer before AppCenter loads to stop them. Even though Appcenter starts a second later, they already have the apps open and hence the issue. I have tried loading AppCenter via startup registry instead of \Windows\Startup\ folder and this did seem to go a little faster, but not fast enough. Anyone else run into this and any thoughts on being able to stop this scenario?

Disabling windows start button (via registry as below) and moving \Windows\Desktop\* items to other folder might prevent user from launching applications prior to Appcenter start up. [HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Shell] "HideTaskBar"=dword:00000001 "EnableStartButton"=dword:00000000
