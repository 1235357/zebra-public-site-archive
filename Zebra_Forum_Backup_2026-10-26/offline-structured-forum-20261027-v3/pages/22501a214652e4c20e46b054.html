Hi,

 

I am trying to get the Link OS Version of a Zebra ZD230T connected via USB, using SGD command (appl.link_os_version), I am calling from the SGD class within the Link-OS SDK.

But it's returning "?"

In a ZT231 it returns correctly.


I assume that it should return the version because this model is marked as compatible with the appl.link_os_version command. (See picture "SGD Table" Attached)

 

I also checked using the Direct Communication Tool, with the command "^XA^HH^XZ", but it's not showing the LINK-OS version also. (See picture "Direct Communication.png" Attached)

 

Can you help me discover why is not returning?

 

Best regards.

The ZT231 is a Link-OS printer (a.k.a., Zebra Print DNA printers). The ZD220 & ZD230 are Link-OS Basic printers (a.k.a, Zebra Print DNA Basic printers). Unlike the Link-OS printers, the Link-OS Basic printers do not have the Link-OS version defined for the "appl.link_os_version" SGD.
