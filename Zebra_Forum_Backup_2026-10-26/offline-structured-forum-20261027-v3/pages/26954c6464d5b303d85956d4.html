We have a ZE511 Printer that is going to be used with the Applicator Interface on a Industrial Environment.

The Dinamic Data of the Label will arrive to the printer by Ethernet Socket, so we are creating the ZBI that will handle this and has the ZPL format of the Label.

Our doubts at the moment are regarding the activation of the Interface Eletrical Signals. 

The Printer Menu has the Configuration setup for the Mode of the Applicator and we have define the desired value on this field.

Setting the value in this menu it's enough for the printer to manage the eletrical signlas of the Applicator Port?, or in ZBI program it's need to set/reset those signals?

Hi Nuno.

Are you using ZBI to create the label from incoming data? And are you using the Applicator interface to trigger printing?

You should be able to set the Applicator data to your desired settings and not worry about it afterwards as long as your label code does not include the ^JJ command or any SGD commands.
