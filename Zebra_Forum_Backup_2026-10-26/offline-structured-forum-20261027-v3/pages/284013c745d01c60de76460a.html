TC75 Alpha Users,

If you have a Nano SIM and are trying to get it to work on the TC75, read the following:

Here is what you need to do to make the Nano SIM slot active…

• Place the config file (attached) into the SD card root folder. Config file is placed in the path
          o \\celerra11.symbol.com\Projects2\Ubuntu_Tools\WWAN_UI
• Go to settings -> More… -> Mobile networks -> SIM socket selection to set the SIM socket (default is Mini SIM).
• The config will enable the "preferred network type" UI. From the UI the required network type (2G/3G/4G) can be selected.

That should do the trick.
