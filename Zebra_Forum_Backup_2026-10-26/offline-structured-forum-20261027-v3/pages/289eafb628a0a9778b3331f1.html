I tried to remap the Volume Up Key to the function Button_SCAN
To use the settings for a mass rollout I exported the settings and used the exported file key-config.xml
This file need to be placed in /enterprise/device/settings/keypad/ on the TC75

Using the device file explorer and copying the file manually from the SDCard to the /enterprise/device/settings/keypad/ folder will work.
The XML File will be auto imported and the desired value will be set.

Using a FileMgr Setting in Stage know to copy the file into /enterprise/device/settings/keypad/ will work as well.
The XML File will be auto imported and the desired value will be set.

Unfortunately, it is not working with SOTI 12.1
Within a SOTI Pakat, I copy the file into /enterprise/device/settings/keypad/´
after that I will use this Postscript command to set the file rights.

execute_shell chmod 777 /enterprise/device/settings/keypad/key-config.xml

The key-config.xml will not be automatically consumed and the values are not set.
The same method will work on TC70.

Because the customer need to change the mapping later on, it is necessary to be able to set the mapping along wit SOTI.

Any ideas on how to get this fixed?
