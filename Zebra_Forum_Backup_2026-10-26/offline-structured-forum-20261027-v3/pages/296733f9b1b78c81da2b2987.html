Team, We have a customer with the following Appcenter issue on there MC9090: To connect to the server, their application turns on the device's WiFi using the EMDK, currently using 1.7, and waits for a notification from the OS (via .NET’s Microsoft.WindowsMobile.Status.SystemState class) that a network connection has been established.

 

In MC9090 with AppCenter installed (even when not in kiosk/user mode), the network connection notification is never received.

Their application worked as expected, meaning it was able to turn on WiFi and was aware that a network connection has been established, until they installed AppCenter.

 

Their MC9090 units have Windows Mobile 6.1 Classic (CE OS 5.2.19590 Build 19590.1.1.5) installed and the AppCenter version is 2.0 Build 947.

 

One other problem they have with AppCenter is that when trying to open up wireless manager (through WiFi icon on windows start bar or the Windows settings/connections/wirelessmanager) in admin mode, the wireless manager somehow always ended up being closed automatically.

There application woks as expected after Appcenter is uninstalled. Any ideas? regards, Daniel

We have a customer with a similar issue whereby connection manager is not updating its status to the registry while AppCenter is running. The case number is 2113144. As a quick workaround they delayed launching AppCenter for 40 seconds, allowing CM time to update the registry. They have a tool that disables the touch screen for this&nbsp;time until AppCenter kicks in. The symptom described here occurs mostly when coming out&nbsp;of a Cold-boot and/or backup battery drain condition. Hope this helps.
