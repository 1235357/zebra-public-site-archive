Quick FYI - Because Xamarin Product is no longer supported by Microsoft- it is also likewise not supported by Zebra.

I have encountered other (external developers) who have successfully used the RFID SDK for Android Studio - library quite to make a Xamarin support stub module - but this is also very unique to those partners and is supported "as-is" where if an issue is encountered and the RFID SDK for Android Studio - demonstrates the same fault- the issue is resolved in the Android Studio RFID SDK - or for the Device / Platform Specific Firmware for the RFID Module Used.

I do apologize - but the above error - is likely due to AI - based solutions attempting to configure a Binding Library with an incomplete supporting definition method - that is unique and likely specific to the AI output.
 

As such - from the above - there is likely missing information for the required API definition - that is resulting the NULL parameter binding compilation error.

I would at this time - highly recommend either using the RFID SDK for Android Studio in native format - or using the MAUI RFID SDK for Android - as an alternative.  Since the Xamarin Platform overall is no longer supported and why that library stopped at V2.0.1.116 in the past.
