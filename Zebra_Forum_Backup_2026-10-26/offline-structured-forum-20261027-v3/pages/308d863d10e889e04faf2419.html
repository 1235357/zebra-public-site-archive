Changing Mobile IE version on OEM 35 MC55 MC75 OEM 35 have both by default IEMobile 8.12 aka "6 on 6" as the browser.Some functionality is not working ok:- Datawedge 31. cannot be configured on the Unit because local host cannot be reached.- some webpages are not rendering ok With following regkey the IEMobile mode 7.11 can be set on OEM 35
[HKEY_LOCAL_MACHINE\Security\Internet Explorer]"MSHTML"=dword:00000000     ; value change to 0     IEMobile 7.11 functionality ; value 1 is default     IEMobile  8.12 functionalityAfter this change Datawedge 3.1 will work locallyalso Menu within IEM will show "One Column" and "Fit to Screen" options againsee also attached document.
