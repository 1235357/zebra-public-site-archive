You can achieve your desired use case by configuring the audio-related parameters in the scanner settings. Specifically, to adjust or turn off the volume, you can use a URI pointing to either a silent audio file or a loud audio file.

Refer to the following fields in the scanner settings for implementation:

  1. decode_audio_feedback_uri – This parameter allows you to specify the URI for the audio feedback file, which can be silent or contain specific audio cues.
  2. volume_slider_type – Use this parameter to chose the type of the notification.

For more detailed instructions, please refer to the official documentation available at the link below: https://techdocs.zebra.com/datawedge/latest/guide/api/setconfig/

Let me know whether you can achieve your need by setting these parameters.
