Hello Amzar,

The ZT610 600dpi supports TCP/IP communication. It comes standard with a built-in internal Ethernet port for network connectivity.

How to establish communication:
Set a Static IP: Use the printer’s front panel menu (Network settings) to change the IP Protocol to Permanent and manually assign an IP address. This ensures the PLC always finds the printer at the same location.

PLC Connection: Program the PLC to open a TCP socket to the printer's IP address using Port 9100 (the default port for raw ZPL data) to send print commands.
