Hi everyone,

I have a question regarding the use of Zebra ZBR4001 RFID tags attached to reusable boxes in our factory.

During production, once finished goods are packed into a box, we write the job/order information into the User Memory Bank of the RFID tag.

After the products are shipped to customers, the empty boxes are returned to our factory for reuse. However, the RFID tags still contain the previous job data stored in the User Memory Bank.

What I would like to achieve is a process that can erase the User Memory Bank data from multiple RFID tags at the same time, ideally around 30 boxes per batch.

The concept I have in mind is to use an RFID gate/portal, where all returned boxes pass through the gate and the system automatically clears the User Memory Bank on every detected tag.

Has anyone implemented a similar solution, or can anyone recommend Zebra hardware, software, or best practices for this use case?

Any suggestions or guidance would be greatly appreciated.

Thank you!

Hi Khunakon

I do not provide a specific solution to your question, but recommend as a guide one option that can be done via Fixed readers - that are properly integrated into Infrastructure for IOT connected RFID Fixed Readers.

There are a few predicate conditions where ZIOTC being used ( I am going to use MQTT as my driving example here )

  1. You know the first 3 words of the MEMORY_BANK_TID  In my example I know the tags I am seeking are "e280 6f12 2000" .
  2. You know the EXACT Word Count you need to deal with.  ( In my Case - the USER mem bank is only 4 words long and no offset. )

Using ZIOTC you could Scan ( A TagAccess Inventory ) for a specific series of tags as follows:
<snip> //SMK MQTT Example set_mode API to Read a specific TID for USER by wordpointer and wordcount.
{
 "command": "set_mode",
 "command_id": "abcd1234",
 "payload": {
   "type": "CUSTOM",
   "query": {
       "tagpopulation": 100,
       "sel": "ALL",
       "session": "S0",
       "target": "B"
   },
   "selects": [
       {
           "target": "S0",
           "action": "INVB_INVA",
           "membank": "TID",
           "pointer": 0,
           "length": 48,
           "mask": "e2806f122000"
       }
   ],
   "accesses": [      
       {
           "type": "READ",
           "config": {
               "membank": "USER",
               "wordPointer": 0,
               "wordCount": 4
           }
       }
   ],
   "radioStopConditions": {
       "antennaCycles": 3
   }
}
}

</snip>

If you use the result set from the above you can address the "idHex" for each result where USER is non-zero above (Recommended) 


-AND-  

You may notice in the above - that I am not using any Passwording - since using the "Access Password" may be assumed - but implementing that - is not in scope to your question ( Yet SHOULD be something you should have thought to implement to protect your tags.)  So...  I have left that out of this response - to allow you to begin this journey of looking at what code you can implement for what you seek.
