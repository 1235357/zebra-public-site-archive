Hi Team, The following reg key will disable the SMS conversation mode on the MC75/MC55 running WM6.1 (BSP27): [HKEY_CURRENT_USER\Software\Microsoft\Inbox\Settings\OEM] "SMSInboxThreadingDisabled"=dword:1 However, this reg key will not work on devices running WM6.1 (BSP35) Any ideas on how to disable SMS conversation mode on devices running BSP35? regards, Daniel
