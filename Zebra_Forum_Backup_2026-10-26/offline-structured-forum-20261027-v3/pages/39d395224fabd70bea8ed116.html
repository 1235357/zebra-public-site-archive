Hello Gary You could set the terminal type as part of staging - you could use a script to do this automatically i.e. write the OEM string (e.g. "MC70 Symbol") to the registry or file.&nbsp; With a script you can also get the other variations of terminal type i.e keypad type, radio type, scanner etc..&nbsp; So could go into detail about the terminal configuration. Also if you set the ident registry key (can set under control panel on WM termianls) to terminal type (OEM string),&nbsp;DHCP will use this to identify the terminal - but think its limited to 8 or 12 characters.&nbsp; This can be automated with a script.
