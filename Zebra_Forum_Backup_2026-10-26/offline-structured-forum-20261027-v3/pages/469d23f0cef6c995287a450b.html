I'm running DataWedge 13.0.325 on a TC22 (Android 14). My custom app (Qt for Android) has an entry field, which focused programmatically. When the app is freshly started, it doesn't receive any input from DataWedge. Scanner input is simply discarded. However, after manually selecting the input field, it starts to work and continues to do so until the app is closed.

How do I force DataWedge to work without manual intervention?

Hi Rüdiger, it requires the input field to have focus otherwise the KeyStroke output of DataWedge will not work.

If you have developed the application you could control the DataWedge output by using Intent Output instead of KeyStroke and in that way the data can be pasted automatically inside the input field without requiring any manual input from the user.
