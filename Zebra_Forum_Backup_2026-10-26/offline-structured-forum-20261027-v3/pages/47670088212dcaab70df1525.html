Hello,

we are using:

  • Enterprise Browser: 3.7.1.7
  • Android: 13
  • Model: TC22

We developped a Warehouse Management application as a React-Ionic-Typescript SPA. We run the application in EnterpriseBrowser with EnterpriseKeyboard. That is the only part of the EB API we are using. We primarily chose EB for management options through StageNow and stability.

An important customer (among others) has been using this application since May 2024 without any issues. 

Starting in December 2024, they (and no others as far as we know) experience the following issue: Enterprise Browser suddenly crashes. When tapping EB from "Recent Apps", the application restarts and the user has to identify in our application again and restart what he was doing. We cannot identify any breaking changes we could have done to our code, and the devices do not update their android version or EB version automatically (and we have not done it manually either).

I also activated Trace logging on EB but, as far as I can see, the logging does not give me any more information as to why EB crashes. The logging just suddenly stops at the moment of crash. Checked this multiple times already. I have included last part of the most recent crash log I have. 

Does anybody have any hints as to how to discover de source of this problem. Is there any crash log that can be activated that could tell me more? Is this a known issue?

I suggest that you log a support case for this issue but you could also:

a) Update Ent Browser to the latest release (5.0.0.13)

b) Update Ent Keyboad to the latest release (5.1.0.0)

c) if the problem persists, start RxLogger before the issue and then export the log immediately after the issue occurs - the log may contain some useful diagnostic info concerning the reason for the crash
