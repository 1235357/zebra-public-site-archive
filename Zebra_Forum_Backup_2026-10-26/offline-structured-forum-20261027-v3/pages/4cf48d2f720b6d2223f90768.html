Hi,

If you are running GitHub - Zebra/samples-emdkforandroid-6_4 at BarcodeSample1&nbsp; without modification then ensure 'continuous' is checked and then press 'start'.&nbsp; Start does not start the laser but rather enables the scanner hardware and as long as the sample trigger type is set to HARD the hardware trigger should be in effect.
