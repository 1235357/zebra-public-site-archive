I was testing some Android code I wrote to perform printer firmware updates for one of my customers, and during that process I successfully updated the firmware on my ZD510 printer that I use for development, so I knew the code worked. I attempted to roll the printer back to an earlier version that supports these cartridges, but every downgrade attempt has failed. I’ve followed all documented procedures to apply the older firmware (V80.20.29Z) without success.

Is there any way to return the printer to a firmware state that supports the older black cartridges? Is there any plan to support folks like use who made the mistake?
