For connectivity with ZQ220, try to use Bluetooth. To print from a browser based application, use the Browser Print, which has an Android based client app to install on an Android device. The client app is responsible for connecting to the ZQ220 printer. Since the ZQ220 only works with CPCL, you need to design your label in CPCL. Use the ZebraDesigner 3 to design CPCL labels.
