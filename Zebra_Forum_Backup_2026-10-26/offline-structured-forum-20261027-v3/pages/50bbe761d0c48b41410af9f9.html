Hi there,

I've created an web application in .Net 4.8 that needs to print Code 128 barcodes out to the above printer on the fly. 

Up to now, I have been generating bacrodes by having an asp image placeholder and creating a bitmap in code. Then I use that bitmap to populate the barcode image and sending that to the printer. That works on an A4 printer and I've been using that method in the past. However, the specific application requires specific labels to be printed on this printer and it looks to be trying to either dither or scale the barcode image. I've contacted support and changed the printer image settings to clipart as requested, but it still isn't working.  It's also been suggested that I generate the image as PDF, but I can't see how I can do that and send it to the printer.

The image looks fine on screen (and scans), and also is fine if printed to a 'normal' printer, but not if printed directly to the label printer.

I've installed Zebra Designer 3 and generated a barcode from there, and it works perfectly, but printed from my application, it doesn't (see image).

I'm unfamiliar with Zebra printers, so am looking for some advice/guidance on what the best methods for printing from a web application.  I've seen the Browser Print utility and have looked on the documentation for that, but I'm not sure if that's the answer fo this solution.

Any help would be much appreciated.

Thanks in advance.

Russ
