Hi,
You have a couple of options:

Use Enterprise Browser, please see this post:&nbsp;https://developer.zebra.com/community/home/blog/2019/03/05/javascript-f…;
Use DataWedge with keystrokes, please see this post:&nbsp;https://developer.zebra.com/blog/listening-keypress-events-datawedge&nb…;
Use DataWedge and capture data into input fields, see the official docs for Keystroke output:&nbsp;https://techdocs.zebra.com/datawedge/8-2/guide/output/keystroke/

Most Angular developers I have seen have opted for the second approach above.
Hope that helps.
