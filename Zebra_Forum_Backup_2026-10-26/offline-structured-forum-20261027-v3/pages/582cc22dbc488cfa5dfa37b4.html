this more sounds that the SD card driver is unloaded during suspend/resume cycle&nbsp;( default behavior ) if you want sd card driver loaded all the time&nbsp; check following:
For MC75A..

[HKEY_LOCAL_MACHINE\Drivers\BuiltIn\SDHC_GENERIC]

"NoRemoveOnResume"=dword:00000001

&nbsp;

Additionally following regkey can be change to 1 if required

&nbsp;

HKEY_LOCAL_MACHINE\Drivers\BuiltIn\SDHC_GENERIC

“NoRemoveOnBattFault”=dword: 00000001
