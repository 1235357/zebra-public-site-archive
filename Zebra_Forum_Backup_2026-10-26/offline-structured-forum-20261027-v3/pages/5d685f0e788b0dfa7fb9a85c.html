Hi I need to get all the logs from a ZTC ZT411-203dpi ZPL printer under tcp connection. I have been trying to get the logs with:

! U1 setvar "device.syslog.enable" "yes"

! U1 setvar "device.syslog.save_local_file" "yes"

! U1 setvar "device.syslog.configuration" "info,local;notice,local;debug,local;emerg,local;alert,local;crit,local;err,local;warning,local;" (to configure the type of logs)

! U1 getvar "device.syslog.entries" 

but its always returning an empty string and I don't understand why.

Other commands like this works (but I still cant see the logs of this):

! U1 DO "device.pause" ""

! U1 DO "device.unpause" ""

What am I doing wrong?

The command used to enable the syslog was wrong. To enable/disable device.syslog.enable, use "on" or "off" (not "yes" or "no", which is wrong)

! U1 setvar "device.syslog.enable" "on"

I attempted multiple times, using several different printers, to get syslog working without success. After reviewing the documentation (zpl-zbi2-pg-en.pdf) and researching online, I discovered that the configuration string must have become case-sensitive (possibly after firmware upgrades?), when before it was not. The configuration shown in the example in this Thread did not work for me, even after resetting the printer.

However, in the following post within this forum, the keys are shown in uppercase, which contradicts all other examples I found:
https://developer.zebra.com/community/home/blog/2015/12/02/link-os-printer-operating-system-syslog

When I changed the configuration string to uppercase
("INFO,LOCAL;NOTICE,LOCAL;DEBUG,LOCAL;EMERG,LOCAL;ALERT,LOCAL;CRIT,LOCAL;ERR,LOCAL;WARNING,LOCAL;")
and then reset the printer, syslog began working as expected.
