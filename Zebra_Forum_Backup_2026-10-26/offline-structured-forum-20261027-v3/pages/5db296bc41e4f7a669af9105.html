There isn't any registry key which will disable the Backlight key on the keyboard. One possibility is to modify the keyboard .rmt file and remove the key from the remap table that the keyboard driver uses.&nbsp; You can contact support to find the location of the keyboard SDK for the MC75.&nbsp; I'd send you the files, but I don't have that SDK in my possession (I do have the ones for the MC9090, 9060, and 55). Hope this helps.
