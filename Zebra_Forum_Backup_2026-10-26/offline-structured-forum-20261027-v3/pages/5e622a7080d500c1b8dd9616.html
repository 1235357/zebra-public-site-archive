Hi All, Just wondering if anyone has any experience using trixbox as a PBX for the WSM? I'm running into a problem where the EWPs are able to call out to non-EWP SIP clients, but not able to receive calls. So far, I've been using the 1.72 Lab Guide v2.1 to set things up...  Only change I did make was to set the PBX Type in the WSM to Nortel-CS1000 (setting it to Avaya-SES per the lab guide didn't allow any calls to/from EWPs at all). Some other notes:  - WSM is running Rev.E  - EWPs are running Rev.E  - trixbox ce is latest downloaded at v2.8.0.4   - calls between standard SIP clients work fine in both directions (e.g. PC, Droid, etc.)  - calls from EWP to any std SIP client work fine  - but calls to an EWP (from either std SIP or another EWP) fail (EWP gives fast busy signal, "Call Failed" error message)  - EWPs show Full Service  - trixbox does show SIP Peer entries for the EWPs, using port 5061.  Their status shows "Unmonitored" (vs. std SIP clients show "OK")  - no other dialplans or other configurations in trixbox Any tips and/or suggestions of things to check out or try appreciated!  I'm just sorting through both the WSM and trixbox now trying to learn which debug log options might be helpful... In case anyone else is trying this, maybe this'll save you some time…

We did end up getting Trixbox working with the WSM (so far, for basic calls to/from EWPs…)

The piece that needed to change was the dial string for the EWPs.&nbsp; While the default is something like “SIP/502”, it needs to be something like “SIP/502@10.20.0.54” instead (where the IP is WSM).&nbsp;&nbsp;(Thanks to Bob P's install docs for the tip)

This looks to be a good demo with the SIPdroid client, too!
