Have the customer create a .pfx user cert Rename .pfx to a .p12 file.&nbsp; Raname&nbsp;anyvother cer files to crt Copy all certs to the root of the tablet. Install the certs from within Settings/Location and Security/Install from SD in order&nbsp;from the root down M ake sure Use Secure Credentials is selected from within the Location and Security settings tab Create a wireless profile with your SSID Select WPA2 Enterprise EAP method is TLS Phase 2 leave @ None CA Cert leave at unsepecified Select your User Cert
