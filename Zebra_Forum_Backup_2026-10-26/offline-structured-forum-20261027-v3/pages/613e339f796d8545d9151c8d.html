Yes, receiving tag scans is working by intent output. On TC53e-RFID I receive barcode and rfid tags with one profile by using the right yellow scan key on the device.

 

First: in your receiver for the intent data differ between rfid and barcode capture as follows:

 //Source is scanner
 if("scanner".equalsIgnoreCase(intent.getStringExtra("com.symbol.datawedge.source"))) {
 	String barcode = intent.getStringExtra("com.symbol.datawedge.data_string");
 	//do anything with it
 }
 //Source is RFID reader
 if("rfid".equalsIgnoreCase(intent.getStringExtra("com.symbol.datawedge.source"))) {
 	//Multiple rfidTags are splitted by "\n"
 	//RSSI values are coming with " -65" (for example)
 	String rfidTags = intent.getStringExtra("com.symbol.datawedge.data_string");
	//do anything with it
  }

Second (for TC53e-RFID):

Configure settings-->Key Programmer 

https://techdocs.zebra.com/datawedge/latest/guide/input/rfid/#keymapping

Mapping RIGHT_TRIGGER_1 to SYMBOL_TRIGGER_3 causes RFID and barcode scan with the right scan button:

[Image unavailable locally: https://developer.zebra.com/sites/default/files/inline-images/sm.png]
