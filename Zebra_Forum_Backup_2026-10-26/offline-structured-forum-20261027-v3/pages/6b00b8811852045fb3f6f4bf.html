The ZQ210 is a value tier mobile printer and non-Link-OS printer that does not support ZPL. The ZQ310 is a Link-OS printer that supports ZPL. I would recommend the ZQ310 for receipt printing. You can easily create a receipt template in ZPL with the ZebraDesigner for Developers 3 Software, which is free. You can also take the advantage of the Link-OS SDK for .NET MAUI 8, which provide API for connecting to Zebra printers over Bluetooth.
