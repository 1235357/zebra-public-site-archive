Hi Lukas.

The following Support portal : https://www.zebra.com/us/en/support-downloads/mobile-computers/wearable-computers/hd4000.html
Has the Service and SDK Packages for the HD4000.
It is really designed to work with Zebra Android Host devices ( and Windows 10 ) But the SDK / ZebraHudSdk_2.1.zip Is geared toward usage / development with Zebra Android Host devices.

This also means that the "Emulator" as you refer to is not a feasible option. (Help Desk does not support that use-case.) 

But the ZebraHudSdk_2.1.zip Contains the APK's and Documentation and HowTo guides to use these Android APK's that when used with the HD4000 can provide the Heads-Up experience of the Six15 available methods for the HD4000.

To your question for running Android apps; Refer to the "README.pdf" in the Hud SDK folder and review your options. (Screen Mirroring)

But I also point out to use the SDK for making the HUD a successful Add-on to the Zebra Android Experience - since this is what the HUD is optimally designed/used for.
