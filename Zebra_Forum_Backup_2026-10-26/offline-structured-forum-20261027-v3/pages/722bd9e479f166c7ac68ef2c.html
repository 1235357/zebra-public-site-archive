It sounds possibly like a focus issue. Keystroke based scanning typically requires focus (often visibly indicated by a cursor) to be on an input field for the keystroke data to have somewhere to go. If the focus is not on an input element the keystrokes will basically go no where and will be lost.

Chrome does not natively listen for intents so it will only work with Datawedge configured via the Keystroke output plugin. If you want to use intents for better control of the decoded barcode data (recommended) then the best option is to use Zebra Enterprise Browser : Enterprise Browser Support & Downloads | Zebra
