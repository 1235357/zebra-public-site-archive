TC22R: TagAccess.writeWait() returns TIME OUT on EPC write (SDK 2.0.5.297)

Hi all,

We are trying to write EPC tags from our Android store application on the Zebra TC22R, and the write fails with an OperationFailureException. getVendorMessage() returns TIME OUT. The same SDK version and the same tag write successfully on a TC52.

Environment

  • Device: TC22R (model TC2205-0G1250SS-US)(sled)
  • Android OS version: 14
  • RFID SDK: 2.0.5.297
  • Current EPC length and format: SGTIN-96 (Example -303802CCC0E19A400000160D)

What we are trying to do

We select the tag by its current EPC and write a new EPC.

private void writeToTag(String oldEpc, String newEpc, String password) throws InvalidUsageException, OperationFailureException {
    TagData tagData = null;
    TagAccess tagAccess = new TagAccess();
    TagAccess.WriteAccessParams writeAccessParams = tagAccess.new WriteAccessParams();
    if (writeAccessParams != null) {
        writeAccessParams.setAccessPassword(Long.decode(password));
        writeAccessParams.setMemoryBank(MEMORY_BANK.MEMORY_BANK_EPC);
        writeAccessParams.setOffset(2);
        writeAccessParams.setWriteData(newEpc);
        writeAccessParams.setWriteDataLength(newEpc.length() / 4);
        if (reader != null && reader.Actions != null && reader.Actions.TagAccess != null) {
            reader.Actions.TagAccess.writeWait(oldEpc, writeAccessParams, null, tagData);
        }
    }
}

Observed behavior

  • writeWait throws OperationFailureException.
  • getVendorMessage() returns TIME OUT.
  • Access password: "0"(null)

Questions

  1. Is this approach (TagAccess.writeWait with WriteAccessParams on the EPC bank) still the recommended approach on the TC22R with SDK 2.0.5.297, or is there a different method or setting for this device?
  2. Are the parameters passed to writeWait correct? 
  3. Are there TC22R-specific RFID settings (power, session, sled firmware, or a minimum SDK or firmware level) that could cause TIME OUT where the TC52 succeeds?

Any pointers or sample code for TC22R would be appreciated. Thanks in advance.
