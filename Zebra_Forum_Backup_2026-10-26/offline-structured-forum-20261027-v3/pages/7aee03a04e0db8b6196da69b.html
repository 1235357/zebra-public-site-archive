Hello Zebra Developer Community,

I'm facing integration issues with the latest Link-OS SDK (v1.6.1158) while migrating from the static library to the xcframework in our SwiftUI + Swift Package Manager project.

**Development Environment:**
- SDK: Link-OS v1.6.1158
- Xcode: 26.2
- Min Deployment: iOS 16.6
- Language: SwiftUI, Swift 5
- Project: Fully SPM-based
 

**Background:**
Previously used the static library (libZSDK_API.a) successfully. Attempted to migrate to the xcframework by removing static library dependencies, but encountering multiple issues.

**Issues Identified:**

1. **Framework not functioning after migration** - After removing static library and adding xcframework, SDK APIs are not working as expected in SwiftUI project

2. **Documentation mismatch** - The integration guide heading mentions xcframework integration, but the content still describes static library steps (dragging ZSDK_API.framework, setting Header Search Paths, etc.). This creates confusion during migration.

3. **SPM compatibility unclear** - Our project is fully SPM-based. The xcframework contains ZSDK_API.a files inside ios-arm64/ and ios-arm64_x86_64-simulator/ folders. Is there official SPM support via Package.swift? Or guidance on integrating this xcframework alongside SPM packages?

4. **Simulator support limitations** - Documentation states "Valid architectures: armv7 and arm64" which excludes simulator support. This blocks our development workflow. Is there a workaround or plans for XCFramework with simulator slices?

5. **Build errors when manually adding xcframework** - When dragging xcframework into project alongside SPM dependencies, getting: `Command SwiftGeneratePch failed with a nonzero exit code`

**Questions:**
- Is the v1.6.1158 xcframework fully compatible with SwiftUI + SPM projects?
- What are the correct integration steps for xcframework (not static library)?
- Is official SPM support planned or available?
- Any workaround for simulator builds?
- Best practices for mixing manually-added xcframework with SPM dependencies?

**Reference:** 
I had previously worked with Zebra support in 2023 for static library integration which was successful. Now attempting to upgrade to latest framework version.

Any guidance or documentation updates would be greatly appreciated!

Thanks in advance!
