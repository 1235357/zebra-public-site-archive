We wrote a Xamarin app using the "Zebra LinkOS Multiplatform SDK for Xamarin" to connect to the bluetooth zebra printer. This works fine on an IPhone 8, but using an iPhone SE the connection is lost every minute or so and then reconnects. This takes quite some time, though, resulting in our application showing an error message or printing with a long delay.

Has anyone experienced this before and have you ever found a solution? Or tips, anyone?

Thanks in advance for ANY help out there

This is a known issue with the latest iOS devices, such as iPhone 11 Pro, iPhone SE and later version iOS devices. See this thread Bluetooth connection frequently disconnected when printing with zpl for details of the symptom. If you experience the same symptom, then you would need a special build of the printer firmware as a workaround.
