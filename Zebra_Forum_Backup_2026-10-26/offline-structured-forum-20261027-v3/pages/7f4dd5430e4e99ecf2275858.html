Hi All,
I have encountered issue with strange vertical shift for big (module size 38 in 300 dpi) QR code in ZPL.
When I use datamatrix code there is no vertical shift but for QR there is shift about 6-7 mm in Y-axis.
I use this ZPL for test: (This is fragment of larger label)

^XA
^FO802,0^BQN,2,38,Q^FDQA,3SDUB000012HCP2FU193980622D^FS
^FO30,0^A0N,29,28^FDMFG PART NUMBER:^FS
^FO405,0^A0N,29,28^FDORIGIN:^FS
^PQ1,0,1,Y^XZ

Y position for QR code and for Texts are the same :0 in ^FO command.
You can see result in attached png file.

Do you know how to remove this shift for QR code?

I use ZT421 with linkOs:7.4.

Kind regards
Adam

Are you using a height parameter in a ^BY anywhere in this or another label format that printed prior on the printer (maybe for a code128)? If so, the height parameter should be put into the ^BX command. It will cause this to happen on a subsequent QR code. I'm betting that if you restart the printer and print this label first, it will be corrected. That should confirm it.

If using Zebra Designer for ZPL, it will introduce this parameter for a code 128, but it needs to be corrected.

See: ^BY Command Parameter Causes a Position Shift of the QR Code Barcode
