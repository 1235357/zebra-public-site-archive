Hi,
To change the default keyboard you should use the MX UI Manager InputMethod action:

InputMethodPackageName: com.symbol.mxmf.csp.enterprisekeyboard
InputMethodClassName: com.android.inputmethod.latin.LatinIME

You will find the XML at the very bottom of&nbsp;http://techdocs.zebra.com/mx/uimgr/
Hope that helps
