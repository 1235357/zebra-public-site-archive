The Browser Print allows to print labels from an webpage (an web app, or website) to a local printer. A local printer means the printer is connected to the device that have the access to the webpage. The connection from the printer to the device can be either network, USB or Bluetooth. The Bluetooth connection is only applicable for Android device, while the network and USB connections are application to Windows PC, Mac OS and Android. To use the Browser Print, a Browser Print client app is required to be installed on the device. With the network connection, the printer and the device are need to be on the same network. If the printer is on a separate network than the device, the Browser Printer client app on the device will not be able to detect the printer.
