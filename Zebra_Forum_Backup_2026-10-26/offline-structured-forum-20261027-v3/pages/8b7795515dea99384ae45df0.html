RFD40 standard will require a Zebra mobile device and an adapter to connect to it and run 123rfid mobile to run inventory tests.

you can also try and connect it to PC via USB-C. use 123RFID Desktop.

If you have an RFD40 Premium then you'll be able to connect a device via BT or even use the mqtt interface to get data to a desktop.

If you have fixed rfid reader you can use 123RFID Desktop to collect and analyse the info.

 

many options! hope this helps
