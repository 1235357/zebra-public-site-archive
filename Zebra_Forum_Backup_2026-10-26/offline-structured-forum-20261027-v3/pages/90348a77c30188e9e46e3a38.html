The FXP20 rfid reader does not have a publically available RFID SDK for any platform at this time.

The 123RFID Desktop app can connect to this reader as an RE40 device and you can check the firmware version as well as test the Operation of RFID reads.

Please keep an eye on this Support portal to when the Support files you asking about.
https://www.zebra.com/us/en/support-downloads/rfid/rfid-readers/fxp20.html

A publicly available RFID software development kit (SDK) for any platform is currently unavailable for the FXP20 rfid reader. You can check the firmware version and test the operation of RFID reads using the 123RFID Desktop program, which can connect to this reader as a RE40 device.
