Hello everyone,

I'm currently facing a challenging issue with Zebra Technologies' Browser Print software version 1.3.2.489. When trying to print labels, I receive an "Unauthorized device detected" error, and the printing fails. This issue does not occur with the older version, v1.2.1.279, where everything works perfectly.

Details of the Issue:

  • Software Version: Browser Print v1.3.2.489
  • Error Message: Unauthorized device detected
  • Operating Systems Tested: Both MacOS and Windows exhibit the same problem.
  • Connection Types Tested: The issue persists on both HTTP and HTTPS (ports 9100/9101).
  • Diagnostic Tools Used: I've tried monitoring the network traffic with Wireshark, which shows no attempt to communicate with the printer using the latest version of the software.

  • Error Logs (~/.Zebra/BrowserPrint/log.txt):

When upgrading the Browser Print client app on MacOS or on Windows to v1.3.2.489, make sure to upgrade the Browser Print JavaScript library on the server as well. The matching Browser Print JavaScript libraries are BrowserPrint-3.1.250.min.js and BrowserPrint-Zebra-1.1.250.min.js.

I've just tested the v1.3.2.489 on my MacBook with the test app that comes with the Browser Print JavaScript Library successfully. I have no issues.

You can also test the Browser Print from this site https://cagdemo.com/ or https://cagdemo.com/BrowserPrint/test/external/zebra_test.html.
