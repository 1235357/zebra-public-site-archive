Does this happen all the time? If it happens all the time, then you need to take a look at the ZPL.
What tool do you use to generate the ZPL? There are a lot ^LH commands and ^FD ^FS commands without field values. We only need to use the ^LH once in one&nbsp;ZPL label format. Once we have the label origin is defined at the beginning by ^LH, we only need to use ^FO to specify the field origin for each elements on the label that are relative to ^LH.
