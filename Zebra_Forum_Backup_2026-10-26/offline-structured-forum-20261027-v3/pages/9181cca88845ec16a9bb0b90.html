Hi everyone,

I’m working with a Zebra FX9600 using RFID IoT Connector and MQTT, and I’m trying to continuously receive data for the same EPC from two different antennas at approximately 10 readings per second per antenna.

What I want to achieve:

  • Same tag should be reported by antenna 1 and antenna 2
  • Around 10 reports per second (≈100 ms interval)
  • Data should include RSSI and phase

Current approach:

  • Using INVENTORY mode
  • Two antennas enabled
  • Continuous reading (DURATION = 0)
  • Using reportFilter to control repeated reports

Example (simplified) configuration:

 

{  "type": "INVENTORY",  "antennas": [1, 2],  "interval": 100,  "transmitPower": 30,  "tagMetaData": ["RSSI", "PHASE", "ANTENNA_ID"],  "reportFilter": {    "type": "PER_ANTENNA",    "duration": 100  },  "antennaStopCondition": [    {      "type": "DURATION",      "value": 0    }  ] } 

Issue / question:

  • With certain configurations, the tag is reported by only one antenna
  • I understand that:
    • RADIO_WIDE suppresses other antennas
    • PER_ANTENNA with duration = 0 can block reporting
  • I want to confirm the recommended configuration to reliably get:
    • ~10 reports/sec
    • From both antennas
    • For the same EPC

Questions:

  1. Is PER_ANTENNA with a ~100 ms duration the correct approach for this?
  2. Are there internal limits on antenna switching or report rate that affect this?
  3. Is INVENTORY mode the best choice for continuous multi-antenna phase/RSSI data, or is there a better mode?

Any guidance or confirmation would be appreciated.

Thanks

I think you are mixing things and not getting the right result.

You can use Inventory with interval =0 seconds which means the reader will be reporting tags all the time. Select tagmetadata to contain ANTENNA so that you get all reads with the antenna info. 

When you use the Inventory mode report filter is normally not effective and in latest version should not be available in the web interface.

Next best thing is to use Custom where you can specify antenna start and stop conditions and probably specify the dwell time per antenna.
