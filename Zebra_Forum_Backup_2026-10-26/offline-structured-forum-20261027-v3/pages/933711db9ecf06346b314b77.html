Valery,

You can try using the method detailed below which will allow time restriction on the use of WAN for Elemez data transfer. One additonal point - if you use AccessMgr (via the EMDK or StageNow) to create a whitelist for apps to run on the unit, it will automatically stop Elemez and other non-whitelisted apps from running or being restarted/reinstalled.

Create a text file called exactly “elemez.properties” with the following text and place it in either /Internal for devices without a physical SD card or the root of the SD card.&nbsp; The file is read upon reboot .

# the name used for the group of devices using this configuration set.
name = TC75
# the time range that elemez should not send cellular data. The times are specified as 24 hour clock, and refer to device local time.
# This example blackout cellular data between 0600 AM and 0700 AM in device local time. This means NO data will be sent over cellular connections between 6 and 7 AM.
cellular-blackout = 0600-0700
# To completely block WAN data use: cellular-blackout = 0000-2359
