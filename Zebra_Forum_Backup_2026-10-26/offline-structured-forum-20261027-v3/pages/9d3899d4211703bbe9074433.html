Hi.
A quick tip, since you are configuring the IoT for the FX-Series reader and using AWS as the instance that you are connecting to, I would not attempt to connect to the FX-Series reader with 123RFID Desktop - or use the "Read Tags" in the Web Console since the existing RFID Connection to the RFID Engine is for the IoT instance connection.

You may need to review how you are reading tags for the RFID Read, and you may need to review your configuration for the reading / re-reading. (Trigger config? - Default Read config? - Are you using GPIO for detection?) Since you are using the "Default Profile" - why not configure / setup one of the built in profiles and test that? (there are quite a few)
