Hi Alberto, &nbsp;You should be able to work around this using the new Datawedge RFID plugin posted on Support Central i.e. enable Datawedge, define a profile for RFID and make a route from the RFID reader input to the keyboard queue output. In this configuration, any tags read will be placed in the keyboard queue and into any active input field in the Telnet session. Best Regards, Ian Hatton
