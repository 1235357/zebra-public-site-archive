The Zebra printers, including ZD420T, have no dependency on the ERP system. It's up to the ERP application how to connect and use the Zebra printers. For example, the Zebra printers work with the Oracle ERP and SAP ERP in the label printing via the XML stream. See the references below.

Oracle Integration

SAP Integration

Unfortunately, we don't have documentation about the Odoo integration. If the Odoo supports the XML stream printing, then it should work with the ZD420T.
