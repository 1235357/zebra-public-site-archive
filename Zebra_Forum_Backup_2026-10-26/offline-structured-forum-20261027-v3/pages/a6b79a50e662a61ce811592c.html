Hello Jaskaran,

A 504 Gateway Timeout on the SendFileToPrinter API (api.zebra.com/v2/devices/printers/send) indicates that the Zebra Cloud API timed out waiting for a response. This is typically caused by device-side communication drops, though it can occasionally be tied to backend routing delays.

Please check the following common causes on your end:

  1. Printer Connectivity: Verify that the target printer is powered on, has a stable network connection, and shows as "Online" in your Zebra cloud portal.
  2. Clock Sync / TLS Failure: If the printer recently lost power, its internal clock (RTC) may have reset. An incorrect time causes TLS authentication to fail, silently dropping the cloud connection. Please ensure NTP (Network Time Protocol) is enabled on the printer.
  3. Payload Size: Test with a very small ZPL file to ensure the gateway isn't timing out before a large file finishes downloading to the printer.

If you verify these and still consistently receive 504 errors, this may be related to an internal system delay on our end. Please raise a ticket so that the team can look into it.

You can submit a support case through the Zebra Support Center here: https://support.zebra.com/
