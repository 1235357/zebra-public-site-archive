Hi Christophe,
To get non-ASCII characters to print you must encode them correctly.&nbsp; By default the printer takes code page 1252 character encoding.&nbsp; This is a combination of how you encode them in Xamarin and in the printer.

Send this command as this :
Encoding encoding = Encoding.GetEncoding(1252);
printerBluetooth.Write(encoding.GetBytes(strToPrint));

You may also need to add the Country command to your format:+ "COUNTRY FRANCE\r\n"
