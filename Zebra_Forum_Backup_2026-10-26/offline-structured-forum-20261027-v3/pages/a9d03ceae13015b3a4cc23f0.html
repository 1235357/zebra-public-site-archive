ZebraDesigner Professional 3 is a tool to design and print labels. It has the ability to connect&nbsp;directly to a database for dynamic data source. The supported database types are: Microsoft Excel, Microsoft Access, Text File databases, ODBC data source. ZebraDesigner Professional 3 doesn't send HTTP requests to a database. It only connects directly to the database via ODBC. If your firebase database supports ODBC, you can connect ZebraDesigner to it. If it doesn't support ODBC, then ZebraDesigner Professional 3 might not be the right choice for you.
