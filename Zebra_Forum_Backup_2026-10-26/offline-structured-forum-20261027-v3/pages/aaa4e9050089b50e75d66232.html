 We have over 30 Zebra ZC300 card printers and are changing to Intune-managed laptops to enable automatic installation via Intune. Despite searching, we could not find an Intune-friendly version of the driver or instructions for rollout via Intune.

Is there an installation guide or another version that can be rolled out via Intune so that the card printers work properly on our devices without manual driver installation?

Hello Christian,

Currently, Zebra does not offer a pre-packaged Intune version (.msi or .intunewin) for the ZC300 driver.

The best practice to roll this out via Intune is to run the downloaded executable (DZCG.01.11.00.00.exe) locally to extract the core driver files (specifically the .inf file). Once extracted, you can package those files into an .intunewin format using the Microsoft Win32 Content Prep Tool and deploy it via Intune as a Win32 app.

You can find the official Microsoft instructions for packaging the app here:
Prepare a Win32 app to be uploaded to Microsoft Intune
