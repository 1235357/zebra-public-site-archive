V
Vincent Bonamy
3 years 7 months ago
158 1

Hello,

I can't print via the Java API on the Zebra ZXP3.

It's very surprising because I can print via the API without any problem on other models like the Zebra ZXP7 or the Zebra ZC300 but not the ZXP3.

On the ZXP3, all the commands work well (flipCard, eject, etc.) but not printing !

Even using the SDK demonstrator (java : Zebra_Card_SDK_Demos.jar), it doesn't work.

I tried with different versions of Java (including java 8 from oracle, 32 bits as well as 64 bits), with different versions of the SDK (including v2.12.3782 which is recommended for ZXP3), under windows as well as under linux, it does not working.

I tried with several versions of ZXP3 (we have 2 slightly different models), always the same problem.

Using Zebra_Card_SDK_Demos.jar in v2.12.3782 and calling a simple print, we get the following messages:

Polling status for job id 35...
Job 35: status:processing, position:, contact:, contactless:, alarm:0, error:0
Job 35: status:done_error (ZMC: Invalid parameter (1)), position:, contact:, contactless:, alarm:3005 (ZMC: Invalid parameter (1)), error:3005 (ZMC: Invalid parameter (1))

On the LCD screen of the printer there is also a simple message 'command error'.

Is there anyone today who manages to make the java print demo work on a Zebra ZXP3 ?

Any idea to solve this issue ?

We know that this model is at the end of its life, but we would like to use it a little longer with certain programs.

THANKS
