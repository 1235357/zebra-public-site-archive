Use the Motorola Remote Capture (RemCapture). Download it from the support central " http://support.symbol.com/support/search.do?cmd=displayKC&amp;docType=k…; 1. Install the RemCapture. 2. Cleann boot the device connected to the PC via ActiveSync. 3. Run RemCapture 4. Take baseline.&nbsp; 5. Do the changes to the device.&nbsp; 6. Capture the difference and save.&nbsp; 7. Deploy the difference to the device.&nbsp; After clean boot the changes will get persist. If you want to install it from a cab file enable Cab file&nbsp;provisioning&nbsp;in the Options dialog. For more information please refer to the Help file.&nbsp;
