Not sure if anyone has been able to connect the WT6000 to MobiControl? I have tried v13.0.0.33754 and the WT is not being recognised correctly whereas the TC8000 (which is running the same MobiControl agent ) is. Screenshot below shows the MobiControl console view of the two devices and the agent seems to have an issue checking the available memory on the WT6000.

The concern here is that for several apps ( MobiControl, Pocket Controller , MyMobiler) the WT6000 is not behaving as a standard Android device and this may indicate a potential compatibility issue for other applications also.

We also must have MobiControl working 100% on the WT6000 before release in order to ensure we have a usable device management platform for the unit. It is possible that this may be an issue introduced with Lollipop since the other devices which are working are all KitKat - if this is the case then we will need a new Lollipop compatible agent from SOTI in order to support the WT and new devices such as Falcon.
