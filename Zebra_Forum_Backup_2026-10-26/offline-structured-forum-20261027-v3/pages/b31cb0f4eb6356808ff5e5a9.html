Hi,

I'm currently integrating the Zebra Scanner iOS SDK with out project to allow pairing and usage of Zebra CS6080 barcode scanners. The project works fine when built and run on an iPad, but we need to be able to test our other features and the rest of the app on simulators on our macbooks (which have arm64 processors) as our team is not fully equipped with iPads. When I try to build for an iOS simulator I hit the error:

clang: error: linker command failed with exit code 1 (use -v to see invocation)

Is there a way we can only link when building for iOS hardware, or some other know workaround or solution?
