There is no auto conversion tool or API to convert the *.nlbl to ZPL. You would have to use the ZebraDesigner to convert them one at a time.

The simplest solution is to use the ZebraDesigner for Developer 3 tool to create a label template in ZPL. With a label template, you use one template for many more items, even 1,000+ items. Your application just needs to send the variable data each time when print a label for a particular item.
