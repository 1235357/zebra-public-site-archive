I tried to install Siebel HH sw to MC75 and MC55 using .cab package .On both units I am getting the error complaining about certificate error/missing components:

"The file 'siebel' cannot be opened. Either it is not signed with a trusted certificate, or one of its components cannot be found. If the problem persists, try reinstalling or restoring this file."

I am not really convinced this is an error caused by a certificate, as all the other applications install fine and our Integrator Guide clearly states that: "Motorola ships all Windows Mobile 6 based products in an *open* state, which means all signed and unsigned applications should work. However, customers can still reconfigure their MC75s to operate in the *trusted* mode." (Trusted - All applications must be digitally signed by a certificate on the MC75.)"

All the units I have been testing operate in 'Open' mode and use the same Windows 6.1 Pro version & build. From Settings-System-About: CE OS 5.2.20963 (Build 20963.1.5.2)

Intermecs use CE OS 5.2.20774 (Build 20774.1.4.8) and they run just fine.

Does anybody know how to overcome this issue? BTW. With the BETA release 903401 we did not have this issue.
