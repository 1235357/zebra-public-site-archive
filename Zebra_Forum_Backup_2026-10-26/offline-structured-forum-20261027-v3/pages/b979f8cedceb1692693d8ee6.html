Windows 10 - Turn Windows Features On/Off Blank can be fixed by checking windows modules installer service status. To do that you need to ensure, that the Windows Modules Installer service Startup status is arranged to Automatic and it is working at that moment. You need to write services.msc in Run box and tap the option of Enter to open the Services Manager. Now search for Windows Modules Installer and see its status. Then double-click on it to make changes to its Properties in case you think it is needed. This Windows Service allows changes, installation, and removal of Windows updates and optional sections. Try https://appuals.com/windows-features-blank-or-empty-windows-11/ for this site to find more solutions. If this service is disabled, then installing or uninstalling Windows updates will probably not work.
