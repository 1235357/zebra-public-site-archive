Hi Anders, Did you set the default printer in Browser Print?&nbsp; This is separate from the Windows Default printer.
getDefaultDevice is asynchronous, so the "After BrowserPrint" will almost always show up before the default device is found.
Past that, is the printer capable of taking PDF files?&nbsp; You need special software installed on the printer to print PDFs directly.
Once you have determined that, I would recommend using the sendUrl() function to send the PDF.
