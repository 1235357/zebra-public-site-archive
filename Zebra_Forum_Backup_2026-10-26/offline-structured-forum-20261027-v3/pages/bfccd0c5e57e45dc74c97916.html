You can create a server with Zebra Link-OS Multiplatform SDK, and have the server make a direct TCP raw connection to the networked printer. The web app takes the printing request from the browser, and then route the printing request to the server to print on the printer via the TCP raw connection. You can also use the Zebra Browser Print, which supports networked printers within your private network. The Zebra Browser Print option is simple and easy to implement.
