What devices do you use to read the RFID tag? If you use the RFID scanner to read the RFID tags, you need to consult the documentation of the scanner SDK. If you use Zebra printers to read the RFID tags, you need to use the RFID ZPL command to read TID. Here is the RFID Programming Guide.
