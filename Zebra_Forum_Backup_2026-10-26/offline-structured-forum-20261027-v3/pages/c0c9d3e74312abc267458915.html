Anand, 

Just place all of the .aar files into a libs folder that you will create inside the app folder. Then, in your build.gradle file, in the dependencies, add one line as follows: 

If you are using Groovy (build.gradle): implementation fileTree(dir: 'libs', include: ['*.jar', '*.aar'])

If you are using Kotlin (build.gradle.kts): implementation(fileTree(mapOf("dir" to "libs", "include" to listOf("*.jar", "*.aar")))) 

You don't need the *.jar but I included it so you can see how it's done if you need to add .jar files to libs in the future. 

Skip all of the other steps mentioned in the documentation.

Best of luck.
