There is a complete misunderstanding of the memory map and how to read the 128/128.&nbsp; 128M is RAM and 128 is flash.&nbsp; The flash is broken down into 64M or NAND flash and 64M or NOR flash.&nbsp; The application partition sits within the 64M of NAND flash.&nbsp; The additional 64M of NOR flash is to be used by the object store and is not available for the application partition. If they need to make the application partition larger, then they must make the platform partition smaller. Or, better yet, build a CAB file that loads these additional application into the object store.
