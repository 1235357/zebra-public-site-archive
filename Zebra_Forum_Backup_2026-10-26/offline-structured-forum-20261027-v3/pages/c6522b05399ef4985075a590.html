You need to use the proper encoding supported by the font file in the ZPL. Using the statement below is incorrect, as the printer doesn't know how to map the Thai characters in plain ZPL to the ones in the font file. You need to use the UTF encoding for these Thai characters, so that the printer can find the corresponding characters in the font file according to their UTF encoding.

^FDสรรพคุณ:^FS
