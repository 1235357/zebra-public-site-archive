Seems like a reasonable solution if the main requirement is to be able to store data in the event of a dropped network connection. It is possible to write apps which run on the FX itself using the Zebra Embedded SDK (https://www.zebra.com/us/en/support-downloads/software/developer-tools/…) but unless this is a large scale deployment it would probably not be worth the time and effort required to do this.&nbsp;
