Quick Update here.
As of FW 3.0.16 - LLRP is made available to those developers using the Legacy RFID SDK (HOST-BASED) that uses LLRP.
Caveats:  - You need to remove the "Auto-Reconnect" in your HOST-BASED SDK App - or the LLRP / DLL will fault / crash.

This is due to the amount of time for the FXR90 to become available and initialize the Frameworks / LLRP support.
So if you have a connection loss / drop - You may have to refactor the code to be compatible with the LLRP support that the FXR90 provides ( As of FW 3.0.16, and .FW V4.0.4. - as of the posting date of this update.)
