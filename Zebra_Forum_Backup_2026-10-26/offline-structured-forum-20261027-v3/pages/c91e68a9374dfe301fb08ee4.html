Brian, I assume the RFD8500, is connecting as a HID device. When an external HID device is connected, Android will default to that device for Input.

To change that behaviour:
1. Attach the HID device
2. Go to Settings &gt; Language &amp; Input
3. Tap Default
4. Change Hardware Physical Keyboard from On to Off

Now the soft keyboard should popup when an entry field is selected. The Android device should now accept input from the soft keyboard or the external HID device.
