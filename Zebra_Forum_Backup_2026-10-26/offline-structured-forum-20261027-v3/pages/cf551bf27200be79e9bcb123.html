Correct Alex, ( And thank you )

Zebra EMDK / DataWedge - and Embedded RFID - and other technologies (*) - are not "Simulation" capable using the Device Definitions for Android Studio.

To develop for these technologies - you do need to be working/operating with "Actual" Zebra hardware platforms - where this software technology runs upon.

(++ Please Note - the RFD40P / RFD90 devices - bring Bluetooth based - can allow for Google Pixel - or iOS / iPadOS - software development on these "Non-Zebra Device Platforms"  ++) 

(*) Some software depends on Hardware technology that is integrated on the Zebra device, such as the RFID Engine / Dimensioning technologies, and Barcode Scanner / Engine technologies.
