The v2.16.2905 on the NuGet is an updated version of the Link-OS SDK for the .NET Framework 4.7. The API documentation remains unchanged. So the API documentation on the website for the v2.14.1869 is still valid. The engineering team is working on updating the SDK to support the .NET6 MAUI, which will be available in a week or two.
