RemCapture Can be used to find the reg key for the keylight by following the steps bellow.&nbsp; 1. Connect the MC65 to the PC via ActiveSync.&nbsp; 2. Open RemCapture.&nbsp; 3. Click Baseline (+). 4. Go to Settings-&gt;System. 5. Select Backlight &amp; Keylight icon 7. Select Keylight and change the selection and Click OK to save the settings.&nbsp; 8. On RemCapture click Difference (-) Once the difference capturing completed following change will appear with other registry differences.&nbsp; [HKEY_CURRENT_USER\ControlPanel\Keylight] "Keylight" = dword:00000001 - "The value could be different" Make sure that&nbsp;[HKEY_CURRENT_USER\ControlPanel\Keylight] is not in the registry "Exclusions" list
