Can MC9300 only use EMDK for Xamarin

E
Elizabeth Palmer
1 year 8 months ago
203 3
//Expert user has replied. //Solved

I am working on MAUI app for the MC9300 which is using Android 10. My question is if we were to upgrade to using Android 11 would we be able to use an SDK or would we still have to use EMDK for Xamarin? My company is afraid of vulnerabilities since it has the word Xamarin in it.

Thanks!

Hi Elizabeth - MAUI is fully supported by EMDK for Xamarin since March 2023.
You can search for "MAUI" here https://techdocs.zebra.com/emdk-for-xamarin/9-0/guide/about/  and read about the update.

Also, I wrote a blog for that https://developer.zebra.com/blog/developing-net-maui-zebra-androidtm-devices , and a specific page was created to support MAUI developers https://techdocs.zebra.com/emdk-for-xamarin/9-0/guide/maui/  .

Since you mentioned security, it's worth mentioning that Android 14 (and 13) are also available for MC9300, with these two versions getting most of the updates now.
If you prefer to download an A14 OS image, look here https://www.zebra.com/us/en/support-downloads/mobile-computers/handheld/mc9300.html#Tab-item-85dbc8d2f9-tab .

When upgrading to Android 11, you can use both the SDK and EMDK for Xamarin. and in my opinion, EMDK for Xamarin is still necessary if you want to access the special features of Zebra devices.

This detailed update addresses that issue https://techdocs.zebra.com/emdk-for-xamarin[url=https://driftboss3d.io]Drift Boss[/url]/9-0/guide/about/
