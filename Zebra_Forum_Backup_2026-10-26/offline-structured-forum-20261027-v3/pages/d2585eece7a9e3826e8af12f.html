Jon, &nbsp;&nbsp; There is a Motorola specific API (Audio Extension , documented in the EMDK) to switch between the front and rear speakers - this would need to be implemented in the VOIP client in order to redirect audio to the front. You can also switch manually using the attached audiocontrol.exe utility which can be run while the VOIP client is active in order to select the output required. Best Regards, Ian Hatton EMb EMEA
