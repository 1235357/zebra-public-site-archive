Erick, inside the MSP Client Software Guide you can find the following statement on embedded CE:
"Due to the extreme variability that can exist in OEM builds of the Windows CE Operating System, the Windows Device Client is not intended to support non-Motorola (or non-Symbol) Windows CE-based devices."
Only Motorola/Symbol devices with CE4.2, 5.0 and 6.0 are fully supported in MSP. All other embedded CE devices are not. Thomas
