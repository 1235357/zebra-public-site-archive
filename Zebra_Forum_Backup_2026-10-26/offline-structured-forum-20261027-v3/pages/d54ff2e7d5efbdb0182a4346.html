Guy, &nbsp;There are a few options which you could use in this case: MC75A- there is a RS232 cable in the accessory list (25-91518-02R) which is designed for a printer connection but could connect to other RS232 devices MC75A and MC95xx - the standard USB charge/comm cables can be used to connect USB client devices such as an optical probe (for meter reading) , USB to RS232 cable , memory stick etc. To do this, you just need to select USB host mode via the Settings/System/USB Config applet and then connect the USB device via a USB female A to A adaptor&nbsp;such as the one shown at http://www.amazon.co.uk/StarTech-com-Gender-Changer-USB-Female/dp/B0006… &nbsp;&nbsp; If&nbsp;you use the FTDI UC232R-10 cable ( http://www.easysync-ltd.com/product/528/es-u-1001-b10.html) you do not need to install any drivers i.e. drivers are built into the OS. &nbsp; Hope this helps Best Regards, Ian Hatton &nbsp;&nbsp;
