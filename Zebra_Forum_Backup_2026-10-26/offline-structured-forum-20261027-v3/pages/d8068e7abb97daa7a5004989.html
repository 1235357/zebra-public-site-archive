As the lead developer for ERDP, I can answer your question.

ERDP doesn't provide an override for the client name to be configured by the user.  Instead, it uses the device's Serial Number for the client name.

For the purposes of RDP licensing, the client name needs to be unique and shouldn't change.  If the client name changes, a new RDP license from the license server would be required.  

If the RDP license server isn't being used, then this isn't an issue.
