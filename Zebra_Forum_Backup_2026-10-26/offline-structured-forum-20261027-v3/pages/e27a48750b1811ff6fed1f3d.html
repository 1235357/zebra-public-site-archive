You tagged the question with EMDK so presumably you are using EMDK :) You can use the EMDK ProfileManager to "Upgrade" the application which will happen silently.&nbsp; There is a sample app showing this at&nbsp;https://techdocs.zebra.com/emdk-for-android/latest/samples/app-manager/… although only available in Java should show the principles... we also have a tutorial showing how to install an app:&nbsp;https://techdocs.zebra.com/emdk-for-android/8-0/tutorial/tutMxAppManage…;- again it is in Java and you are 'upgrading', not 'installing' the app but the principle is the same.
