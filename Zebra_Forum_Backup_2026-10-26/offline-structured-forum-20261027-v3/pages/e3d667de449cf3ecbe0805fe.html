I'm trying to read the EPC memory bank from an RFID tag, using the DataWedge intent APIs.

I'm building the intent to set the DataWedge profile like this:

private fun createRfidBundle(configuration: ScannerConfiguration, volatileConfiguration: VolatileScannerConfiguration?, scanType: ScanType): Bundle {
   val pattern = volatileConfiguration?.getRfidFilterPattern()
   val filterMemoryBank = volatileConfiguration?.getRfidFilterMemoryBank()
   val enabled = volatileConfiguration?.wantsRfidCapability() == true && pattern.isNullOrBlank().not()
   val session = "2"
   val barcodeParamListBundle = bundleOf(
      "rfid_input_enabled" to if (enabled) "true" else "false",
      "rfid_beeper_enable" to "false",
      "rfid_led_enable" to "false",
      "rfid_session" to session, //Session
      "rfid_tag_read_duration" to "100",
      "rfid_memory_bank" to "4",//Memory bank EPC
      "rfid_antenna_transmit_power" to "30", //5-30dB
      "rfid_filter_duplicate_tags" to "false",
      "rfid_inventory_state" to "2", //inventory flip ab
      "tag_RSSI" to "true",

      //TRIGGER MODE
      "rfid_hardware_trigger_enabled" to when (scanType) {
         ScanType.AUTO   -> "false"
         ScanType.MANUAL -> "true"
      },
      "rfid_trigger_mode" to when (scanType) {
         ScanType.AUTO   -> "1"
         ScanType.MANUAL -> "0"
      },

      //Pre-filters
      "rfid_pre_filter_enable" to if (pattern != null) "true" else "false",
      "rfid_pre_filter_tag_pattern" to pattern,
      "rfid_pre_filter_target" to session, //Session
      "rfid_pre_filter_memory_bank" to when (filterMemoryBank) {
         RfidMemoryBank.EPC  -> "0"
         RfidMemoryBank.TID  -> "1"
         RfidMemoryBank.USER -> "2"
         null                -> "0"
      },
      "rfid_pre_filter_action" to "0",
   )

   return bundleOf(
      "PLUGIN_NAME" to "RFID",
      "RESET_CONFIG" to "false",
      "PARAM_LIST" to barcodeParamListBundle
   )
}

I'm expecting 2 things from this configuration:

  1. the prefilter should filter out tags where the EPC bank doesn't respect the pattern (not required, but nice to have, not the focus of this question)
  2. that I get the content of the EPC memory bank in the Intent I receive


Number 2 is required, and since I'm setting "rfid_memory_bank" to "4" in the bundle I'd expect it to work, but this is all I'm getting in the Intent I receive from DataWedge

action: com.barcodescanner.sample.INCOMING_INTENT_ACTION
data: null
extras:
 Bundle {
  'com.motorolasolutions.emdk.datawedge.source': rfid
  'com.symbol.datawedge.source': rfid
  'com.symbol.datawedge.label_type': E2801190A5030065899DE5EF -25
  'com.motorolasolutions.emdk.datawedge.data_string': E2801190A5030065899DE5EF -25
  'com.symbol.datawedge.data_dispatch_time': 1770651167195
  'com.symbol.datawedge.data_string': E2801190A5030065899DE5EF -25
 }

All I'm receiving is the tag ID (E2801190A5030065899DE5EF) and the RSSI (-25), no EPC in sight.

I'm testing on a MC3300x.

123RFID is able to read the EPC, so I'm guessing there is a way to read it.

How do I read the EPC memory bank using the Intent APIs?

Not sure if the EPC memory is supported in the version of Datawedge on that unit - you can check by creating a new profile in the Datawedge menu , enabling the RFID plugin and then configure the reader.  If there is a Memory Bank option and you can select EPC then you can attach the profile to a test app in order to check that it works. If so, then the issue is likely to be in your DW profile creation code which would either need to be fixed or you could switch to using a pre-installed profile with the settings already configured (assuming you don't need to change the profile dynamically).
