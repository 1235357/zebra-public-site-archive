A networked printer has an embedded mini webserver, which is accessible http://192.168.1.154/index.html. From there, you can navigate to the page where you can make changes to the network settings. A direct link would be&nbsp;http://192.168.1.154/settcpip. (The IP address shown here 191.168.1.145 is just an example). Unfortunately, this embedded mini webserver doesn't provide REST API.
Another way to change the IP address on the printer is via SGD commands of ip.addr. Here is an example. Of course, the DHCP needs to be disabled on the printer.

// Set IP address to 192.168.1.154 as an example
! U1 setvar "ip.addr" "192.168.1.154"

// Reset the printer for the new IP to take effect
! U1 setvar "device.reset" ""
