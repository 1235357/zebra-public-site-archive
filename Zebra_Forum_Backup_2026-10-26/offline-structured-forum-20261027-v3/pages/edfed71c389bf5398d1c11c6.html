Hello Horst,

i am not sure if you are aware of the following&nbsp; but judging from the video it looks the&nbsp; PTT key was pressed just too long on the unit, so that the first option of recovery mode was selected once releasing the key.

see CQ&nbsp; SR EMBPD00172860 [F][3] - BETA TC75 MV Recovery Mode&nbsp; Release PTT button invokes 1st menu selection
BETA TC75 MV Recovery Mode&nbsp; Release PTT button invokes 1st menu selection

when using MV unit and putting the device into recovery mode

reboot and hold PTT button.

when device is booted into recoverymode and you release the PTT button it invokes the first menu option ( in this case reboot device )

so that makes it very difficult to bring device into recoverymode as you need to time your PTT Release very good.

on DV unit this issue is not happening most likely due to the Key changes done during the dev phase.
