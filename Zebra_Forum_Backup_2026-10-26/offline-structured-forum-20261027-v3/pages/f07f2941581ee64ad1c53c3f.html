Ok simple answer to this but probably what you want to hear. No they're not compatible in any way, those sdk files are for i-series printers that the ZXP range superseded.

The only SDK's that work for the ZXP 7 are the zmotif and linkos which in turn do not work for the i-series.

To my knowledge there is no way to get usb emulator to work, it broke with the release of windows 10 and although there was a new release to allow ZC350 emulation it didn't fix the usb problem but if I'm wrong I'd love to know how to get it work as well.
