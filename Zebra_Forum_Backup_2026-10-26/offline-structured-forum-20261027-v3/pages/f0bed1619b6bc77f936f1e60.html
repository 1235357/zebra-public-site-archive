Dino, &nbsp;The EMDK for Java includes pre-built CAB files for the sample apps so you can easily test the EMDK samples as follows: a) install Creme JVM (free download from www.nsicom.com) b) install Moto EMDK for Java support ( symbol.java.arm.cab ) c) install Moto EMDK for Java samples ( symbol.jsamples.arm.cab ) &nbsp; The samples can then be run from Samples.Java in Programs. Best Regards, Ian Hatton MSI EMEA
