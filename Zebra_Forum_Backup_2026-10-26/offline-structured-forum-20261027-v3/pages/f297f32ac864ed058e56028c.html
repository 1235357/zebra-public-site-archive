Issue with Zebra RFID Reader SDK for Android. eventStatusNotify – ClassCastException during Trigger Events on MC3300x

Device: MC3300x

Android Version: 11

Zebra RFID Reader SDK Version: 2.0.5.238

Description: I am encountering an issue where the eventStatusNotify callback is not triggered when the mapped physical trigger is pressed or released. Based on Logcat analysis, the SDK seems to encounter a casting error internally when a trigger event occurs. 

Specifically, it appears that the SDK is attempting an invalid cast, which prevents the event from being dispatched to my application.

I enabled IRFIDLogger's debug logs and i got these:

Logcat snippet when eventStatusNotify doesn't get triggered in my app: 

IRfidserviceImp D ON_KEY_EVENT KEYCODE = 102 STATE = 1
IRFIDinfo D API3SystemService: broadcast: TRIGGERScom.symbol.button.L1
IRFIDinfo D ASCIIHelper: GetReplyDetails =Notification:TriggerEvent,TriggerValue:1lastResponse = null
IRFIDinfo D RFIDASCIIProcessor: getReplyMsg = Notification:TriggerEvent,TriggerValue:1
IRFIDinfo D TransportSerial: Data from Reader : << Notification:TriggerEvent,TriggerValue:1
IRFIDinfo D parseMsg RFIDASCIIProcessor: replyType = NOTIFY IRFIDinfo D GetReplyDetails Notification:TriggerEvent,TriggerValue:1 msg.getMsgType NOTIFICATION
IRFIDinfo D Notification_TriggerEvent TRIGGER_RELEASE
IRFIDinfo D com.zebra.ASCII_SDK.ENUM_TRIGGER_TYPE cannot be cast to com.zebra.rfid.api3.RFID_EVENT_TYPE

Logcat snippet when eventStatusNotify does get triggered in my app:

IRfidserviceImp D ON_KEY_EVENT KEYCODE = 102 STATE = 1
IRFIDinfo D API3SystemService: broadcast: TRIGGERScom.symbol.button.L1
IRFIDinfo D TransportSerial: Data from Reader : << Notification:TriggerEvent,TriggerValue:1
IRFIDinfo D ASCIIHelper: GetReplyDetails =Notification:TriggerEvent,TriggerValue:1lastResponse = null
IRFIDinfo D RFIDASCIIProcessor: getReplyMsg = Notification:TriggerEvent,TriggerValue:1
IRFIDinfo D parseMsg RFIDASCIIProcessor: replyType = NOTIFY
IRFIDinfo D GetReplyDetails Notification:TriggerEvent,TriggerValue:1 msg.getMsgType NOTIFICATION IRFIDinfo D Notification_TriggerEvent TRIGGER_RELEASE
IRFIDinfo D eventType value : 12 IRFIDinfo D WaitForEventNotification IRFIDinfo D GetEventData result : RFID_API_SUCCESS eventType HANDHELD_TRIGGER_EVENT RFIDHandler I Status Notification: HANDHELD_TRIGGER_EVENT
RFIDHandler I Rfid Trigger released
RFIDHandler D stopReading: entry

I think that because of this `ClassCastException` within the SDK's internal notification handling, my implementation of `eventStatusNotify` never receives the event. 

Note: This behavior is intermittent. The application works as expected sometimes, but once this error occurs, the eventStatusNotify stops receiving trigger events correctly and becomes unreliable.

I can provide more detailed logs / code snippets or additional information if needed.

I would be grateful for any help,

Thanks.
