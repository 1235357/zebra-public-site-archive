Hi Yusuf,
You want to set up the printer driver as a shared printer.
Then you change the discovery code to:
foreach (DiscoveredPrinterDriver printer in UsbDiscoverer.GetZebraDriverPrinters())You should be able to then use that with shared printers.&nbsp;
It is slower than direct USB connections though.
Hope this helps, Robin
