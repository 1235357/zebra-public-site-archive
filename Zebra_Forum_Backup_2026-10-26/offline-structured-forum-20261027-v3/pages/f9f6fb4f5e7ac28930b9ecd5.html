Hi Deyab,
For this situation, you should definitely use ZPL.
The reason is that: 
ZPL is the printer's native language, so it prints almost instantly. A PDF has to be processed by the printer first, which is much slower and not ideal for a fast-paced workflow.
ZPL gives you a perfect, crisp barcode every time. With PDF, you risk generating a low-quality barcode that won't scan properly, and might also not align the borders well, which would be a major problem for your customer.

Since you might be new to ZPL, here are a couple of great ways to get the code for your label template:

  1. Use ZebraDesigner:
    • Download the free ZebraDesigner software onto a Windows computer using this link (ZebraDesigner for developers).
    • Visually design your label by dragging and dropping the fields you need.
    • Go to File -> Print and check the "Print to file" box. This saves a file containing the exact ZPL code for your design. You can then use this as a template in your app.
  2. Use an Online Viewer for Testing:
    • You can use this link to check the preview of the designed label: Labelary.
    • You can paste ZPL code there to instantly see a preview of your label. It's perfect for quickly testing and tweaking your code without needing to print a physical label every time.

Using ZPL is the professional standard for this task and will give you a much more robust solution. 
I hope this helps you!
