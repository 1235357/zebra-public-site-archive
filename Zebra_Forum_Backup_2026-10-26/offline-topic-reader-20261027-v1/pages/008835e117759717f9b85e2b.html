            The SendFileToPrinter API is platform and language agnostic, as it's a REST API. It can be used to build a Web App, mobile app or laptop based app for Windows or Mac (e.g., .NET or Objective-C, etc.). The demo app (Print From the Cloud Demo) on the GitHub is an example using the JavaScript. It can be downloaded and hosted on a PC as a Web App, then print from the PC.
The ZebraDesigner label design tool doesn't support the cloud printing. But it does support printing on the network connected printers. When installing the driver for the ZebraDesigner, you can specify for the USB connected printers or the network connected printers.
