I'm a developer new to the Zebra SDK. I read the Developer Guide document, watched videos and made sample applications.

What is required of me is software development for Zebra LI4278 Barcode Scanner and Zebra ZD421 Label Printer devices.

I don't have the devices. In a location far from me, out of my reach. I am doing remote application development. That's why I'm going to buy these devices in my own country and develop applications.

Devices are expensive. I aim to buy more economical devices for application development. But it should work compatible with the devices I have given information about. So that's what I want to ask. What are the more economical devices that are compatible with the same generation as the devices whose product details I have given below?

Full product code information of devices;
Label printer:  Zebra ZD421, connected via USB-cable (Zebra part# ZD4A043-30EM00EZ)
1D barcode scanner:  Zebra LI4278 cordless scanner (Zebra part# LI4278-TRBU0100ZER)
Labels: 102 mm x 102 mm

            Both ZD220 and ZD421 support the ZPL label format language. The label designed in ZPL for the ZD220 should work for the ZD421, but with different scale. As you've already pointed out, the printhead resolution of the ZD220 is 203dpi, while 300dpi for the ZD421. Because of the different resolutions, you will need to do the final adjustment when move from the ZD220 to ZD421. If you use the ZebraDesigner for Developer tool to design the label, it will be very simple and straight forward for making the adjustment with the tool when moving from one printer model to another.

            The ZD421 is a Link-OS printer, while the ZD220 is a Link-OS Basic printer. If your application doesn't use the cloud-based printing, then you can use the ZD220 as a substitute for development. If your application requires the printer connection via the websocket (or weblink), then you need a Link-OS printer.
