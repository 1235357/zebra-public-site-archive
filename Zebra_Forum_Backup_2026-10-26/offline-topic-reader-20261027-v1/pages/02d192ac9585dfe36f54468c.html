            Why would you need to create a .nlbl file if you already have the ZPL file for the label? A .nlbl file is a file format for the ZebraDesigner tool.  The ZebraDesigner is a tool to provide a graphic user interface to help developers creating labels. If you already have the label in ZPL, it doesn't make sense to reverse engineer a .nlbl file.

            Unfortunately, there is no tool to convert a ZPL file into a *.nlbl file. You will need to redraw the label in the ZebraDesigner to get the .nlbl file.
