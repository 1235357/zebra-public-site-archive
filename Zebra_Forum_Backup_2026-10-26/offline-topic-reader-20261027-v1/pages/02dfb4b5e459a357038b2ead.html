                  Hello,I am using an RFD4031 Premium + (RFID reader + barcode scanner). I want to operate by code (.NET) the barcode reader on Win10 + Win11. I have used CoreScanner previously on RFD90 with the same goal with no problems. Now with this RFD40 it does not work at all !I have tried multiples things. For my client I need to use the RFD40 SAAFKS00-013-R02E0 firmware. I tried using CoreScanner SDK 3.07.0012 with 3.08.0019 core scanner driver. Result : the scanner of the RFD is not detected/discovered. So I switched back to core scanner driver 3.07.0028 with same SDK. This version detects the scanner. When I press the trigger or simulate it, the barcode lights up, read a barcode but the barcode is not sent back to the app. I tried with the SDK C# App, C++ App, the sample app on GitHub and my tests app and none of them where able to get the barcode read. I checked the code and the register command (1001) is successful.To me it seems that there are several problems, first with the latest core scanner driver that ignores the reader and second with the callback mecanism that does not work. The RFD90 that was working well, now has the same problem. The only meaningful thing I did was to upgrade the SDK. I can't test with a previous SDK as they are available (I did not make a copy of it).My questions are : Is this normal that the barcode reader is not detected any more with the latest driver ? If yes then how can I drive the barcode from C# code.Thanks for your help. Regards.
