            Example using pillow and zplgrf (a Python library for converting images to ZPL):from PIL import Imageimport zplgrf# Open the imageimage = Image.open("label.png")# Convert to monochrome (1-bit pixels, black and white)image = image.convert("1")# Generate ZPLzpl = zplgrf.image_to_zpl(image)# Save ZPL to a file or send it directly to the printerwith open("label.zpl", "w") as file:   file.write(zpl)
