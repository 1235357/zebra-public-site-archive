            Thanks Dave.   The other link doesnt mention that -   http://msdn.microsoft.com/en-us/library/ms880955.aspx   
Port : REG_DWORD
Default setting is 80. This port receives HTTP connections. Do not set the port to zero (0). When the Web Server is running from Services.exe, which is the default, this value is ignored and Services.exe becomes the super server.
  From this&nbsp;I suppose that web server on our terminals is running from Services.exe so the port cannot be changed with registry.   E.g. Local page of Datawedge is using different port than 80. When you launch&nbsp;Datwedge then&nbsp;in IE you can see the following -   http://localhost:48873/dwui/index.html   But the port is changed programatically with application dwhttpd.exe and not with registry.   So I will write to customer that the port can be changed programatically - Registering a Super Service Programmatically -&gt;   http://msdn.microsoft.com/en-us/library/ms938090.aspx   Thanks  Milan
