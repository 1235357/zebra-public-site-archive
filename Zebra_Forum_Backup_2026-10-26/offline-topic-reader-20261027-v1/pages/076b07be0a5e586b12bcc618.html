            Christian,   I created an MC75 golden image for a customer that needed to updated the HC25 modem firmware if required.&nbsp; I was able to automate it using SymScript to run the HSDPAConfigInfo utility and then parse through the ConfigInfo.log file generated by the utility to determine the firmware version.&nbsp; The value captured by this process can be stored in the device's registry so it can be reported back to MSP.&nbsp; MSP can then make the determination if the modem firmware needs to be updated.&nbsp; Attached is a script that should do it.   Thanks,  Ken
