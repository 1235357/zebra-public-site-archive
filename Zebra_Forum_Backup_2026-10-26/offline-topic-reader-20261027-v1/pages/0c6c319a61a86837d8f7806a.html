            Hi Jon,  The default input method is kept here [HKEY_CURRENT_USER\ControlPanel\Sip] "DefaultIm"="{42429667-ae04-11d0-a4f8-00aa00a749b9}"  The value is the input method class ID. By default it's set for "Keyboard" IM class. By searching for "IsSIPInputMethod" in registry you will find all the SIP input methods classes and the class for "Transcriber" on my MC75 is&nbsp;{F0034DD0-2AD4-11d1-9CB0-E84BE8000000}  So the registry settings to make transcriber as a default IM will be [HKEY_CURRENT_USER\ControlPanel\Sip] "DefaultIm"="{F0034DD0-2AD4-11d1-9CB0-E84BE8000000}"  Regards, Valery .
