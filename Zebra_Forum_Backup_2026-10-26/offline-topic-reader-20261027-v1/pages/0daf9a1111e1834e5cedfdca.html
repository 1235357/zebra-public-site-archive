            Hi Smith,From your description, it looks like you’re trying to use a locally installed Windows printer (added via network IP) and send print jobs through the Windows print queue instead of communicating directly with the printer using the Zebra SDK.Currently, this scenario is not supported by the Zebra SDK. The DriverPrinterConnection in the SDK is designed to work with printers connected via USB, and creating a printer instance using a local Windows printer queue is not supported.The SDK primarily supports direct communication with the printer (e.g., using IP/port), which is why it operates synchronously (send command → wait for response).Could you please confirm if this matches your use case? Based on that, we can explore possible alternatives.Regards,Shreyas Purohit
