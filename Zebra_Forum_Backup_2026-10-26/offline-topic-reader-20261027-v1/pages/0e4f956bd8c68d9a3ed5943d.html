            If I'm understanding correctly, you just want to print over the network from an application you're writing? The simplest way to print over the network is to just send label data to port 9100 TCP on the printer. Another option is to print via HTTP Post: Link-OS Demos - Zebra Technologies TechDocs If you want to print a PDF, you need to enable PDF direct on the printer: https://supportcommunity.zebra.com/s/article/000014538
