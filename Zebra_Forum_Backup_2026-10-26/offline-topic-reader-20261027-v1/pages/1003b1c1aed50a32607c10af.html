            Hello Yildirim.

The Sample code for the XCODE SDK is Objective-C at this time.  There is no Swift version of this code available.

An as-is suggestion, is there are online Objective-C to Swift conversion applications / tools, and you can investigate this at your leisure - but if you run into an issue, you will need to reproduce the fault on Objective-C XCODE,  or you may encounter Support limits for Supported Development environments as a result.
