            Hi,
It is not possible to extract an image of the barcode from the TC25 imager (scanner).
To send the barcodes as text strings you have a couple of options:
- Use the DataWedge IP output plugin (https://techdocs.zebra.com/datawedge/8-0/guide/output/ip/) to send the data to an IP address. &nbsp;Although that is designed to be used on conjunctions with a desktop tool to place the scan data in the clipboard or output as keystrokes.
- Write a custom app to upload the barcode data as required. &nbsp;I have never tried to write data to a network folder from Android but I guess it must be possible.
