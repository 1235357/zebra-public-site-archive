If the application is loaded stand alone it works, but there are issues when using AppCenter (and maybe SymScript…but I am sure that they are not using that because it is not supported…) According to Support AppCenter is English only. Are any of you using a locking program that would support global languages? (AppCenter does not recognize the directory structure of other languages.)
