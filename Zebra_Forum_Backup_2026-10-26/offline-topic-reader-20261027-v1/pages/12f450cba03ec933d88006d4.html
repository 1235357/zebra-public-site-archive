            I concur with Alex.Using 123RFID Mobile - with up-to-date version - and the RFD40 with at least "SAAFKS00-008-R01" Reader firmware or higher operating on this sled.In 123RFID Mobile (iOS) find the EPC of the target Tag. highlight it. Goto Access Tab (*bottom of Inventory UI*)In the Access Menu - switch to USER memory Bank.Offset - set to 160 from default 0.  Length --> Set to 2 words.Click read.Then change the offset = 170  <same length>Click read.Then change the offset = 175  <same length>    // this is approaching the "19h"Click read.Then change the offset = 177  <same length>    /this should be the 18th and 19th wordsClick read.Note the times it takes to read these succession of blocks it should be the same amount of time.Please let us know what you encounter.
