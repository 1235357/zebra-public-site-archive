            There are two areas to look at. 
Label length calibration. If we have not done so, we can use the keypad on OLn420 to get to the Label Length Calibration (Home-&gt;Tools-&gt;Label Length Cal). The calibration should fix this problem.
Does SAP Smartform overrides the label length? Usually, the SAP software should get the label length from the printer. In some rare cases, the software could override the label length. Check if that's the case.
