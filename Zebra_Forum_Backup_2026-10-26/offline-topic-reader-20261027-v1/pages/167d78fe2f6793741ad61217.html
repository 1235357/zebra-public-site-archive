                  I have working Android code to create a profile in DataWedge, that correctly reads and reports 2D barcode scans back to my application, so I have a working base. I'm now adding RFID reading, in particular I need to search for a pattern and receive updates on the RSSI for that tag (so that I can show it in our app UI). I'm facing 2 problems:I can't find the correct string to use in the bundle for RSSI reporting. I found out it is saved as "tag_RSSI" in DataWedge, but it doesn't set it in DataWedge when used with the setConfig intentI can't find documentation on how to receive this data (with RSSI) via the Intent Output (which I have working for barcode scanning)This is the code I have to create the RFID bundle private fun createRfidBundle(configuration: ScannerConfiguration): Bundle {
val pattern = configuration?.getRfidPattern()
val enabled = configuration?.wantsRfidCapability() == true && pattern.isNullOrBlank().not()
val barcodeParamListBundle = bundleOf(
"rfid_input_enabled" to if (enabled) "true" else "false",
"rfid_beeper_enable" to "true",
"rfid_led_enable" to "true",
"rfid_session" to "1",
"rfid_antenna_transmit_power" to 30,
"rfid_hardware_trigger_enabled" to "true",
"rfid_trigger_mode" to "0",
"rfid_filter_duplicate_tags" to "false",
"rfid_pre_filter_enable" to "true",
"rfid_pre_filter_tag_pattern" to pattern,
"rfid_pre_filter_target" to 1, //Session 1
"rfid_pre_filter_memory_bank" to 4, //Memory bank EPC
"rfid_pre_filter_action" to 0,
"rfid_post_filter_rssi" to -100,
"tag_RSSI" to true
)
 
return bundleOf(
"PLUGIN_NAME" to "RFID",
"RESET_CONFIG" to "true",
"PARAM_LIST" to barcodeParamListBundle
)
}

            hi there: 1/ rfid_enable_tag_rssi: This parameter is specifically used to include RSSI (signal strength) information for each tag read. Setting it to "true" ensures that the RSSI values will be appended to the tag data output.Other Parameters: The remaining parameters (rfid_input_enabled, rfid_enable_hardware_trigger, and rfid_enable_antenna) remain as before to enable RFID input and ensure proper operation of the RFID scanner.Expected OutputWhen a tag is scanned, the output will include the following information:Tag Data: The unique identifier of the tag (e.g., EPC or TID).RSSI Value: The signal strength of the tag read. This is typically a negative value (e.g., -65 dBm), where a higher absolute value indicates a weaker signal.2/ not a specialist but maybe a path below:@Overrideprotected void onNewIntent(Intent intent) {   super.onNewIntent(intent);   if ("com.example.rfid.DATA_CAPTURED".equals(intent.getAction())) {       String tagData = intent.getStringExtra("com.symbol.datawedge.data_string");       String rssi = intent.getStringExtra("com.symbol.datawedge.data_rssi"); // Check if RSSI is included       Log.d("RFID", "Tag Data: " + tagData);       Log.d("RFID", "RSSI: " + rssi);   }}
