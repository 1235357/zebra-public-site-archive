            Hi Cemgiz,
Yes it is possible to use datawedge get information from the RFID readers and send to the outputs methods of datawedge (Keyboard, Serial, IP etc)
For this you need to install the RFID Plugin :
https://portal.motorolasolutions.com/Support/US-EN/Resolution?solutionI…… 
After install it you need to configure the RFID parameters.
