            Brian,   &nbsp;The key remap tool included in Rev A1 is not enabled on the Numeric keypad config for some reason. We have been able to remap keys using a third party utility
(AEKMap) which&nbsp;can be used in Freeware mode e.g for&nbsp;the function key remapping of the numeric keypad. The attached files demonstrate remapping of F1 to F10 to A through J and can be installed by unzipping to \Application and then clean booting the unit ( which must be running BSP 30). To change the remap to something else, you just need to edit the Simple Sample.AEK file ,change the character codes at the end of the file and then reboot the unit to make it effective.
