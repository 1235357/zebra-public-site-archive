                  We have tried to submit an app to the Apple App Store that includes a version of the Link-OS iOS ZSDK_API.xcframework but Apple will not accept the build.Apple gives us the following error:ERROR: [altool.600001D4C1C0] [ContentDelivery.Uploader.600001D4C1C0] Validation failed (409) Invalid bundle structure. The “.app/Frameworks/ZSDK_API.a” binary file is not permitted. Your app cannot contain standalone executables or libraries, other than a valid CFBundleExecutable of supported bundles.             Hi Christopher,The error msg shows the current issue is that the ZSDK_API.a file should not be included in the Framework folder of the project. Please move the ZSDK_API.a file to a lib folder in the Xcode project.Please make the changes as suggested and resubmit your app.
