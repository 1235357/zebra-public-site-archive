            There seems a confusion about the emulation term used here. The emulations referred to by the link above are not about the emulation of the printer. Instead they are the emulation of the other label formatting languages. The Zebra printers normally support the label formatting languages of ZPL, CPCL, EPL, etc. If a label is designed with another formatting language that is not supported natively on the Zebra printers, then we can take the advantage of the emulation of the label formatting language. For example, if a label is designed with the Datamax formatting language, then we need to install the emulation of the Datamax on to a Zebra printer, so that the label can be printed on the Zebra printer. The *.NRD files are not for the Windows or Mac. They are the files of the emulations for the printers and should be install on the printers.
