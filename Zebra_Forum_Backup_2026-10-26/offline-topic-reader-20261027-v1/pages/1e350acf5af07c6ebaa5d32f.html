                  Hi,
We've been using Zebra TC56 devices with our Xamarin application for a good while now with great success. However, we now have some TC57 devices and these do not behave in the same way. To explain:
We allow the user to scan an item (using Android intents) and whilst processing is done the scanner is switched off (again using Intents). The scanner is re-enabled when the app is ready for processing again.
There are scenarios where rapid scanning is required and the processing is immediate. On the TC56 it is possible to scan the first barcode and then immediately scan the next. On the TC57 there is a noticeable delay in the scanner re-arming which pretty much halves the scan speed capability.
We're controlling the scanner on both devices in the same way, should we be doing something different on the TC57? Is this a hardware limitation? Any suggestions welcome.
Thanks
Phil
