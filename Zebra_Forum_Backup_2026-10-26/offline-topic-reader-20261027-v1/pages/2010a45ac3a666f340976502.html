            Ken,  There is a registry key defining the default input method. It looks like the following  [HKEY_CURRENT_USER\ControlPanel\Sip] "DefaultIm"="{42429667-ae04-11d0-a4f8-00aa00a749b9}"  where DefaultIm points to the SIP class ID. Setting it to "" will effectively disable the default SIP and if you haven't installed any other SIPs then you're done.  Not sure whether it's supported method or not though - but it works.  Valery
