            Harry,   I have a customer using SymScript to automate PEAP UserID and Password entry into their Fusion profile.&nbsp; An unconfigured device will prompt the user (typically an IT administrator) with the device ID to assign.&nbsp; The device ID is combined with a prefix to come up with the PEAP UserID (i.e. CHICAGO + 123 = 'CHICAGO123' for the UserID).&nbsp; The customer uses the same password for all user ID's at a particular location, but that can be modified if needed.&nbsp; The script then starts up the Fusion Profile editor, disables the keyboard and touchscreen to prevent the user from messing things up, and then steps through the Fusion profile making modifications to the UserID and Password fields.&nbsp; The script then walks through the Fusion option to Export the profile.   It's been pretty foolproof so far.&nbsp; We just need to make sure we retest if we update the Fusion drivers since the script uses keystrokes (i.e. up arrow, down arrow, Tab, Enter, etc.) to navigate through the Fusion screens and sometimes new Fusion versions change things around.   Ken
