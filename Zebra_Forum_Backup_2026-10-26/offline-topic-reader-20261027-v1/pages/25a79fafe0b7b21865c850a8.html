            Don,
&nbsp; There is a freeform template included with Simulscan called 'Default - DocCap+Optional Barcode.xml'. If you select this in the Simulscan demo app, you can test document capture of a full A4 size page and view the resulting image on the screen of the device. To use this for a customer app, the easiest way would be to modify the EMDK SimulScan1 sample to select this template and save the resulting image as a PNG/JPG file.
