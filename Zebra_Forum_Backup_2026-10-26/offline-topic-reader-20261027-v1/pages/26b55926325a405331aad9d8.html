                  When we try to apply a license on our MC3200 we get the error message "Registration Failed – Company name does not match the registration code".  Does anyone know what this means?  The message only appears if we attempt a manual registration with either a device specific license or a company deployment license.  If we try loading via a .REG file we don't get the error message however the license is still rejected.

            Problem solved.&nbsp; We finally got an answer from the support team out of the USA and the answer is the company name was too long.&nbsp; I'm not sure what the length limit is for this but if you have the same problem try shortening the name of the company.
