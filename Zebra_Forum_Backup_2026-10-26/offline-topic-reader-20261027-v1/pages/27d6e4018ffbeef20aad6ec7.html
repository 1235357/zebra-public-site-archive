            Chris, is it possible you have more than one Android SDK installed on your PC? Check to ensure that both EMDK and Android Studio are pointing to the same SDK.
Run SDK Manager through Studio and take note of the path from which SDK manager was launched. Then with FileExplorer navigate to that area and drop into the add-ons sub-folder. You should see the 2 EMDK libraries.
