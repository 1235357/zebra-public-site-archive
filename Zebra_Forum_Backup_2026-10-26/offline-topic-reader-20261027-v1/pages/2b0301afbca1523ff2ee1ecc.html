            LilyPad Mobile Warehouse is a web application. To print a label from the LilyPad Mobile Warehouse, you would need to ask LilyPad to add the label print feature in their web application. There are two ways to integrate the ZQ520 with a web app. They can either use the cloud-based SendFileToPrinter API to print with the ZQ520, or use the Browser Print on Android to print with the ZQ520.
