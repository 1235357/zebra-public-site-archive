We recently began targeting the TC22R, only to find that the Zebra Xamarin RFID SDK (v2.0.1.116) does not support this newer hardware.While we plan to migrate to Android Studio eventually, the complexity of our current feature set makes that a long-term project. In the interim, we are attempting to create a Xamarin Android Binding using the latest Zebra RFID SDK for Android (v2.0.5.238) .aar files.We successfully compiled the DLL in VS 2022. However, when swapping this new DLL into the Zebra sample project, we encountered the compilation error and we did many attempts to fix it with help of AI and still not working. We are currently stuck at the error mesage below. Has anyone successfully navigated this binding process for the TC22R, or is there a known workaround for supporting the newer units within Xamarin?             Quick FYI - Because Xamarin Product is no longer supported by Microsoft- it is also likewise not supported by Zebra.I have encountered other (external developers) who have successfully used the RFID SDK for Android Studio - library quite to make a Xamarin support stub module - but this is also very unique to those partners and is supported "as-is" where if an issue is encountered and the RFID SDK for Android Studio - demonstrates the same fault- the issue is resolved in the Android Studio RFID SDK - or for the Device / Platform Specific Firmware for the RFID Module Used.I do apologize - but the above error - is likely due to AI - based solutions attempting to configure a Binding Library with an incomplete supporting definition method - that is unique and likely specific to the AI output. As such - from the above - there is likely missing information for the required API definition - that is resulting the NULL parameter binding compilation error.I would at this time - highly recommend either using the RFID SDK for Android Studio in native format - or using the MAUI RFID SDK for Android - as an alternative.  Since the Xamarin Platform overall is no longer supported and why that library stopped at V2.0.1.116 in the past.
