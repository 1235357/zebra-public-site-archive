            Hello, so after a lot of attempts I think it should now work so that you can integrate the TID as a serial number into the SGTIN-96:"${^SLT" + chr$(13) +"^RB96,8,3,3,24,20,38^FS" + chr$(13) + "^RFW,E^RU^FH\^CI28^FD48,1,5," + Left$(@MeinBarcode,7,False) + "," + Right$(@MeinBarcode,6,False) + ",#S^CI27^FS}$" Best regardsStefan

            Here is an example ZPL to read the TID from the tag, create a serial number based on the tag type, write serial number to the 96-bit EPC field, and print the serial number (in hex format) onthe label. Copied from the RFID Programming Guide 3.
^XA
^RU
^FO10,10^A0N,50,50^FDSerial Number: #H^FS
^RFW,H^FD12#H^FS
^XZ
