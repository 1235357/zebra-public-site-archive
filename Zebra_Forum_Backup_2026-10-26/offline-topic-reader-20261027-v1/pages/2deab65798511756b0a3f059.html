            There are a few ways to print the labels (or RFID tags) with the ZD500R printers.
1. Use Zebra's Print Station, an Android app available on Google Play. It's a template based print app. You can create RFID label as a template and store the template on an Android device. Instead of sending the whole text file to the printer, the Print Station enables you to just input the values for the variables.
2. Use Zebra's PrintConnect, also an Android app available on Google Play. It's a template based print solution for the 3rd party apps. You would need to create your own app to communicate with the PrintConnect app via the Android intents.
3. Use the SendFileToPrinter API, which can send the entire text file of the RFID label to the ZD500R printer that is connected to Zebra cloud. With this option, you would need to create your own application.
4. The last option is to use the Link-OS Multiplatform SDK. Again, you need to create your own application.
