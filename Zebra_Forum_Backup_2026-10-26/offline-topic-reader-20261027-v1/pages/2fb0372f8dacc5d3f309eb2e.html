                  Hello, I am developing an Android application that runs on a TC26/RFD40 RFID reader.             The region codes do follow the ISO standard for country codes but the codes returned by the reader query API will vary depending upon the hardware  i.e. the EMEA model does not return USA or China country codes as there are specific models required for use in those countries as follows:
USA: RFD4030-G00B700-US
China: RFD4030-G00B700-WR

            Another Method - to review is the way 123RFID Mobile app for Android - does the Region Code setup.The 123RFID Mobile app - enumerates the connected RFD40 / RFD90 (and RFD8500) for the Region Codes that specific RFD sled supports.Please Note - there are several SKU's for the RFD platforms sleds.  The Part Number ending in -E8 for example has the ETSI supported EU region setups.  The Part Number ending in -US are the FCC Complaint region setup. The Part Number ending in -WR are the 900Mhz Worldwide compliant RFD Sleds.Each when queried will return different values - and from these values you need to choose the correct setting for the Country of Operation.  Please choose both the SKU and the Setup for the correct operation.
