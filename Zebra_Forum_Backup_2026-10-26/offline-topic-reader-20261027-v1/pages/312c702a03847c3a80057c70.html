When I type some keys from the keyboard, such as numbers or letters, they register on the remote server. However, when I press function keys, they do not work. How can I enable those keys for RDP?

            The default keycode mapping of the function keys on the MC3300 probably is not matching the keycodes expected in the app on the host side so you may need to either:
a) use a different RDP client which allows Function keys to be selected via a popup on-screen keyboard 
b) try redefining the keycodes generated on the MC3300 using the Mx Key MappingMgr : https://techdocs.zebra.com/mx/keymappingmgr/
