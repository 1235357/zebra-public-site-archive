            Hello,
You are using the wrong SDK for the ZXP-7 Card Printer. The SDK you are using is for the ZC-series Card Printers. You will need to return to www.zebra.com, navigate to the Support and Download page and navigate through the links to the SDK download package for the ZXP-series card printer. The easiest path to do this would be to start with the printer itself, then select software and drill down to the development tools section to locate the ZMotif SDKs installer.
