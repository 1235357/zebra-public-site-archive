            There are no standard desktop emulators for Windows CE5 devices for the VS2005/VS2008 development environments like there are for Windows Mobile.
This is because Windows Mobile builds are standard and every build must contain the same components. Windows CE builds and the associated components vary from manufacturer to manufacturer and may vary even with the same vendor.
There are a few methods to still provide Windows CE5 desktop emulators.&nbsp; See the attached doc I created in 2011 to see if it helps you at all.
