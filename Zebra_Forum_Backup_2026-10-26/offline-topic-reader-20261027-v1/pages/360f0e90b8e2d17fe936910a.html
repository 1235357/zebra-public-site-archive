            Hi,
FxConnect can only send tag data to a host or local device - it does not provide any remote management functionality.  As an alternative you could look at using the RFID Cloud Connect API (https://developer.zebra.com/apis/rfid-reader-management#/) to control GPIO ports remotely without requiring a dedicated server
