            Hello again! I have solved this case by performing the following steps:1. Download Zebra 123Scan Utility.2. Create an ADF Rule:3. Generate/read the code with the DS3608. Includes the following actions: Set factory defaults/Erase all Rules/Replace GS by Equals character 4. Read the code with the DS3608 Add an Enter Key (Carriage Return/Line Feed) after scanned data:Once the above has been done, I obtain the required result!Best regards,
