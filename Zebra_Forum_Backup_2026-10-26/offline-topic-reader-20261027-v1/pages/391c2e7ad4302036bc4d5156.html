            In the log, you have configured the printer to send out alerts on ALL MESSAGE, including the BASIC RUNTIME events.
{"alerts.configured":"COLD START,SNMP,Y,N,255.255.255.255,162,N,|ALL MESSAGES,BLUETOOTH,Y,Y,,0,N,"}The BASIC RUNTIME events are&nbsp;from ZBI (Zebra Basic Interpreter). You may have a ZBI program running, which generates this event. To stop this, you need to reconfigure the alerts. Instead of using ALL MESSAGES, you can specify the specific alert conditions you want to monitor. Or, you can try to stop the ZBI program&nbsp;from running.
Alternatively, you can try ^SQ command in ZPL to stop the BASIC RUNTIME events.
