With a MC3190 CE  with 1x battery: under Start -> Settings -> Control Panel -> Power Icon -> RunTime tab,  there are 3 options (Option 3 Normal, Option 2 Less, and Option 1 Minimum).
   
For Option 3: at what main battery percentage does the device do a critical suspend?
Also for Option 3: once the device has done a critical suspend how long does the combination of the main battery and backup battery keep memory viable?
   
For Option 2: at what main battery percentage does the device do a critical suspend?
Also for Option 2: once the device has done a critical suspend how long does the combination of the main battery and backup battery keep memory viable?
   
For Option 1: at what main battery percentage does the device do a critical suspend?
Also for Option 1: once the device has done a critical suspend how long does the combination of the main battery and backup battery keep memory viable?
