            Datawedge does not support sending function keys so I don't think you will be able to do this although you could experiment with the non-printable character output option in ADF which allows non-printable characters to be defined in the format \xNN (hex) and \uNNNN (unicode) : https://techdocs.zebra.com/datawedge/latest/guide/process/adf/
