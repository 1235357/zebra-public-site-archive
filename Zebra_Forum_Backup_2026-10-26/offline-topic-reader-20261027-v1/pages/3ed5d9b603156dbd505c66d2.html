                  RFID SDK for android in java for zebra MC33 device has been integrated successfully but couldn't able to Get Available RFID Reader List, its showing as null, why?Attached the code and screenshots I have used and got the null pointer exception.Here is the error message:
java.lang.NullPointerException: Attempt to invoke virtual method 'java.lang.Object android.content.Context.getSystemService(java.lang.String)' on a null object reference

try {
readers = new Readers(this, ENUM_TRANSPORT.SERVICE_SERIAL);

ArrayList<ReaderDevice> availableRFIDReaderList = readers.GetAvailableRFIDReaderList();



if (!availableRFIDReaderList.isEmpty()) {

ReaderDevice readerDevice = availableRFIDReaderList.get(0);

RFIDReader rfidReader = readerDevice.getRFIDReader();

Toast.makeText(this, "Reader found: " + rfidReader.getHostName(), Toast.LENGTH_LONG).show();

} else {

Toast.makeText(this, "No readers found", Toast.LENGTH_LONG).show();

}

} catch (Exception e) {

e.printStackTrace();

Toast.makeText(this, "Error: " + e.getMessage(), Toast.LENGTH_LONG).show();

}
