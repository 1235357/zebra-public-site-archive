            Hi,  I use this process and it does work.&nbsp; Here is more detail on how to do this so you can test.&nbsp; I have also provided a sample of the xml file you pre-stage on the MC40 to make this work.   Loading a configuration automatically on the MC40 for the Wavelink TE is done as follows:   An overview of the process is:  The MC40 is staged with an xml file that contains the URL of a web server onto which the actual config xml file is placed.  (If there is no web server accessible in production, I guess you could do this in a staging center to get a config file onto the unit).  You go to a Wavelink supplied web site to generate a TEconfig.xml file that you will use.  You place the config file onto the web server.  When you starte Wavelink TE on the MC40, it will go to the web server and pull down the config file and configure itself.    Following are detailed descriptions of how to create the files:  --------------------------------------------------------------------------------------------------------------------------------------------  Create a folder on MC40 named \sdcard\Wavelink&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;   Create a file and name it TEConfigurationURL.xml, and add the following lines:&nbsp;&nbsp;&nbsp; &nbsp;    http://x.x.x.x/TEConfig.xml  &nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;   Change the URL IP address / host name to your a web server that is accessible by the MC40  when in use.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;  Copy the TEConfigurationURL.xml file to the \sdcard\Wavelink folder on the MC40 device.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;   Using a PC browse to the following URL:&nbsp; http://192.41.44.46/&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nb…; &nbsp;   Configure Your Host profile&nbsp; &nbsp;  Configure Your Emulation Settings&nbsp;&nbsp;&nbsp; &nbsp;  &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;  Click download this config and save the file as “TEConfig.xml” (or another name you desire) and save it to your PC.  Put this TEConfig.xml file onto the web server that is referenced in the TEConfigurationURL.xml file.&nbsp;&nbsp;&nbsp; &nbsp;   Launch TE on the Android device, you should see a message saying New Configuration was pulled.  --------------------------------------------------------------------------------------------------------------------------------------------

            The Wavelink TE client for the MC40 supports a configuration file similar to our other MSI devices.&nbsp; This was added thanks to a major customer (not mine) that is using it.   A simplified explanation for configuring it is to:  a) Build a TEConfig.xml file with the settings needed in it.  b) Put the TEConfig.xml file onto a web server accessible by the MC40.  c) Load another small XML file onto the SDCARD of the MC40 as part of staging.&nbsp; This file contains the URL for the web server/file referenced in b.  d) Upon startup, the MC40 TE client will check and pull the config xml file down from the server and utilize it.   This support is in the MC40 TE versions 1.3.06 and later.
