            Legacy support for these 32-bit drivers is found in the EMDK downloads.
EMDK for Dot Net V2.9 - will contain the 32-bit Host SDK drivers for the DOT-NET support.
https://www.zebra.com/us/en/support-downloads/software/developer-tools/e...
EMDK For C V2.8 - will contain both 32-bit and 64-bit legacy SDK drivers for C/C++ support.
https://www.zebra.com/us/en/support-downloads/software/developer-tools/e...
The 32-bit EMDK versions have limited support.  The Current 64-bit HOST SDK support from the respective Fixed RFID reader portals - are fully supported.
