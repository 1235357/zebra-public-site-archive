            Hello Fernando,&nbsp; With the EMDK we make it a point not to duplicate functionality that is already exposed though the standard Android APIs.&nbsp; To get notification when the MC18 has been placed in the cradle you will need to make use of the BatteryManager API http://developer.android.com/reference/android/os/BatteryManager.html. With this API you can get a notification via an intent to know when the MC18 is charging/charged.
