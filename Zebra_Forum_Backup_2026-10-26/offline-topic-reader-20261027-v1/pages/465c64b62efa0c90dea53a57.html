I am working with Zebra ZT410 printer and i'm facing an issue when i print rfid tags. I send a ZPL command (below is the code) to write User Memory Bank Data into Confidex Silverline Classic tags (https://www.zebra.com/content/dam/zebra_new_ia/en-us/solutions-vertical…… ).             The RFID Tag ID is called TID. This TID is provided by the manufacturers. The TID should be unique and non-rewriteable. The RFID commands in ZPL cannot alter the TID value.
