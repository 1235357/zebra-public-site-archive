            The data led indicator&nbsp;(the envelope icon or the downward arrow) flashes when there is data exchange happening on the connection to the printer. When calling printer.GetCurrentStatus(), it sends the status querying&nbsp;command to the printer and waits for the response to come back from the printer. Therefore, the data led indicator flashes. This is the correct behavior.
If the connection is a TCP connection, you may want to use the status channel, which is a dedicated channel for querying the printer status. This way, the status monitor loop won't interfere with the print jobs. Hope this helps.
