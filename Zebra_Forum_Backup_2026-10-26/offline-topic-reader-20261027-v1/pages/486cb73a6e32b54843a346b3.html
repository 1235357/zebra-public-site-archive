            Hello Valery,   the adapter you listed cannot be used, because it is not an OTG (On the Go) adapter.  Right now it is not possible to switch from client to host mode via system settings&nbsp;on ES400.  Therefore you need to use an OTG adapter.  The product number you listed from Solution Builder will work for you.  In case you need this urgent, buy this adapter from Nokia:
  http://www.amazon.co.uk/GENUINE-NOKIA-CA-157-CABLE-ADAPTER/dp/B004APRKL…
  Good luck,   Horst
