            A quick question - are you using this RFID SDK found here:
https://www.zebra.com/us/en/support-downloads/software/developer-tools/zebra-rfid-sdk-for-windows.html

This SDK contains the RFID Test app that you can connect to the RFD40 (With Up-to-date Firmware.)

In the Developer guide: on PP 29 - you can use the RFID SDK Demo App to connect to the RFD40.

https://www.zebra.com/content/dam/zebra_new_ia/en-us/manuals/rfid/rfid-sdk-windows-dg-en.pdf

Please let us know if you are able to run this app and if it connects to the RFD40?

Firmware Suggestion - you want to be sure you are running up-to-date FW.
123RFID Desktop app can access the RFD40 / RFD90 to confirm the Firmware version.
( As well via USB - you can check that the RFD40 can read tags.)
