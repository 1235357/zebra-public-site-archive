                  Is anyone finding that the more customers use the MC65 the more they discover legacy features are nonexistent hence having to patch code? A customer recently ported their application from MC55 onto MC65 and found 2 API from EMDK not supported. They are; the Symbol.WirelessLAN API to get detailed information about the current network status and the Symbol.Keyboard API to get key depressed status.    In the interest of avoiding any further surprises, does anyone have a list of defined unsupported function calls (APIs) and roadmap for reinstating such relative to the MC65 and presumably the ES400?.    There are talks of next MC65 OS build may reinstate certain features, do we know what they are?    Any insight would certainly be appreciated.
