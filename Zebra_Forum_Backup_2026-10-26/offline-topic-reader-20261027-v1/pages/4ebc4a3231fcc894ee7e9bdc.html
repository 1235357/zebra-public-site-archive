            It depends on how old is the printer and the firmware. The printer that replaces this legacy printer is the IMZ220/320 printer.
Please, verify the latest firmware of the printer here, and try to update to latest.
Support for the MZ220 Mobile Printer
Please, take the following dates in mind.
This printer is discontinued but still serviced.
Printer Discontinuation Date:&nbsp; November 29, 2013
Service &amp; Support Discontinuation Date: February 28, 2017
Last Ship Date: February 28, 2014
Theoretically you should be able to set up the printer in CPCL with the command below
! U1 setvar "device.languages" "CPCL"
Then you could send some images like the command below
! 0 200 200 210 1
BOX 0 0 200 200 1
FORM
PRINT
Then you could set up again to "line_print"
! U1 setvar "device.languages" "line_print"
If the command setvar is ignored by the printer, it could be due to printer does not have latest firmware, or printer does not allow to update to new firmware.
Thanks,
MC
