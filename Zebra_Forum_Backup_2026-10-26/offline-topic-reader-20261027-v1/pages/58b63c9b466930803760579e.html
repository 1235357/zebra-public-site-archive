            Before connecting ZD410 to your PC, make sure that the USB driver is installed. You can find the Windows driver for ZD410 printers at the support page of&nbsp;https://www.zebra.com/us/en/support-downloads/printers/desktop/zd410.htm....
Link-OS SDK for PC-.NET release package has a demo project. In the demo project, there is a Connectivity demo that has code to show how to make a connection via USB. Hope this helps.
