            This was something that was provided by Wavelink on their website that could be imported into MSP. The issue with the addon is that first it does not allow for the complete configuration of all emulation parameters and host configurations. Also Wavelink did not test the addon with MSP v331 and it appears that not all the features work correctly. Finally if you have an issue with the Wavelink addon you will need to contact them directly for support as if they still have the download on their website then they have to support it.   As for pocket browser support that I cannot comment on.
