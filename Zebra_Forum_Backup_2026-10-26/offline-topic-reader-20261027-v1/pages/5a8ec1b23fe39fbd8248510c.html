                  We are developing an browser based ELN with support for Zebra printers. We were wondering if we can get around each of our users having to install BrowserPrint? We were thinking to install BrowserPrint on a "server"/laptop and then use the URL/IP of this "server"/laptop to connect to. But if we do that, we receive CORS issues, that only 127.0.0.1 is allowed - so almost there :-)Can you help us with a multi-user environment where we do not want each user to install BrowserPrint?
