            Another thought is the file BarcodeDB=\Scanned Barcodes\DBASE.txt.&nbsp; From the reference manual it says 
"Bar code database filename. If file exists,
checks scanned bar codes against content.
If bar code exists, generates a positive beep;
if not a negative beep"
I don't have a CS4070 to play with but I am wondering if the DBASE.TXT file does not contain the barcode you are scanning then I believe you will hear a beep but I wonder if it will it add the scan to the BARCODES.TXT file?&nbsp; You may need the code listed in the DBASE.TXT file first as a validation.
