            Hi Ian   For Westminster, each device had manual intervention. The steps were:  1.&nbsp;Set the correct date and time  2. Load a certificate install program&nbsp;via Activesync  3. Ensure network connection is to a PC that can see certificate server  4. Run certificate installer and enter Username &amp; Password  5. Check that Certficate can be seen in Manage Certs screen   Cheers  Justin

            Within TNT Post, we have used MSP to configure EAP-TLS. With MSP we are able to configure the fusion parameters correctly, but due to the fact the certificate authority at TNT Post is using a custom&nbsp;certificate template (named other then ClientAuth) fusion is not able to ask for the 'custom'&nbsp;certificate template.   TNT Post has decided to make a move towards PEAP with no certificate validation towards the server. Initially, MSP is used to configure fusion, using a staging WLAN under wpa-tkip security. Updating the abup30 version to support the correct PEAP settings being configured by MSP
