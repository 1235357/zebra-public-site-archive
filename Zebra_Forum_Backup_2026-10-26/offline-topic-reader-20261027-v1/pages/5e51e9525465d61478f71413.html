            I don't have a device to build the reg file but you can use the CtlPanel applet in Application to create this file.  Set PERSIST=YES and then set the Picklist Mode and I recommend FOCUS=NEAR.  When you exit out gracefully this applet will generate a registry file in the Applicarion directory.
