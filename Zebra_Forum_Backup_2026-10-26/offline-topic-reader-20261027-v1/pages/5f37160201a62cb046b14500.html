            ZD621 should come with the PDF Direct installed. If not, the PDF Direct can be download from the the ZD621 support page on www.zebra.com website. The PDF Direct is included in the Factory Installed Printer Emulations package. The PDF Direct, a.k.a., PDF emulation, is the Virtual-Dev-PDF-v2xx.NRD file. It can be installed and enabled on the printer through the Zebra Printer Setup app.
The Link-OS SDK for iOS support Bluetooth and network connectivity to ZD621. If you want to use Bluetooth, please make sure that the ZD621 printer had Bluetooth Classic, which is an option. The standard configuration of ZD621 doesn't have Bluetooth Classic.
