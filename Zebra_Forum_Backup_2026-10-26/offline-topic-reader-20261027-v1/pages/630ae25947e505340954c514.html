            Please note that there was no new EMDK API SDK (Android SDK/Xamarin NuGet SDK) has been released after March 2023 Update as there were no changes in EMDK Android/Xamarin API programming interfaces. But Android Studio plugins/Xamarin Visual Studio extensions have been continuously updated to support new MX version integrations and released to the marketplaces to facilitate the static profile generations thru Android Studio IDE and Visual Studio IDE UI menu extensions. So, NuGet SDK v8.0.0.9 is the latest available as of now.
