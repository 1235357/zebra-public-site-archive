                  Just thought I would let you know that I've recently published a free open source java application which emulates a zebra printer. You run it, tell it to listen to a port, 9100 for example and then send plain text ZPL to it and it renders the label on screen. You can also open a text file which contains zpl and it will render it.The software is on GitHub, I won't post a direct link as I'm not sure that is allowed but you can find it here github.com/C4J/ZPL-Renderer I wrote it for myself so I can run full tests and print labels from my core application - Commander4j.Feedback would be most welcome - maybe on the Github discussion page.I've attached a screenshot.Dave
