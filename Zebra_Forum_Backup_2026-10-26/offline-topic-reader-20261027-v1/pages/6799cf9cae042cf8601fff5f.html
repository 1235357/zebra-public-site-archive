            Dont try to override the external buttons - you do not need to do this.There is a simpler method to do this - in Datawedge - you use the Soft-Scan feature.In techdocs starting here:  https://techdocs.zebra.com/datawedge/13-0/guide/about/Look at the Datacapture Sample app here:https://techdocs.zebra.com/datawedge/13-0/guide/samples/barcode1/As you see in the UI - there is a Soft-Scan button - this is the programmatical method to indicate to Datawedge to begin scanning.The Very Basic verison of using Datawedge in a Lightweight manner is the second sample I always refer to - which is "Basic Intent" sample app found here:https://techdocs.zebra.com/datawedge/13-0/guide/samples/basicintent1/FYI - These samples expect to use Android Studio - and not the legacy eclipse-based projects - so you may need to re-adjust for this in your code / project.
