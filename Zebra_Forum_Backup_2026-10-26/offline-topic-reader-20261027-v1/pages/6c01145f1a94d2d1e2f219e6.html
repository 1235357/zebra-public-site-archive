            I'm pretty sure that the existing&nbsp;MSP 3.x&nbsp;licenses (qty 300) are transferable to the new version 3.3.1 running on the new install. As long as the customer only has 1 instance of MSP server they shouldnt have to pay&nbsp;again for&nbsp;server software. They are entitled to the 3.3.1 upgrade if they have a software support agreement which it appears they do have.   I dont know anyone using a 3rd party reporting tool to access the MSP database although it should be possible. I believe that you furst need to enable Asset Reporting via MSP to make the data available to a 3rd party tool such as Crystal.
