                  Link-OS is Zebra's new operating system and set of tools designed for today's software ecosystem.  These tools enhance the capabilities of our printers and other devices by making them significantly easier to manage and integrate into global operations.  Link-OS allows users to spend less time on device deployment, administration and troubleshooting. 
 
Link-OS has several tools available now, with regular future releases planned for additional tools.
Cloud ready Link-OS device firmware
Lonk-OS Multiplatform SDK - Software development kit to create custom apps
Print Touch - NFC based Bluetooth pairing and app launching
Cloud Connect - Connect securely and directly to the cloud
Print Station App - Print from anywhere – using today's platforms
AirWatch Connector plugin - Seamless integration with AirWatch mobile device management
See attached datasheet for more details.
