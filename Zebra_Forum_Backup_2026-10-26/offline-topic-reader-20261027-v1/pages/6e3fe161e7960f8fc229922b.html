            The Add Printer in the settings of the Browser Print only allows the user to add the network connected printers that cannot be detected by the discover API of the Browser Print due to the network configuration. The USB connected printers are always detectable by the Browser Print, so there is no need to manually add USB connected printer in the settings. Apology for the misunderstanding in my first response.
