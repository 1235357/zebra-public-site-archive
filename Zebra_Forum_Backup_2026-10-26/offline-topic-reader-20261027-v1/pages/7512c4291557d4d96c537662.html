            The RFD Sled Platforms and the MC33x0(X)R platforms use the newer RFID SDK support platforms for Android as follows:

RFD40 / 90 / MC33x0XR ( for Android 10+)   { RFD8500 running FW greater than R71 works too }

https://www.zebra.com/us/en/support-downloads/software/developer-tools/rfid-sdk-for-android.html

The latest of which (and strongly suggested to use) is V2.0.2.110.

 

Xamarin is similar with V2.0.1.110 here:

https://www.zebra.com/us/en/support-downloads/software/developer-tools/zebra-rfid-xamarin-sdk-and-demoapp-for-android.html

If you are using 123RFID Mobile app - and want to review the Source code to understand what goes on underneath the covers:

https://www.zebra.com/us/en/support-downloads/software/demo/123rfid-mobile.html

 

The MC33x0XR - if you are up-to-date with the Android 10+ on this - the above software platform SDK allows you to use the RFID device.

The Barcode Scanner on MC33 Zebra Android - is Datawedge based.  (this also has an impact for the RFD Sleds)

https://www.zebra.com/us/en/support-downloads/rfid/rfid-handhelds/mc3300xr.html

FYI - Be Careful -  the EMDK SDK is shown for support - but EMDK Barcode NameSpace is warned about here on the TechDoc for EMDK for Android:

https://techdocs.zebra.com/emdk-for-android/11-0/guide/about/   ( Read the Note about "Regarding EMDK Barcode Scanning APIs" )

Datawedge:
There is not a dedicated DataWedge development portal / SDK per se - TechDocs is the best resource for understanding this:

https://techdocs.zebra.com/datawedge/11-4/guide/about/
