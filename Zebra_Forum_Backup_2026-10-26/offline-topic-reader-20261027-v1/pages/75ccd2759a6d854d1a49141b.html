                  On previous Android OS builds (GB and JB) , it was possible to download an APK file direct from a link displayed in the Android browser e.g. browse to this link http://moto.airsetup.com/android and click on an APK file to download and then install it directly on the TC55 or other MSI Android device (after enabling 'install from unknown sources' in Settings). On the TC55 JB OS , this works as expected. On the KK OS builds, it seems to not handle the .APK extension correctly and thinks that it is a text file. If I use an alternative browser such as Opera Mobile then the APK download works on KK as expected.
   Is this a known issue and if so, is it a Google change in KitKat or a bug in our OS build?

            Just to note that I found yesterday that I could use the default File Explorer tool to rename the downloaded file (which has a .TXT extension) to .APK and it does install correctly afterwards. This is a usable workaround but would be good to understand why this behavior has changed in KK.
