                  Dear everyone,
We have been trying to develop a React Native application capable of printing with Zebra devices.
Printer: ZQ110
S/N: XXZN19-18-0002
Firmware version: ZQ110_V1.04 STD 062917 (upgraded from 1.0)
Self test image file attached for additional information
Libraries Tested:
Polidea/react-native-ble-plx: React Native BLE library (https://github.com/Polidea/react-native-ble-plx)
catnuxer/react-native-zebra-bt-printer: Bluetooth printer zebra (https://github.com/catnuxer/react-native-zebra-bt-printer)
kenjdavidson/react-native-bluetooth-classic: ⚛ Bluetooth classic Android(Bluetooth)/IOS(ExternalAccessory) module for serial communication (https://github.com/kenjdavidson/react-native-bluetooth-classic)
We attempted to connect to the printer via bluetooth implementing the device scanning/pairing with each of the libraries aforementioned, testing on real iOS (iPhone 6) and Android (Samsung Galaxy S9) devices, enabling and disabling MFi mode on each try, but the devices found while scanning did not show any information that indicated that it was a Zebra printer. The only time we could connect to the printer and actually print something was using your proprietary apps ‎Zebra ZQ110 for iOS (https://apps.apple.com/us/app/zebra-zq110/id937888890) and Zebra ZQ110 for Android (https://play.google.com/store/apps/details?id=com.zebra.zebraZQ110)
What other options do we have in order to connect to the Zebra printer ZQ110 and print something generated from our React Native app?
Thanks in advance

            Hi -&nbsp; We do have Android and iOS native SDKs for that printer specifically&nbsp;https://www.zebra.com/us/en/support-downloads/printers/mobile/zq110.htm…; Unfortunately we do not have something specifically for React, but you can create a wrapper for these.&nbsp; There may even be a wrapper out there created by someone else.&nbsp; Keep in mind that this in not a Link-OS or ZPL printer, so SDKs designed for that are not going to work in this printer.&nbsp;&nbsp;
I am not entirely sure these printers will be discoverable as Zebra printers using the standard means.&nbsp; They are very different from most of our printers from the ground up.&nbsp; Did you try to connect with the printers directly given thier known serial/mac addresses rather than via discovery?&nbsp; You could add an easy to scan barcode to the printers (or use the ones we usually have on them) to get the mac address into your app.
Robin
