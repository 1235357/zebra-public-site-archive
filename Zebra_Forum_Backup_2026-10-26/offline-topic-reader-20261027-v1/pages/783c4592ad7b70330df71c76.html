            EDMK API support - is not available via Emulation on both Little Windows and on Android.
Emulation support is only available for Generic Library SDK suport for the respective Platform API's and not for Hardware/Aligned / HW / FW specific solutions like Little Windows / Android - Zebra - branded solutions.
The Development Solution is to use Zebra - Branded HW/FW - to develop EMDK SDK solutions.
