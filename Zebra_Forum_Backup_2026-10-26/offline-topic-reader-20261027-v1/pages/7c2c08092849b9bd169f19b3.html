            All current MC3090 CE Core models are with 64/64 memory so this should not be a problem.   Please remember that you will not be able to simply reinstall/upgrade&nbsp;the OS on the existing units from Pro to Core - OSUpdate or hex installation will fail (at least I have been always told so, never tried). You need to install another configfile to the units. No technical problems with this as well - but someone should officially provide you or the customer with this file.
