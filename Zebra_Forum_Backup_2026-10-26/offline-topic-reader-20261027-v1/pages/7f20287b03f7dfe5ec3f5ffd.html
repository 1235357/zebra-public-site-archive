            Chris,   Sounds like you may have a Read Only file somewhere in the Application folder.&nbsp; If you use the -#"0" Custom Option in the OS Update Package Builder, it should remove any Read Only attributes.   There could also be an application running from the Application folder.&nbsp; I've run into this problem if DataWedge was installed in the Application folder and is running when the OS Update utility runs.&nbsp; You'll need to shut down DataWedge before starting OSUpdate.&nbsp; OSUpdate attempts to shut down running processes before it starts but DataWedge doesn't listen.&nbsp; You can run DWCtlApp.exe with the "Uninstall" argument to have DataWedge stop.   Ken
