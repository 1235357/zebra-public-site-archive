            If DataWedge is installed in the Program Files folder the configuration will not get persistent across coldboot.&nbsp;   What you can do is once the configuration is saved Copy the configuration (contents of the&nbsp;\Program Files\DataWedge\Config) to the \Application folder. After a cold boot copy the backed up configuration to the \Program Files\DataWedge\Config folder.   or Create cpy file that would copy the configuration files from \Application folder to&nbsp;\Program Files\DataWedge\Config.   If you need a sample cpy file let me know. I will send it.&nbsp;
