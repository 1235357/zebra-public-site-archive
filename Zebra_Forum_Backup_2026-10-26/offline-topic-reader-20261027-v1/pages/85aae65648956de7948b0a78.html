            Although not an RFID or Zebra-Specific issue - Access Control Systems - can have remote operation via a GPIO (GPO) that would operate a Contact Closure for activating the Barrier.A good suggestion is to work with the Building Management / Access Control system partner to then consider methods to integrate  the RFID Use-Case solution to allow the access controls.  ( Also you can Google for these system providers.) Please Note: As you can see -- I did not make any recommendation - other than the high-level partner suggestion. This is due to the Human-Safety considerations with Access Controls. These systems need to correctly designed / built / integrated to not pose a risk to persons - whose access provisions are being considered.
