                  Currently we have an app that is build using the EMDK. This app starts a "docking mode" when the device is upside-down. which will start the scanner and keeps reading codes until the activity is closed.
Now we are trying to achieve the same thing but using the DataWedge way.
while using the EMDK we did the following:
config.readerParams.readerSpecific.imagerSpecific.beamTimer = 0
config.readerParams.readerSpecific.imagerSpecific.aimType = ScannerConfig.AimType.CONTINUOUS_READ
config.readerParams.readerSpecific.imagerSpecific.sameSymbolTimeout = 5000
this works perfectly is there a way to do the same in DataWedge?
We tried setting different aim-types where "press and sustain" combined with "beam timer = 0" gets the closest but still stops after a scan.

            Hi, yes, if you set "Configure scanner settings" --&gt; Reader params --&gt; Aim Type to 'Continuous Read' in your DataWedge profile it will continually read barcodes after a soft scan has been initiated once.
