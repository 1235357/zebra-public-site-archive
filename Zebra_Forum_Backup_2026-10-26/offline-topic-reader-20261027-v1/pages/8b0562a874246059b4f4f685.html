            Hi,
We have a general Getting Started guide available here: https://developer.zebra.com/docs/getting-started
For the SendFileToPrinter API, we have a specific guide for setting up your printer here: https://developer.zebra.com/docs/printer-setup-sendfiletoprinter
Full details of the API can be found here: https://developer.zebra.com/apis/sendfiletoprinter
We have a free version of the API which allows 100 calls / day, w/ a maximum throughput of 5/second.
If you require more calls than this, we charge $0.01 / call, again w/ a maximum throughput of 5/second.
Thanks,
James
