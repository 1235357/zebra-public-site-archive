                  12:05pm/07-13-2009 3 day MC7090 WM5.0/BSP43 1923551  MC7090 is connected to a USB to Ethernet client device using a USB host snap-on cable. Customer needs to programmatically or via registry disable power draw from the client device. They have used a registry key to put the terminal into client mode, but the terminal is still sending power to the client device. So it would seem that the physical connection of the host cable is overriding the registry setting. Any ideas?

            I had originally suspected that the hardware configuration of USB Host took precedence.&nbsp; But, that isn't the case.&nbsp; The registry key will override the hardware.&nbsp; Setting the terminal to Client mode using the registry key (be sure to merge then warm boot) is the only method to remove power.  Be sure that the remote device is disconnected from the terminal when testing.&nbsp; There is concern that the external USB device is backdriving the power giving invalid results.
