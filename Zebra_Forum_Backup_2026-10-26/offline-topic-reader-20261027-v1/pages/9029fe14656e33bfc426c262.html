                  Hi,
We are waiting for a ZD420d printer to be delivered which is likely to be in about 10 weeks. Is there a Zebra printer emulator available so that we can develop and test before the printer arrives? 
Requirements:
- The Zebra printer emulator will run on Windows or Android
- It must be possible to connect to the emulator from an Android app (either on Android Windows emulator or physical device)
- The emulator will support a TCP/IP connection
Current search results for "Zebra printer emulator" have come up with:
- Zpl Printer Chrome extension. This installs OK but it doesn't seem possible to connect to it from an Android app (either over local network or Android Windows emulator)
- ZPLViewer available on sourceforge. It hasn't been updated since 2014 and it doesn't seem possible to get it to install on Windows 10
- Zebra Printer Emulations available from the zebra website. These are on-printer apps and do not fit the requirements above.
Thanks

            Unfortunately, there is no Zebra printer emulator (or simulator). You will need a physical printer if you want to test the printer connection, the printer configuration, etc. If you just want to test and verify the ZPL label design, the online http://labelary.com/viewer.html is sufficient. The Printer Emulations offered at Zebra site are the emulations for the non-ZPL label formatting commands, such as Datamax, Intermec, etc., which have to be installed on a physical printer in order to use.
