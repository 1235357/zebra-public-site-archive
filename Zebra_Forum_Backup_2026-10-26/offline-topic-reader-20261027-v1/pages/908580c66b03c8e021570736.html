            We got this response from SOTI which is very helpful.&nbsp; In the SOTI set up use this script to enable system apps.
enable_system_app
For example, to enable Google Chrome you would send:
enable_system_app com.android.chrome
So just a matter now of determining the app name for Datawedge.
Thank you SOTI support.
