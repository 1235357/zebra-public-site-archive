                  This is actually similar to the topic raised earlier by Horst.
Russian beta-customer has reported today that they have spent ~$500 extra on cellular connetivity during two weeks of field test because the device sends extra kilobytes each two-three minutes and they quickly got out of their quite limited plan. I believe this is because of Elemez and probably other hidden things enabled by default. Because of this the customer had to completely turn off mobile internet access which limits the functionality of their applcation and narrows the field test scope.
Thus:
1. I need an approved way to turn Elemez off together with other hidden things (if any) that send the diag data over network in background - now and ASAP.
2. I believe this functionality must be disabled by default and can be turned on only manually and only by customer's permission. Apart from the extra traffic cost these things create privacy concerns. We're promoting our MX in particular as a way to protect customers from Google services and at the same time introduce the similar (as it seen by customers at least)

            Valery,
 You can try using the method detailed below which will allow time restriction on the use of WAN for Elemez data transfer. One additonal point - if you use AccessMgr (via the EMDK or StageNow) to create a whitelist for apps to run on the unit, it will automatically stop Elemez and other non-whitelisted apps from running or being restarted/reinstalled.
Create a text file called exactly “elemez.properties” with the following text and place it in either /Internal for devices without a physical SD card or the root of the SD card.&nbsp; The file is read upon reboot .
# the name used for the group of devices using this configuration set.
name = TC75
# the time range that elemez should not send cellular data. The times are specified as 24 hour clock, and refer to device local time.
# This example blackout cellular data between 0600 AM and 0700 AM in device local time. This means NO data will be sent over cellular connections between 6 and 7 AM.
cellular-blackout = 0600-0700
# To completely block WAN data use: cellular-blackout = 0000-2359
