                  On Beta units, the default port for the SIM card was the mini SIM slot.
We changed this in production to nano SIM Port 1.
Please be aware that mini SIM cards will not work any longer on a production out of the box device.
If using mini SIM cards you need to switch the default SIM port from nano to mini.
This can be achieved by copying the WWAN_UI_Conf file to the root of the external or internal SDCard. The file is attached.
To disable the settings again, just change all values within the WWAN_UI_Conf from "1" to "0" and copy the file again onto the device.
When activated, you can change the settings within "Mobile Metworks" manually.
Unfortunately for Staging, right now there is no option to change those settings automatically.
Therefore, we need a solution being able to change the default SIM port and maybe other necessary values along with that.
