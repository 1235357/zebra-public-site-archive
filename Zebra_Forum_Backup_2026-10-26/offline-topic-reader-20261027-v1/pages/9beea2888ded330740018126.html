            ZQ600 series are Link-OS printers. For POC purpose, any Link-OS printers will do, because all have the same feature set and work the same way with Link-OS SDK from software perspective. I would suggest to get a ZQ310 (2") or ZQ320 (3") printer for the POC purpose. If you plan to use Bluetooth connection from your iPad to the printer, make sure to be a little diligent of checking the printer's status prior to each print job and prior to closing the connection as well, because we don't want to jam the data buffer on the printer or close the connection prematurely. Another note is to do all the communication with the printer in a background thread and never do that in a UI thread. In general, printers are considered as slow external accessories. Using a UI thread to deal with the printer can lead to numerous other issues. Hope this helps.
