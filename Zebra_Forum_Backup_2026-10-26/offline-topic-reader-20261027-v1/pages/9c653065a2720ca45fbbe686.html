            Is this with the RFD40 / RFD90 sleds?If so - (I use the BasicIntent1 - Android Studio Sample app) - in the Datawedge Profile - if you turn on the RFID Module and select the RFD40/RFD90 for the attached Reader to the profile. Make sure to exit from the profile to allow you to access then the extra menu's that you need to check.In the "Configure reader settings" for the "RFID Input" menu -check that the "Hardware key" is setup to default.The Upper and Lower triggers when configured on the RFD40 - if the RFID Trigger is configured as "RFID" and the Scan Trigger is setup to "Terminal Scanner"  the RFID Trigger - when used with the RFD Sled - will read / send RFID Tag Data.
