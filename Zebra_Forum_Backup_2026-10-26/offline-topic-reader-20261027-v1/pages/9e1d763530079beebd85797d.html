            DataWedge itself does not need the EMDK runtime to run on TC70.&nbsp; As far as I know Velocity client uses EMDK to create the DataWedge profile and hence you need the EMDK runtime.&nbsp; I would expect Velocity provides documentation on their requirements.

            Something else to be aware of with the DataWedge Profile:
When you install the Velocity (All-touch Client) on the TC70 or other, and then open it, it will create a DataWedge profile for you called Velocity
This data wedge profile is part of the application build, so if you need to change a scanning characteristic, you need to do it in the console
If you make a change to the Velocity profile in DataWedge, the Velocity client will overwrite any changes you made, unless you built a customer build using the Velocity Console
In the Velocity console, there is place to configure the DataWedge parameters at the bottom
