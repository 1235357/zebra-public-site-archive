            There isn't a command prompt but there is an equivalent to the Start -&gt; Run in windows.      Hold down the action button (centre of the Directional pad) and then tap and hold the the clock at the top of the screen for about a second or two. Release both, clock first, and a menu should pop up under the clock with "Run" in it. From there you can run any application you want and specify arguments if needs be. On a mc70 the action key is the enter key.
