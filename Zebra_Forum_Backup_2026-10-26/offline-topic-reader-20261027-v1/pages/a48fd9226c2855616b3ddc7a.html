            What's the printer model? Only Link-OS printers support the SendFileToPrinter API. Before sending the enrollment string to the printer with the Printer Setup app, please make sure the Device Language on the printer is set to ZPL, or XML and ZPL. If the Device Language is Link Print, the printer will print the enrollment string instead of using the enrollment string to configure the weblink. You can use the Printer Setup app to confirm and configure the Device Language.
