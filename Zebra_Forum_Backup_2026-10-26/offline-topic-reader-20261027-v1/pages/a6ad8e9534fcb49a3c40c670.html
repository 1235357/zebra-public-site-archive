            Juan-Antonio,   &nbsp;Another solution to remove the PIN entry requirement is to switch to the MS BT stack. When I did this on an MC75 BSP35 , I could pair the RS507 with no PIN entry using the following sequence:   a) switch BT on in discoverable mode   b) Run BTScannerCtlPanel to link with comm port   c) scan pairing barcode created by Display_BT_Address   d) RS507 is now paired with no PIN entry requirement   Best Regards,  Ian Hatton  EMb EMEA
