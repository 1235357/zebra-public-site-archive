            It's all the same as for any our CE device - use \Application folder and .reg, .cpy and .run files to keep settings/install apps&nbsp;after coldboot.   Specifically for timezone - this thread may help http://devcentral.motorola.com/view/21308/view.aspx   Just set up the required timezone and export&nbsp;related registry keys in \Application\whatever.reg file. You may have to warmboot after coldboot to bring these settings to life - this is definitely true for regional settings but I'm not sure about the timezone.   As for time - the only way to keep the time after coldboot is to sync it with some external source - which is probably not an easy option for MC1000 as it has no radio. Also I remember there was a Symscript script which periodically saved the current time into a file and being started automatically after coldboot it read this file to set the&nbsp;time to the last saved one.   Valery
