                  Hello, we have an iOS app that is using the Zebra SDK for iOS and we’re having issues when trying to find printers. This used to work on iOS 13 but on iOS 14 we’re getting an error. Specifically when we try to use this method:
+(NSArray *)localBroadcast:(NSError **)error;
We’re getting this error:
Error Domain=ZSDK_API_ERROR_DOMAIN Code=5 "Network error during discovery" UserInfo={NSLocalizedDescription=Network error during discovery}
The app is currently available on the App Store and several users are not able to use the printer anymore. Can you please let us know if there’s a updated version to the library with a fix to this issue?

            The error from the network discovery is due to the recent enforcement on the multicast network entitlement in iOS 14.5 and higher. You need to apply for the multicast network entitlement through Apple Developer Program. Please see this article for detail - Link-OS SDK for iOS – Printer Network Discovery API impacted by iOS 14.5 and higher
