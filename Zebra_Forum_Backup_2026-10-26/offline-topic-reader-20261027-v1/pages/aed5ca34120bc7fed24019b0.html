            To exit Pocket Browser manually one of the following is needed:  1. Add Quit button meta tag to the page from where Pocket Browser needs to be exited  or  2. Add Quit button meta tag to the registry path HKEY_CURRENT_USER\Software\Symbol\SymbolPB\Tags   Please refer to PB help file for details.   Hope it helps.  Sudhakar.
