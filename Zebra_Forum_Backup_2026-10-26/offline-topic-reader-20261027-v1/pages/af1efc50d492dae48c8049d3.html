            Shridhar,   &nbsp;I find that the best performance from the imager engines (pre-Blockbuster) is achieved with auto focus enabled which can be done via the registry key below (click on it in File Explorer to merge with the system registry):   [HKEY_LOCAL_MACHINE\Drivers\BuiltIn\BarCodeReader\Settings]  "ReaderParams"=hex:\  &nbsp; 5C,00,00,00,44,00,00,00,02,00,00,00,00,00,00,00,\  &nbsp; F4,01,00,00,03,00,00,00,88,13,00,00,00,00,00,00,\  &nbsp; 00,00,00,00,00,00,00,00,02,00,00,00,01,00,00,00,\  &nbsp; 01,00,00,00,01,00,00,00,00,00,00,00,00,00,00,00,\  &nbsp; 00,00,00,00,00,00,00,00,00,00,00,00,00,00,00,00,\  &nbsp; 00,00,00,00,00,00,00,00,00,00,00,00   Best Regards,  Ian Hatton  EMS EMEA
