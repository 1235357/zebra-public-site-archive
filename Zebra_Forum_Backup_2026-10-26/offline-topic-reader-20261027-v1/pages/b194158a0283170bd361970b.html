            So I have a customer that has been having the same problems for almost two months now. Loaded the Supercab v1.2 with no success and was then told to load the latest OS hotfix at the time was 80.32.06 and still had the same issues.   The problem was that it was assumed that the Supercab fixes were rolled into the OS and no where in the release notes did it state that the Supercab still needed to be applied. This applies to both v80.32.06/05 OS'   After installing the OS then reinstalling the Supercab, all issues that we had were resolved......go figure   Going to try and get that statement inserted into the release notes
