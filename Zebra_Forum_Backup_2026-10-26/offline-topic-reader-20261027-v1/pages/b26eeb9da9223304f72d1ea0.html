                  Hello everyone,I’m seeing a recurring issue on Zebra MC34 / MC94 devices: after applying the WLAN profile, the device only connects to our corporate Wi‑Fi if I either reboot it or briefly toggle airplane mode. Once that manual step is done the connection remains stable, but the network team won’t investigate the root cause.I want to automate a workaround in StageNow so each device performs the required action immediately after the WLAN configuration and connects without manual intervention. Is there a way to implement this in StageNow?I currently use two profiles to set up the handheld devices, and I currently have to apply the first profile again for it to work.Staging Profile 1 (Configuration):FileMgr -> Transfer CA-certificate (embedded barcode)CertMgr -> Install CA-certificateWiFi -> Configure WLAN network (EAP-TTLS-MSCHAPV2)WiFi -> Connect to WLAN networkClock -> Set NTP server, Auto Time Zone, Auto TimeFileMgr -> Transfer XML file from internal HTTPS server -> "Cancellation due to missing Wi‑Fi connection", Problem: Saved / IP Configuration FailureBatch -> Execute XML fileStaging Profile 2 (Installation steps -> XML file): e.g., APKs from internal HTTPS server, EHS, DataWedge Thank you in advance for the help.

            You can try modifying your profile to toggle the WiFi power off and on as per the XML example below:
 
  <characteristic version="11.5" type="Wi-Fi">   <characteristic type="System">     <parm name="WiFiAction" value="disable" />     <parm name="WifiWakeup" value="1" />   </characteristic> </characteristic><!-- delay 1s -->  <characteristic version="6.0" type="ConditionMgr">     <parm name="DataType" value="2" />   <characteristic type="IntegerDetails">     <parm name="IntegerSourceType" value="2" />     <parm name="IntegerSystemValue" value="1" />     <parm name="IntegerConditionTest" value="1" />     <parm name="IntegerConstantValue" value="0" />   </characteristic>   <parm name="ConditionMetAction" value="2" />   <parm name="ConditionNotMetAction" value="2" />   <parm name="ConditionRepeatCount" value="1" />   <parm name="ConditionRepeatInterval" value="1" />   <parm name="ConditionFailMessage" value="Condition Failed" />   <parm name="SuppressMessage" value="1" />   <parm name="ConditionWaitMessage" value="" /> </characteristic>  <characteristic version="11.5" type="Wi-Fi">   <characteristic type="System">     <parm name="WiFiAction" value="enable" />     <parm name="WifiWakeup" value="1" />   </characteristic> </characteristic>
