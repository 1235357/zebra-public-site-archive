            Sorry that will not work as you expect.Two things:  1) Xamarin as of May 1, 2024 - is no longer supported.  ( Developers / users can do their own Xamarin use-case self-support - but there will not be any Zebra Support for same. )2) MAUI (Newer DOT-NET / C_Sharp) development environment also is what you should be transitioning to.And there are "Gotchas"  - like MAUI - is no longer supporting Android 11 - and that ecosystem is still out there.As much as I understand Partners / Developers have that legacy - Google / Android / Zebra / Android is not staying still and progression from Older Platforms to newer ones is an ongoing topic that we repeatedly indicate to move forward or be exposed to potential platform security risk if you are running Older Firmware / OS / SDK's.  ( As much as Zebra Lifeguard provides - as-is security updates - this is also on all fronts of up-to-date currency.
