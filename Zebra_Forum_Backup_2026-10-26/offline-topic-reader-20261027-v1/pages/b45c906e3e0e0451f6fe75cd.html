            use the 25-156846-01R cable from the LS3408 to the VCD9500 cradle.
We set the LS3408 to HID keyboard emulation (should be the default setting)
&nbsp;
On the MC9590 we did the following:
Settings -&gt; System -&gt; USBConfig
Set the USB Port Mode to “USB Host Mode”. &nbsp;.reg key attached.
This will allow the LS3408 to be powered off of the MC9590 battery.
