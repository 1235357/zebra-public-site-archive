                  A partner is testing the custom application at customer site, using 2 types of devices: MC3x90 and MC9x90. There is a part of the application where it's hopping that the users press CTRL+G, on the MC3x90 it's working perfectly, but on the MC9x90 isn't. It seems that on the MC9x90 the OS isn't returning anything when the users press CTRL+G, but on MC3x90 is.  Does anybody have any suggestion or solution for this problem on MC9x90?             Paulo,   &nbsp;Depending upon the keyboard configuration of the two devices, it is possible that the 9x90 does not have Ctrl-G mapped by default whereas the 3x90 does. You can check the keycode being returned when you press Ctrl-G on each unit using the EMDK sample keycheck.exe (attached). If Ctrl-G is not available by default then it may be possible to add it using the kbtools utilities which allow custom keyboard remapping.   Best Regards,  Ian Hatton
