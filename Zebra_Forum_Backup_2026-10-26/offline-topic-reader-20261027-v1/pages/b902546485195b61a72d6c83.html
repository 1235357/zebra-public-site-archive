            Hi, 

The engineering team that owns EMDK confirmed the architectural change in Android 14

At the moment, a valid way to check the EMDK version is
        if(Build.MANUFACTURER.contains("Zebra")) {
            Log.i(TAG, "This is a Zebra device");
            versionManager = (VersionManager) emdkManager.getInstance(EMDKManager.FEATURE_TYPE.VERSION);
            if (versionManager != null) {
                String version = versionManager.getVersion(VersionManager.VERSION_TYPE.EMDK);
                Log.i(TAG, "EMDK Version: " + version);
            } else {
                Log.e(TAG, "Failed to get EMDK Version");
            }
        }
Please elaborate more on the use case that requires to get the EMDK version before it is instantiated.

            Hi G, thanks for the details you shared above.

The method you described did not guarantee the presence of an internal scanner anyway. Devices like EM45 only have a camera, but EMDK is still onboard.
To check for a Zebra/non Zebra device, I'm confirming the  Build.MANUFACTURER option shown above.
Once you are certain of the Zebra brand, one way to check for the scanner is

Instantiate EMDK (use emdkManager.getInstanceAsync so it works fine even at startup) 
Get a list of the available scanners by the barcodeManager.getSupportedDevicesInfo();  and look for "2D Barcode Imager"



Here is an example of what a TC58 would return
and this is a EM45 -note the 2D Barcode Imager missing
