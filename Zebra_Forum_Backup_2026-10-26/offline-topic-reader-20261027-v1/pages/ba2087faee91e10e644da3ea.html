            Hi Mark,
We don't have a lot of demo labels available, but you can easily create your own using ZebraDesigner.&nbsp; It has a GUI interface where you can drag and drop images, text, and bar-codes onto a label, then print or set it up to print to a file.&nbsp; This file can then be imported into Zebra Utility.
