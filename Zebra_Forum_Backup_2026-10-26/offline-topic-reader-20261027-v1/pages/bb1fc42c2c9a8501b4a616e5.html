            Hi Robert.

The Java and Native code Linux/Big Windows SDK's for Linux and / or / Big Windows (Intel) - do not have API's for the network discovery like you see in 123RFID Desktop app. 

FYI: 123RFID Desktop app is closed source and not shared. 

The 123RFID Mobile app - in contrast - is shared source (and installer APK for Non-GMS sideloading) and what you refer to is for the Mobile RFID Sleds and BT.

123RFID Mobile "discovery" API is for Bluetooth Sleds to find the "FriendlyName" in bluetooth.
