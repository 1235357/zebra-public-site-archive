            Sorry, I guess I'm not being clear.  The customer wants the Extended DNS Query functionality.&nbsp; It is included in an OS if the SYSGEN_DNSAPI flag is set.&nbsp; However, our standard OS does not include this flag.  Options: 1) GRIP request to have this feature added to the next maintenance release 2) CPR to have a custom OS built for this customer. 3) Customer can create their own application that provides this functionality 4) Customer can find a third party application to provide this functionality
