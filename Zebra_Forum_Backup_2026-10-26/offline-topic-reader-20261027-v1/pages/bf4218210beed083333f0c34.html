            Hi Pavel,Unfortunately, there is no direct way or official iOS SDK to print straight from an iOS device to Zebra ZXP card printers. Zebra's existing iOS SDK only supports their label and receipt printers.To achieve this workflow, you can have your iOS app send the card data to a custom backend server. The server can then use the official Zebra Card SDK (available in Java or .NET) to process the job and print to the networked ZXP printer.
