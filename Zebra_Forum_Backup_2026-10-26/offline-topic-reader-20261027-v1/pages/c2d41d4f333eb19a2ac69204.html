                  I’m using Zebra RFID SDK version 2.0.5.214 in my Android app, and I have encountered a serious compatibility issue when preparing to publish on Google Play. One of the native libraries included (libvolume-vulkan-lib.so, among others) has LOAD segments not aligned at 16 KB boundaries, which triggers Google Play’s 16 KB page size compatibility warning / error.As per Google’s requirement: starting November 1, 2025, all native libraries in apps targeting Android 15+ must support 16 KB page size alignment. Android Developers Blog
