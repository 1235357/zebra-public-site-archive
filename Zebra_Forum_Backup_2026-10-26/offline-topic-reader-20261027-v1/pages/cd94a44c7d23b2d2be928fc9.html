            CE and WM use different versions of the internet explorer.&nbsp;There are some features which are not supported in WM5 including some javascript objects and methods - which I believe are used in the home page of your customer.  Did you test their application with the PocketBrowser? It may not work as well as this is&nbsp;the system libraries issue. We had similar problem here in Russia and ended up with a custom product which was MC9090-S but with Windows CE.  The only solution for WM (at least now) is to use 3rd-party browsers like Opera. Here is msdn link where you may find what is supported in IE on Windows Mobile   http://msdn.microsoft.com/en-us/library/ms879886.aspx
