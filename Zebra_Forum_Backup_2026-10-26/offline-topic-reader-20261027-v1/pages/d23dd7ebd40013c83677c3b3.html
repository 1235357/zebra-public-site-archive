            Are you using this for the "Packaging and Deployment" ?https://zebradevs.github.io/rfid-ziotc-docs/user_apps/packaging_and_deployment.htmlI have found some issues / mistakes when screen scraping from the example as follows:( Example App is known as "daveapp" for this example )possible reasons why your app may not start from Web UI.1) both start&stop scripts need to be "chmod 744 start_daveapp.sh", and "chmod 744 stop_daveapp.sh" to make the scripts "executable.2) "EXECUTABLE= daveapp" is not correct, "EXECUTABLE=daveapp" { notice the <space> between the Equals Sign and the appname in the script.}The python.py was fine.Please Note: On Ubuntu Linux - I use the "sudo dpkg-deb --build -Zgzip daveapp_1.0.1/" for the build of this DEB example.
