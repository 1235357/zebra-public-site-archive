            There are some registry settings that can be used to make the Windows Mobile/Windows Embedded Handheld browsers behave more like the older browsers.&nbsp; Not sure how much this will help,&nbsp; but try these.&nbsp; You can make a .reg file,&nbsp; copy it to the device and click on it to merge the registry changes.&nbsp; You might need a boot after that to have them take effect.
[HKEY_LOCAL_MACHINE\Security\Internet Explorer]
"MSHTML"=dword:0
; 0=PIE mode
; 1=IE6 mode
[HKEY_CURRENT_USER\Software\Microsoft\Internet Explorer\Main]
"MakeFit"=dword:00000002
; tested in PIE mode
; 2=OneColumn
; 1=FitToScreen
; 0=Desktop
