            Thanks Al.&nbsp; I noticed that.&nbsp; Another Product Manager told me that we were running out of new codes in some of the fields (a single character code can only use A-Z and 0-9).&nbsp; It's too bad that the product teams couldn't start a new configuration sheet that new MCD devices would follow.&nbsp; It looks like both the MC3100 and MC9500 are using their own unique product configuration codes, so it's too late for that.   When we don't have access to Solution Builder, it's nice to be able to whip out a single spreadsheet that deciphers the SKUs for us.&nbsp; For quick reference while out with customers, I've taking the current spreadsheet and added an additional tab for the MC3100 and MC9500 (see attached).
