                  The attached registry key configures the ES400 camera scanning to show the on-screen red/green target and disable the red LED scan line . I find this easier to use in practice and it is a requirement if you want to use picklist mode (although picklist mode is not enabled by this registry key since it slows down the overall decode process).   Best Regards,  Ian Hatton  EMS EMEA
