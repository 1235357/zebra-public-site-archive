            Hi Chetan,In the initialization, you set:reader.Events.setAttachTagDataWithReadEvent(true);This causes the TagData object to be joined to the RfidReadEvent and can't be accessed with the getReadTags function.// Replace this line 
TagData[] myTags = reader.Actions.getReadTags(100);

// With this line
TagData myTag = e.getReadEventData().tagData; If you'd rather get all the tags together as an array using getReadTags, set:reader.Events.setAttachTagDataWithReadEvent(false);
