            I have never done it specifically for a Jedi NIC, but I have disabled WLAN radios on our mobile computers with the following REGISTRY entry:
[HKEY_LOCAL_MACHINE\Comm\NetworkPolicy\WiFi]
"Disabled"=dword:00000001
If you place that in a text file, change the file extension from .txt to .reg.&nbsp; Place the file in the /applications directory on the device.&nbsp; When it reboots, the registry setting will be applied automatically, disabling the WiFi.
I hope this helps.
-Dino
