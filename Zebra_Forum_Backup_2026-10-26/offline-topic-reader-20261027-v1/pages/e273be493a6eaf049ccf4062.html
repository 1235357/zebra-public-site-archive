            Hi Paras.ODOO development framework - like React, Cordova, and other 3rd party development environments - is not supported by Zebra per-se.Rather we support Android Studio Target for Android for the TC21. And we support a Xamarin Forms Android target for TC21.The barcode Scanner however can be integrated with any "Intent-Based" method that a Development framework can use.ODOO would not be an exception to this.  So my suggestion to any user that uses 3rd party development frameworks - review and understand the Android Studio version of the "BasicIntent1" sample code. This will allow you to get the Barcode Data using Intents.( There is also a much simpler method if you do not wish to do this and that is to make a textbox with a blinking cursor in it available to your app.  Profile0 - using the keystroke will populate the text box the cursor is shown in.  - a good demo of this is to open chrome on the TC21 - goto "www.google.com" and make sure the cursor is blinking in the text box. - Then scan a barcode. )
