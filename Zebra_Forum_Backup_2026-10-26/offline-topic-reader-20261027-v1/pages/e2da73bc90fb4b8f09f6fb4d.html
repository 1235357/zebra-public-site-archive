            I was able to talk to Charlie U. this afternoon.&nbsp; There is no way to assure that the MAX volume is set at all times.&nbsp; The registry key provided will set the slider to the maximum setting, but if a user changes it, then the registry changes too.&nbsp; There is no key that only identifies the "default" setting.&nbsp; The registry key identifies the last setting and will use that value for subsequent calls.&nbsp; Including across a warm boot.&nbsp; Note, the setting doesn't take effect until a call is made.
