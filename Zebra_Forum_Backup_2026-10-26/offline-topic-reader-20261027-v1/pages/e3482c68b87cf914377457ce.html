            The default log level is for warnings. There should not be much logging going on unless there is an error. However, the log level can be overridden when starting the Browser Print with the -I option, which could significantly increase the amount of log messages. In any case, the log file does grow in size over time. But the log file can be managed by a script to move, discard or delete when the size exceeds a certain pre-set limit.
