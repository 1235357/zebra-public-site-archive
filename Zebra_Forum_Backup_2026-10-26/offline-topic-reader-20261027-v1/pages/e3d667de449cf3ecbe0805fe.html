            Not sure if the EPC memory is supported in the version of Datawedge on that unit - you can check by creating a new profile in the Datawedge menu , enabling the RFID plugin and then configure the reader.  If there is a Memory Bank option and you can select EPC then you can attach the profile to a test app in order to check that it works. If so, then the issue is likely to be in your DW profile creation code which would either need to be fixed or you could switch to using a pre-installed profile with the settings already configured (assuming you don't need to change the profile dynamically).
