            In general, fonts are copy-righted. The fonts pre-loaded on Zebra printers are authorized fonts. It's user's responsibility to obtain the proper authorization for using 3rd party fonts, such as Arial font. If you have the font file of Arial font, you can use the Printer Setup Utility to download the font file to the printer. Then you can assign a letter to the Arial font to use in ZPL.
