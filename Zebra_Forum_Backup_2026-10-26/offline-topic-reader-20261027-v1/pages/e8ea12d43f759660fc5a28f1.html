                  Hello,
I've been developing with the ZD500r for a year now. I still don't understand how the the configuration/calibration options work.
My questions are about the following menu options:
Sensors - Manual calibration
rfid - rfid calibrate
tools - manual calibration
After I do the three calibrations, I check the results by going to the ip address of the printer and access the 'View Printer Configuration' page. All is well so far.
The problem is, some of the configuration numbers are not consistent between calibrations.
label length (300 dpi ), +- 5
mark sensor, +- 3
mark gain, +- 2
and programming position (forward, mm), +- 12
These variations seem small ( less than 0.1 inches), but they can cause large errors. The biggest error is that labels will occasionally get skipped, when printing many in a row. I think this is because the sensor is looking for the rfid tag, not finding it, so skipping it and going to the next mark for the next label.
Any advice would be well received,

            Hi Justin, The quality of the media you're using may very well effect this. Does your RFID media have black marks on the back to indicate the gaps between labels?&nbsp; Mark media is less likely to have these issues.&nbsp; If you are not using Zebra media, we have run across other manufacturers who aren't the best at making sure the tag antenna is placed perfectly and consistently in the label.&nbsp; Also external lighting can sometimes have an effect on the process, especially the ZD printers. Try to make sure the lighting in the area with the printer is consistent and similar to how your customer will have it, especially if the media is not marked.&nbsp; In the end, you may need to switch media and/or adjust the label threshold&nbsp;setting.&nbsp;&nbsp;&nbsp;&nbsp;
Can you send the command below and post the image of what it prints? That might help determine if it's a gap(label length) or rfid calibration issue.
~JG&nbsp;
