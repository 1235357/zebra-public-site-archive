            Interesting you are not specifically referring to a Reader Platform:  ( FX-Series {ZIOTC},  or FXR-Series {ZIOTC} )Since you mention LLRP - my go-to assumption is using FX-Series.A quick tip.  On 123RFID Mobile  - vs 123RFID Desktop - there is no consistent "Balanced Performance" profile - that can be assessed - vs the "DEMO" mode seen ( Tag Read in the FX-Series menu.  - Which is "Fastest Read" profile similar on the Handheld RFD-based readers.  ( HH Embedded Readers are different from device platform to device platform. )For the Above - a few tips: Handheld - "Balanced Performance" profile uses typically:Antenna Power ~ 270 dBiMLink Profile ~ M4 240K  -- which will setup PIE & TARI as per this drop-down.Singulation Mode - Session_1  {S1}Tag Population - 30, Inventory State - STATE_A, SL_Flag - ALL.This typically gives a .5s to 1.5s responses from tags in Field - drven largely due to the Session = S1 (tag-based holdoff)For the Above - a few tips: Handheld - "Balanced Performance" profile uses typically:Antenna Power ~ 270 dBiM (300 for FCC readers)Link Profile ~ FM0 640K  -- which will setup PIE & TARI as per this drop-down.Singulation Mode - Session_0  {S0}Tag Population - 30, Inventory State - AB_FLIP, SL_Flag - ALL. This DEMO setting which is very quick has no resiliency - because the Link Mode contains no Miller Value Redundancy - which from some UHF tags can lead to Spurious Tag reads. (Mangled EPC - possible)  For EU-Based / RoW RFD readers the settings may be setup with max power as 270 dBiM and the Link Profile changes to M2 320K. ( No Mangled EPC data ) For FX-Series readers the above using LLRP can also be setup where the "Balanced Performance" is:Antenna Power ~ 2700 dBiLink Profile ~ Index 17  -- which will setup PIE & TARI as per this drop-down.Singulation Mode - Session_1  {S1}Tag Population - 100, Inventory State - STATE_A, SL_Flag - ALL. High Performance would be setup as:Antenna Power ~ 3000 (fcc) or 2700 dBiLink Profile ~ Index_1 (fcc)  / Index_33 (etsi)   -- which will setup PIE & TARI as per this drop-down.Singulation Mode - Session_0  {S0}Tag Population - 100, Inventory State - AB_FLIP, SL_Flag - ALL. ( Please Note that the Above is for FCC / ETSI RFID RFD / FX-Series Devices. )In ZIOTC - this is managed via the "/cloud/mode" or <mqtt> "get_mode/set_mode" JSON you provide the RFID Controls for the ZIOTC.For FXR90 - this Integration Guide shows the "MODE" config on PP48 :https://www.zebra.com/content/dam/support-dam/en/documentation/unrestricted/guide/product/fxr90-rfid-ig-en.pdfFor FX-Series with ZIOTC defined - this portal is your Guide - and Specifically the "/cloud/mode" / <mqtt> "get_mode/set_mode"Starting here: https://zebradevs.github.io/rfid-ziotc-docs/And HTTP-POST - "/cloud/mode" : https://zebradevs.github.io/rfid-ziotc-docs/api_ref/local_rest/index.html   ( Control sub-menu )And MQTT Broker - "get_mode / set_mode" : https://zebradevs.github.io/rfid-ziotc-docs/schemas/raw_mqtt_payloads/commands/index.html  (get operating mode)Using ZIOTC Modes - does not give a specific "link profile" to use - rather this is setup by the combination of the Profile Types (INVENTORY, SIMPLE, PORTAL) and / or config with settings that are "CUSTOM". There are other postings I have shared in the RFID Forum where the JSON used - may help you in your search.  (USE "RFID" ZIOTC, and "JSON" for forum responses that may be helpful. )

            ALSO A FOLLOW UP.For Developers - I tend to recommend to NOT use the DEMO mode "Fastest Read"  - Rather adjusting the "Balanced Performance" to a Reader Defined for "Better Performance as follows:Handheld - "Better Performance" profile:Antenna Power ~ 270 dBiMLink Profile ~ M4 240K  -- which will setup PIE & TARI as per this drop-down.Singulation Mode - Session_0  {S0}Tag Population - 100, Inventory State - STATE_A, SL_Flag - ALL.  / (Optionally you can use - "AB_FLIP" - but be careful - AB_FLIP can cause issues when using explicit "state_b" for prefilter conditions. )LLRP Fixed - "Better Performance" profile:Antenna Power ~ 2700 dBiLink Profile ~ Index_7(fcc/etsi) -- which will setup PIE & TARI as per this drop-down.Singulation Mode - Session_0  {S0}Tag Population - 200, Inventory State - STATE_A, SL_Flag - ALL.  / (Optionally you can use - "AB_FLIP" - but be careful - AB_FLIP can cause issues when using explicit "state_b" for prefilter conditions. )
