            By default Datawedge will support barcode scanning into any app including Chrome i.e. if you set focus on an input field of a webpage and press the scan trigger the barcode data should appear. If it does not, run Datawedge, select Profile 0 and scroll down to the Keystroke output section. Find the 'inter character delay' field and increase the delay to 6ms or more - this will slow down the barcode data coming from Datawedge which is required for some web-based apps. 
If you want to receive barcode data without focusing an input field, you will need to handle keyboard events from Javascript as detailed in the blog here: https://developer.zebra.com/blog/listening-keypress-events-datawedge
