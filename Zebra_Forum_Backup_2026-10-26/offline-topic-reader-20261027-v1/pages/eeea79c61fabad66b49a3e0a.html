            RIck,   &nbsp;If they are using the USB port for a memory stick then the&nbsp;RDP client (at least the latest version which is include in WM6.5)&nbsp;has an option to 'map&nbsp;device storage to the remote machine'. If this is enabled then the remote app should be able to access the files on the local USB memory stick (which appears as 'Hard Disk' in the file system when connected &amp; enabled)&nbsp;&nbsp;.
