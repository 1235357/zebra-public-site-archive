            There are a few way to change the darkness setting on the printer.


Use the Zebra Printer Setup Utilities for Windows software tool and send the following SGD to the printer. Refer to the ZPL Programming Guide for more info about the zpl.relative_darkness.
### Get the darkness
! U1 getvar "zpl.relative_darkness"

### Modify the darkness
! U1 setvar "zpl.relative_darkness" "100"
Use the Link-OS SDK for iOS and send the above SGD to the printer via the SGD.GET and SGD.SET API.
Put the above SGD into a configuration file and then send the file to the printer.
