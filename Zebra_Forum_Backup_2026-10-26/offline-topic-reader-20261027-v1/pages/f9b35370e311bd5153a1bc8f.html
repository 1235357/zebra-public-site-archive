                  Hi everyone,I'm trying to enroll a device in the send file to printer API.I was able to enroll a different printer previously, but I have not been able to get it to work for the second printer. (The first printer is being used by another department so it is no longer available).  When I send the file with the configuration string to the device, the device restarts as expected but it does not get enrolled.  I saw in the instructional video one of the common issues is related to the time and date of the device.Does anyone know what it should be? I tried setting it to local time (Sydney, Australia) but that did not fix it.

            Hi Katherine, 
There are a few things that could cause this.  Try the following:

Make sure the printer's firmware is up to date: https://www.zebra.com/us/en/support-downloads/printers.html
Set the real time clock (sounds like you already tried this)
Verify if you have any corporate firewalls that could be blocking
Get the connection log by using the Printer Setup App ( https://www.zebra.com/us/en/support-downloads/software/printer-software/printer-setup-utilities.html ) Select 'Open Communication with Printer' and send:{}{"weblink.logging":null}review what gets returned to find the actual connection issue.
