            Install any application of the Android market into the ET1 is quite simple (except "Market").  All that you need to do is download and install the applications using your Android phone and then use any backup utility, such as Astro File Manager choosing the option "Applications Manager".  Locate the application, check the mark at the right, and tap the button "backup"  This will save the APK files of the applications that you have installed in your phone to the SD card.   Then copy these APKs to the ET1's SD and use the file explorer of the ET1 to install Astro and the rest of the applications. You can even use Astro to install new APKs.   I have also installed the FTP Server "SwiFTP" in my phone and the FTP Client "AndFTP" in the ET1, so I can copy new apk files into the ET1's SD via wireless.   Hope this helps.  Regards
