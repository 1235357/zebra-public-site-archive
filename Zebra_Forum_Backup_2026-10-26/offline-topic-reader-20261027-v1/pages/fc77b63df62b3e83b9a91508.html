            To program (or encode) the RFID tags, you only need to add the RFID related ZPL commands to the ZPL script and send the script to the printer. There is no special treatment on the app side, as the app will treat the RFID commands the same way as regular ZPL commands. To program the RFID tags properly, you need to make sure that the RFID related ZPL commands are used correctly.
