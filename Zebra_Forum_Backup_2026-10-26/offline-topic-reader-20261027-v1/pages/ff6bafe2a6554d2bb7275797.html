            This issue is resolved.When specifying the tenant field, the ID (from the enrollment string) must be used.  I had been using my account email address.While this may seem obvious, it should be noted that if you attempt to use the API before a device is enrolled, with the account email address in place of the tenant ID, the error message returned will reference the correct tenant ID, which implies that the system is performing the ID translation on its own (ie, it does the work, but then doesn't utilize the resulting ID where it needs it).I'm good now.
