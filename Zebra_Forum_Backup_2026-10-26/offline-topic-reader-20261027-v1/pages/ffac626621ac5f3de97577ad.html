                  I'm trying to set up several ZD410 label printers to our network and if I run through the "configure printer connectivity" wizard and send to printer, it will send the changes to the printer. However, if I save the configuration file and try to send the file, either through the setup utilities communication window, or the printer driver's send file feature, the changes are not saved. I can see the data is being sent and I do a full reboot of the printer, but it won't change the values. Anyone seen this before? Thanks.

            When you save the network configuration in the Setup Utility to a file, the last statement in that file is a reset command. This means that the printer will take a reset after the file is sent to the printer. In your description, it seems you had to manually reboot the printer after sending the file. This indicates that the file may not have been successfully sent to the printer or the reset command is missing in the file, otherwise the printer would reset by itself after it receives the file.
Another thing to watch is the setting of the device.languages. Make sure the other printers have the same setting for the device.languages as the one you used to generate the configuration file. Because the commands used in in the configuration file are depending on the device.languages on the printer.
