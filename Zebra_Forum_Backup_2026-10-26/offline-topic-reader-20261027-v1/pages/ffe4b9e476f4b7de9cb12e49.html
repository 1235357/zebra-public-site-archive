                  Customer want to enable Wakeup Sources on TC75 automatically via StageNow or an MDM Software.
Background: The devices are used as well in a Depot opration inside the four walls.
For this operation a pistol grip is used. For the user it would be much more convinient, to use the pistol trigger to wake the device instead of the power button.
We are looking for a method to automatically set the Wakeup Source, in this case the Keypad, to ON during the staging process using StageNow or a MDM like SOTI.

            Solution:
There is an App (SetKBWakeup) available which will enable the Wake-Up source (Keypad).
It can be deployed via a MDM or Stagenow.
The App and souce code can be downloaded here:
http://gofile.me/23wdf/sf6cwAPX
For the future, I suggest to add it into MX, so it can be used by the EMDK, StageNow, or MDM vendors.
Big thank you to the guy who made this happen :-)
