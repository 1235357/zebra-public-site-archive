You are right. The ZQ220 doesn't support ZPL. To use the template based printing for both ZQ220 and ZQ620, you would use the CPCL. The DEFINE FORMAT and USE FORMAT on the CPCL user guide have the details on how to create a label template and store it on the printer (! DF SHELF.FMT), and how to call out the template (! UF SHELF.FMT) with variable values.

When using the ZebraDesigner, the default name for the template is LABEL.FMT. When choosing the ZQ220 in the ZebraDesigner, it automatically recognize the ZQ220 is a CPCL printer. When choosing the ZQ620, the ZebraDesigner may recognize it as a ZPL printer by default (unless the device.pnp_option is set to CPCL on the ZQ620 with the SGD: ! U1 setvar "device.pnp_option" "cpcl").

The template file can be stored directly to the ZQ220 printer from the ZebraDesigner by using the File->Store option. It can also be saved into a local file on the PC if the "Print to file" option is check-marked. The ! DF LABEL.FMT is the first line in the locally saved file. The local file can then be sent to the printer, which results in the LABEL.FMT, i.e., the template to be stored on the printer.

To recall the template file on the printer in CPCL, you will need to create a file manually by following the format defined in the USE FORMAT.

You can create a label template in CPCL for the ZQ220. As mentioned in the early reply, you need to use the File->Store option in the ZebraDesigner to generate the template file. Once the file is stored on the ZQ220 (by default, the filename of the template is LABEL.FMT). See the examples copied from the  DEFINE FORMAT and USE FORMAT after renaming the SHELF.FMT to LABEL.FMT.

#### Example of the stored template file in CPCL
! DF LABEL.FMT
! 0 200 200 210 1
CENTER
TEXT 4 3 0 15 \\
TEXT 4 0 0 95 \\
BARCODE UPCA 1 1 4 \\
TEXT 7 0 0 185 \\
FORM
PRINT
### Example of the recall format in CPCL
! UF LABEL.FMT
$22.99
SWEATSHIRT

Not sure if your ZQ220 printer supports the gap sensing or not. To set media sensor setting on the ZQ220 to gap, run the following SGD commands. If the setting can be set to gap, the getvar should return "gap". Otherwise, the ZQ220 may only support the media with black bars.

### Set the sensor setting to gap
! U1 setvar "media.sense_mode" "gap"

### Verify the sensor setting
! U1 getvar "media.sense_mode"
