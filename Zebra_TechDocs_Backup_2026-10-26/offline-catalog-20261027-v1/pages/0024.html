                                                    About Color Camera SDK for Linux
                                                
                                            
                                                            
                                    
                                
                                
                                    
                                        
                                            
                                            
                                                
                                                    Overview
                                                    This document provides installation and programming information that allow MP7 color camera enabled application development for Linux.
                                                    
                                                    

                                                    Supported Devices

                                                    For the compatible devices list, please visit following page.

                                                    https://www.zebra.com/us/en/support-downloads/software/developer-tools/bioptic-color-camera-sdk-for-linux.html
                                                    
                                                    

                                                    Supported Linux Distributions
                                                    
                                                    Color Camera SDK for Linux supports the following Linux Distributions.

                                                    
                                                        Ubuntu 18.04 (64bit)
                                                        CentOS 7 (64bit)
                                                    

                                                    

                                                    Version History

                                                    Version 1.0.0-39 - 01/2026
                                                    
                                                        Exposed "IsRedIlluminationPresent" API to detect the presence of red spots in the captured image frames.
                                                        Exposed "GetFrame" API for the user to request adjacent frames of a given frame.
                                                        Enhanced memory management.
                                                        Bug fix - Resolved the issue of decode events not getting triggered for SP72 device.
                                                    
                                                    
                                                    Version 1.0.0-34 - 07/2024
                                                    
                                                        Added Multi PID detection capability.
                                                        Added weight data and weight unit for the produce event.
                                                        Bug fix - Resolved the issue on multiple images saving which persisted with the save button.
                                                    
                                                    
                                                    Version 1.0.0-22 - 04/2024
                                                    
                                                        Optimized Camera SDK by exposing only the required symbols to the end user.
                                                        Implemented proper usage of SPD log within the Camera SDK.
                                                    
                                                    
                                                    Version 1.0.0-21 - 10/2020
                                                    
                                                        Bug fix - firmware update failed in camera after detaching while updating firmware.
                                                    

                                                    Version 1.0.0-17 - 06/2020
                                                    
                                                        Initial release.
