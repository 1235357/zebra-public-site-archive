                                        What's new in Zebra DNA Cloud 6.9



Overview

Zebra DNA Cloud (ZDNA) is an administrative solution for managing and configuring Zebra devices and apps. Like a cloud-based version of Zebra StageNow, ZDNA also performs licensing and other administrative tasks, and will eventually do much more. Also like StageNow, ZDNA leverages the power of Zebra's Mobility Extensions (MX), is controlled through a simple, intuitive UI, and can stand alone or work with a company's existing Enterprise Mobility Management (EMM) system.


The ZDNA dashboard provides a high-level system overview, including device and battery status, license allocation
 and available Android updates, refreshing every 24 hours. Click image to enlarge; ESC to exit.

Deployment Profiles for Wireless Insights can now be created using the “New Setup” button.

Device quantities are now accurately shown on the Group Page in Wireless Insights.

Assigning devices to a group now functions consistently in Wireless Insights.

Apps now install correctly on WS50 devices.

The status of Device Settings and App Setup deployments now display correctly when a Profile is reapplied to a device when there are one or more devices associated with the Profile.

Apps now download and install correctly when a device running Android 14 is enrolled through group association with Profiles created for Android 11 and/or Android 13.

The Presence Status filter in the App Setup >> Target Devices page now functions correctly.

Search-text highlighting in Device Settings and App Setup >> Target Devices sections now behaves correctly in filter search boxes.

Deployment status no longer incorrectly displays "In-Progress" when one or more devices are in "Issue" state.

Special Character Support

ZDNA 6.3 added support for an increased range of special characters for name and password fields of Wi-Fi APN and SSID configuration. Character support varies by Android version, device platform and applied device-specific LifeGuard patches, as follows. 


In the "New Device Setup" process: 

Android 11: APN configuration supports all special characters EXCEPT " ' < > & \. No patch required.

Android 13: APN configuration supports all special characters EXCEPT " ' < > & \ after applying the following LifeGuard patches:



4490 - Oct. 2025

6490 - Sep. 2025

6575 - Aug. 2025

SDM660 - Sep. 2025
 See Zebra device models by platform


Android 14: Supports alphanumeric and all special characters on all platforms

Android 15: Supports alphanumeric and all special characters on all platforms

In the "Create New Setting (Wizard)" process: 



All OSes except Android 11: Support for all special characters

Android 11: Supports alphanumeric characters only 


In the "Create New Setting (Advanced)" process: 



All OSes except Android 11: Support for all special characters EXCEPT " ' < > & \

Android 11: Supports alphanumeric characters only

On devices running Android 13:

ZDNA enrollment can require 5-10 min. to complete on device(s).

The “Enterprise” Wi-Fi Security Mode is not supported.

When first booting (or rebooting from either a cold boot or hard reset), all Zebra devices running Android 13 (or later) must be unlocked (using PIN, password or pattern) before the DNA Cloud client app can launch. Also applies to 6490- and 6375-platform devices running Android 11.

Configuring NFC settings sometimes displays an error despite being applied properly on the device.

When creating a managed configuration for Enterprise Keyboard, remapping a programmable key requires two backslash ("\") characters (rather than one, as documented).
