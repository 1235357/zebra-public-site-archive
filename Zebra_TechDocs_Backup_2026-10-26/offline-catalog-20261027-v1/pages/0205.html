                                        Overview

This section describes how to install the DEX Scan & Pair application on an Android mobile computer when used with a line of business application.



Install

To install DEX Scan & Pair on a supported Zebra device:


Download DEX Scan & Pair from Zebra Support and Downloads.

Uncompress the file into a folder on the host computer.

Copy the .APK file from the host computer to the mobile computer.

Install the .APK file on the mobile computer.

When the installation is complete, a verification message appears.
