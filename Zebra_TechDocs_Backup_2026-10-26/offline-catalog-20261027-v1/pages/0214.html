                                        Installation

Enterprise Keyboard Designer is installed in the same was as any Windows application. 


Download Enterprise Keyboard Designer installation file onto the target Windows system. 

Double-click the “EnterpriseKeyboardDesigner.exe” file to run the installer.

Follow prompts presented by the installer. Enterprise Keyboard Designer launches automatically when installation completes successfully.

Go to the EKD Usage page for step-by-step EKD usage instructions.
