Q: Is there a cost for Workstation Connect?

A: Sometimes. A ZWC license is included with most Zebra devices. The EXCEPTION is for Professional-series devices, which require the purchase of an MDNA Enterprise License bundle to activate this and other premium features. Learn more. 





Q: Can Workstation Connect features be configured using Managed Configurations?

A: Yes. Workstation Connect allows administrators to use Android Managed Configurations (also known as "app restrictions") to configure many of its features and to customize the desktop environment it presents to users. This can be done through Zebra DNA Cloud or a compatible Enterprise Mobility Management (EMM) system. 

For details, see the Workstation Connect Administrator's Guide beginning on Page 8. 



Q: What is the minimum LifeGuard update required on the device for compatibility with ZWC?

A: The minimum required software for using Zebra Workstation Connect varies by device. Please visit the Zebra Support Portal for LG requirements. 



Q: Where can I get the latest LifeGuard update?

A: The latest device software is available at the Zebra LifeGuard Updates page on the Zebra Support Portal. 



Q: What is the package name of the ZWC app?

A: The ZWC package name is:


com.zebra.workstationconnect.release




Q: Where can I get the ZWC app?

A: Zebra Workstation Connect app is available from:


The Zebra Support Portal

Google Play 




Q: Is the ZWC app required to connect my Zebra device to a keyboard, mouse and external monitor?

A: No. The Zebra Workstation Connect Cradle connects any supported device to the same external peripherals. The ZWC app must be installed only for Desktop Mode, which adds features for enterprise management and user productivity. 



Q: Which Zebra devices are supported by Zebra Workstation Connect?

A: For ZWC device support, please see the supported device list. 



Q: Are all USB ports on Workstation Connect Cradles the same?

A. No. Output voltage and recommended usage of cradle USB ports varies. Please refer to the relevant product reference guide for specific information. 



Q: What are the "primary" and "secondary" screens?

A: The device's built-in display is sometimes referred to as the "primary" screen. The "secondary" screen refers to the external monitor connected to the Workstation Docking Cradle.



Q: Why doesn't the audio level increase when raising the volume?

A: Increasing audio volume past a certain level sometimes causes a safety warning to be displayed on the primary (device) screen, where it might go unnoticed. If this happens, find the warning and tap "OK" to continue. 



Q: Why can't I log into any apps from the external monitor?

A: As a security precaution for apps that require user credentials, log-in dialog boxes do not appear on the secondary screen. Such apps can be used in the secondary screen after the credentials are provided on the primary. 



Q: Why isn't Workstation Connect automatically showing the Desktop after Lock-task Mode is enabled?

A: When Lock-task Mode is enabled on the device, the Desktop appears on the external monitor automatically at docking ONLY if the following two apps (by package name) are added to the "allowlist": 


com.zebra.workstationconnect.release

com.displaylink.desktop.oem


 Some EMM systems also require the License Manager service (com.zebra.licensemanagerservice) to be allowlisted. This also is required if blocking "all system apps."

Learn more about Access Manager allowlisting (aka whitelisting).



Q: Enterprise Browser doesn't automatically relaunch after "Relaunch and reset" is applied. What can I do?

A: After performing a "Relaunch and reset" action on an EB app, it must be relaunched manually through the ZWC UI.



Q: Why do administrative tasks involving StageNow sometimes fail?

A: Zebra temporarily changed the package name of its StageNow client app on some devices, which can cause actions involving the app such as Device-to-Desktop and Desktop-to-Device movements to fail. 

In such cases, changing the StageNow package name from com.symbol.tool.stagenow to com.zebra.devicemanager usually resolves the issue.
