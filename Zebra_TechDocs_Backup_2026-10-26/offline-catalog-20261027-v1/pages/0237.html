                        Link-OS Multiplatform SDK

                        
						APIs for Label and Receipt Printing
					


					
											
						The Link-OS Multiplatform Software Development Kit enables label and receipt printing from PCs, smart phones and tablets supporting the most popular operating systems. The Link-OS SDK makes creating powerful apps simple and straightforward.
						The latest release of each SDK is available for download at www.zebra.com/linkossdk and includes:

						
						  Libraries
						  API Documentation
						  Developer Demos with source code showing examples of common functionality
						

						
							  Looking for the latest Card printer SDK? Visit the Software Development Toolkit (SDK) for Card Printers page.
						

						
							  Visit www.zebra.com/linkossdk and sign up for new release notifcations.
