                                        Overview

Wireless Insights is a Zebra technology that provides visibility into device Wi-Fi and cellular analytics. The curated data enables administrators to monitor network performance and proactively identify and resolve potential issues before they impact worker productivity. 

A solution using Wireless Insights consists of two key components:


Wireless Insights - The core technology embedded on Zebra's supported devices that gathers insights from wireless connectivity events, internal states, and network packets.

Device Agent: An agent installed on the device to process and transmit the collected data to a dashboard. Use one of the following:


Wireless Insights Agent - Zebra's agent that captures and transmits data to Zebra's cloud, such as Zebra DNA (ZDNA) Cloud, for dashboard visualization. 

Vendor-specific Agent - An agent from a network infrastructure partner (e.g., Aruba/HPE, Extreme Networks, Juniper/Mist) that integrates with their specific dashboard (e.g., UXI, Intuitive Insights, Marvis).

 Important: Vendor-specific Agents capture Zebra’s Wi-Fi data, but not Zebra’s cellular data.​






Main Features

Wireless Insights provides the following key capabilities:


Proactively Monitor Network Health: Gain visibility into the performance of both Wi-Fi and cellular networks to identify issues early and minimize disruptive incidents.

Achieve End-to-End Network Visibility: View network performance from the device itself, providing an end-to-end picture of the user experience.

Access Real-Time and Historical Data: Retrieve comprehensive data and voice analytics across all connected Zebra devices, including metrics for:



Wi-Fi data

Cellular Data


Correlate Events to Find Root Causes: Automatically correlate network and client-side events to rapidly identify root cause of issues and pinpoint the location of performance degradation.

Perform Advanced Network Analysis: Conduct passive monitoring and on-demand synthetic testing of devices, with options for packet capture for detailed offline analysis.




New in v3.0


Now captures cellular data, including failure events, performance metrics, and location information, and sends it to Zebra DNA Cloud for fleet-wide analysis.

Added instructions for installing and configuring Wireless Insights using Microsoft Intune.
