                              The "SmartDocs" bar can customize this page to show only the features present on a particular Zebra device.

                               SmartDocs Nav works when viewing features of an individual CSP. To use, click on a CSP (i.e. "App Manager") and make at least one selection in the SmartDocs bar.  Unsupported features turn grey. Click the forward and back SmartNav buttons to scroll to the next and previous supported feature of that CSP (SmartNav is not supported on the feature matrix).

                                The MX Management System provides a uniform interface into privileged and unprivileged Android APIs on the device. Some features require a specific pairing of MX and OSX versions. More info.

                                    Overview
                                    The AutoTrigger Manager (AutoTriggerMgr) is used to configure automatic scan-triggering, which initiates scanning when a scan target is brought within proximity of the device sensor. Performing such functions would otherwise be manual. Automatic scanning is useful for such applications as those for supermarket self-service, in which a customer uses a hand-held device to scan items as they are placed in a shopping cart or basket. 


  This CSP is currently supported only on Zebra PS20 and WS50 devices.


Main Functionality


Set Trigger Mode as Automatic or Always On 

Set target distance for automatic scan triggering

                                    Trigger Mode
                                    Controls the trigger mode of the device, and whether automatic functions are invoked. For example, the "Auto On" parameter can be used to automatically activate automatic scanning when the device is placed in a shopping cart, holster or other designated location. When trigger Mode is set to Auto On or Always On (options 1 or 2), the scanner is activated automatically whenever a scan target is detected by the proximity sensor. When trigger Mode is set to Off (option 0, the default), all scanning requires manual triggering by the device user. 
                                        
                                        Note: Supported on PS20 and WS50 devices only.
                                        Parm Name: TriggerMode
