                                        Overview

Workflow Input provides options to capture data when executing tasks from a workflow process. User can perform actions like decoding a barcode with the imager or extracting text from a digital image.

Workflow Input consists of:


NG SimulScan Plus - integrates AI capabilities to highlight multiple barcodes in real-time as they are scanned from a form or label.

Free-Form OCR - recognizes text within a captured image and extracts the text in digital form. During image capture, the frame can be resized to ensure the target lies within the frame.

Picklist + OCR - allows for capturing barcodes and digitizing printed text from images, enabling seamless processing within a single workflow with optional customizable OCR rules for constraints and confidence levels.

OCR Wedge - allows for the automatic recognition and capture of text in specific use cases and its conversion into digital data for delivery to any application. The specific use cases are: license plates, vehicle identification numbers (VIN), tire identification numbers (TIN), shipping container IDs, utility meters and identification documents, where OCR can extract specific information from drivers licenses and identification cards.

Image Capture - provides versatile workflows to capture free-form images, stream continuous real-time frames, and digitize structured documents, all with integrated barcode decoding capabilities.


Use SetConfig to programmatically configure Workflow Input parameters in the DataWedge profile.

For developers, to capture data and images from Workflow Input (Free-Form OCR, Picklist + OCR, OCR Wedge, or Image Capture) see Workflow Input Programmer's Guide.

 Note:


While using Workflow Input for data capture, certain built-in Android applications may not allow the camera or imager's viewfinder to open due to restrictions imposed by Android.

License required message appears after device reboot or factory reset. If any Workflow Input options are toggled or accessed via the DataWedge UI after a device reboot or factory reset, a "License required" message may appear. This occurs if the Mobility DNA OCR Wedge license initialization process has not completed after the reboot or reset. This is resolved after some time elapses for the license initialization process to complete.

When retrieving scan data via Keystroke Output, Zebra recommends to add a delay using the "Send Pause" action in Advanced Data Formatting. This prevents potential data loss prior to data delivery.

NG SimulScan Plus

NG SimulScan Plus elevates the NG SimulScan MultiBarcode feature by integrating AI capabilities with barcode highlighting for an improved user experience. This feature provides real-time visual feedback, increasing both scanning accuracy and user confidence when capturing multiple barcodes with the device’s integrated scan engine or camera.

 Note: NG SimulScan Plus requires Workflow Input to be enabled. It is a separate and independent feature from the NG SimulScan MultiBarcode option under Barcode Input. Only one input type can be active at a time.

Primary Features and Benefits:


Barcode Highlighting - Provides instant visual confirmation by highlighting decoded barcodes in green, which is especially useful when barcodes are close together or partially obstructed. This gives operators confidence with every scan and lets them know immediately if a barcode was missed.

Instant Error Prevention - The real-time feedback immediately shows operators if a barcode was missed, allowing them to correct the scan on the first try.

Improved Efficiency - Prevents incomplete data, removes guesswork, and eliminates the need for rescanning, allowing operators to finish tasks more quickly.

MultiBarcode Acquisition - Captures multiple unique barcodes in a single scan session, ignoring duplicates.

Flexible Quantity Modes - Supports both Fixed and Variable barcode quantities to adjust for different label types.

Multi-Device Compatibility - Works with both the device’s integrated scan engine and its rear-facing camera


Use Case Example: Warehouse Package Processing:
A warehouse operator scanning a single package or pallet captures multiple barcodes that may be close together or partially obscured. They instantly see each barcode highlight in green as it is read. This real-time feedback allows them to immediately spot a missed scan and reposition the device, ensuring data accuracy before moving on. This improves efficiency in workflows like inventory checks, shipping validation, and manufacturing traceability.

Barcode Highlighting

This multibarcode workflow highlights successfully decoded barcodes in green directly on the viewfinder. This allows users immediate confirmation of successful capture, preventing missed scans or timeouts. Unhighlighted barcodes indicate the need to reposition the camera or adjust the angle before proceeding.

For camera-based scanning, the on-screen viewfinder also provides convenient controls to toggle the flash and adjust zoom levels during a scanning session.

Multiple barcode highlighting is enabled as part of the Basic MultiBarcode workflow feature under NG SimulScan Plus. MultiBarcode acquires multiple, unique barcodes from a form or label in a single scan session. Data is delivered once a specific quantity-based requirement is met. Duplicate barcodes are ignored. This supports two primary use cases:


Fixed Barcode Quantity - Used when forms or labels always contain the same number of barcodes and there is no other unique criteria to distinguish between them.

Variable Barcode Quantity - Used when the number of barcodes can vary from one form or label to another. A target range for the quantity of barcodes to capture can be defined, along with a specific timeout for the scan session.




Barcodes highlighted using Basic MultiBarcode

Configuration

Basic MultiBarcode parameters:


Input Source - Specify the input source to capture data: Imager or Camera.

Beam Timer/Session Timeout - Specify the timeout period for a scan session in milliseconds. Integer range: 0 – 60000 (increments of 500), default: 15000.

Illumination - Turn illumination on or off during the scanning session.

Zoom – (Camera only) Specify the camera zoom value. Range: 1 to 8, default: 1.

MultiBarcode Quantity Mode Select the barcode quantity to complete a scan session:



Fixed Quantity - For scanning a consistent, exact number of barcodes per session. The session only completes when the target quantity is met. If too few barcodes are present, the session times out with no data. If more barcodes than the target are in view, the scanner decodes the first unique ones it finds until the count is met (the return order is random).



Fixed # of Barcodes - Specifies the exact quantity of barcodes to scan. Maximum: 100.


Variable Quantity - For scanning a variable number of barcodes within a specified range. Data is returned only if the final count of unique barcodes is within the min/max range. If the count is below the minimum, no data is returned. Edge Case: If the Max # is set lower than Min #, it behaves like Fixed Quantity Mode, using the Max # as the target.



Min # of barcodes - The minimum number of unique barcodes required to complete a scan. Minimum value: 1.

Max # of barcodes - The maximum number of unique barcodes required to complete a scan. Maximum value: 100.



Viewfinder – Specify whether preview is enabled or disabled. This parameter is shown only when input source is set to Imager. For Camera, preview is always shown.

Feedback Parameters:



Decode Audio Feedback - Select an audio tone from to play for a successful decode

Decode Haptic Feedback - Enable/disable the device to vibrate for a successful decode. Note: For Android 13 devices, Touch Feedback must be enabled in Vibration & haptics under device Settings in order for Decode Haptic Feedback to function.

Decode LED Notification - When enabled, the Green LED flashes to indicate a successful decode

Ringer - Uses the Ringer volume setting for audio feedback

Music and Media - Uses the Music and Media volume setting for audio feedback

Alarms - Uses the Alarms volume setting for audio feedback

Free-Form OCR

Process documents or labels quicker and capture data with higher accuracy with Free-Form OCR. Free-Form OCR, powered by Google ML Kit using Text Recognition v2 (Beta), automatically captures data by recognizing text within a captured image and extracting the text in digital form. By leveraging Regular Expressions (RegEx), users can filter the decoded text to extract only the specific information needed. Combined with Auto-capture Mode, Free-Form OCR automatically captures the targeted data the moment it matches the defined RegEx rules, significantly accelerating workflows. 

During camera capture, the frame for the Region of Interest (ROI) is visible in the preview screen, allowing the user to adjust the frame to enclose the target text prior to data capture. A Mobility DNA Enterprise license is required for Zebra Professional-series devices.

Free-Form OCR segments capture text into 3 components:


Block - a contiguous set of text lines, such as a paragraph or column

Line - a contiguous set of words on the same axis or line, such as a line of text

Element - a contiguous set of alphanumeric characters ("word") on the same axis in most Latin languages or a character in others.


The image resolution is 1920 x 1080 for images captured from the camera.

See "Extract string data from the intent" in the Workflow Input Programmer's Guide.



Video demonstration of data capture using Free-Form OCR

Session Timeout - Specify the timeout period. Integer range: 0 – 60000 (increments of 500), default: 15000.

Latin (default)

Latin and Korean

Latin and Devanagari


Illumination - Turn on/off illumination during the scanning session.

Report OCR Data Rules - Specify the conditions and actions to decode the selected text. Available options:



Conditions - Define the conditions in which the rule should be applied:



RegEx - Filters and extracts key information from the decoded OCR text by using a regular expression pattern. For example, isolate a PO number on a shipping label.

RegEx Search - Enter the regular expression pattern in Perl Compatible Regular Expressions (PCRE) format to filter and extract the target data. In Free-Form OCR, the RegEx is applied at the Block level to the entire block of text within the Region of Interest (ROI). 
Note on Multiline Matching: When the text contains multiple lines, prepend the (?m) flag to the RegEx. This changes the behavior of the ^ (start) and $ (end) anchors, allowing them to match the beginning and end of each line within the text block, rather than only the start and end of the entire text block. 



Example: To find a 10-digit number starting with “45”, use the expression: \b45\d{8}\b



Actions - Define the action to take when the condition is met:



Report – Return the captured text based on the Conditions specified.



Auto-capture Mode (RegEx) - Enables or disables (default) automatic data capture. Note: Configuring OCR Data Rules is mandatory for successful data reporting. 



When enabled: OCR data is automatically captured upon session initialization once text matching the defined RegEx rules is identified. The screen also defaults to a full-screen Region of Interest (ROI), though developers can change this.

When disabled: Manual confirmation via trigger press or on-screen control is required.


Output Image – Specify the output image mode:



Disable - Do not output image

Zoom – Specify the camera zoom value: 1 to 8. Default value is 1.

Ringer - Uses Ringer volume setting for audio feedback

Music and Media - Uses Music and Media volume setting for audio feedback

Alarms - Uses the Alarms volume setting for audio feedback

Notification - Uses Notification volume setting for audio feedback (default)



Region of Interest (ROI) Size - Define the capture area on the screen.



Width - % of Screen - Sets the width of the ROI bounding box as a percentage of the screen. Default: 40.

Height - % of Screen - Sets the height of the ROI bounding box as a percentage of the screen. Default: 10.


Auto-Remember Resize - When enabled, the ROI retains its manually resized dimensions across sessions. By default, this is disabled, and the ROI reverts to its default size at the start of each session.

Picklist + OCR

Picklist + OCR enables the capture of barcodes and digitization of printed text from images, allowing seamless processing within a single workflow and eliminating the need to switch between functionalities. Data is captured using either the camera or imager. Picklist + OCR supports recognition of a word or line of text, with optional customizable OCR rules for constraints and confidence levels. By leveraging OCR Data Rules (identifiers or RegEx), users can filter the decoded text to extract only the specific information needed. Combined with Auto-capture Mode, Picklist + OCR automatically and instantly captures target data the moment the aimer is pointed at text matching the defined RegEx rules, significantly accelerating workflows.

If using Keystroke Output to output data scanned from Picklist+OCR, Zebra recommends to send a pause (approximately 200 ms) using Advanced Data Formatting rules before sending the scanned data.



Video demonstration of data capture using Picklist+OCR

Ignore Case Sensitivity - If enabled, the captured text is not case-sensitive and does not need to match the letter case of the word in the Contains field. If disabled, the captured text is case-sensitive, and the letter case must match the characters in the Contains field.


RegEx - Filters and extracts key information from the decoded OCR text by using a regular expression pattern. For example, isolate a PO number on a shipping label.

OCR Confidence – Specify the minimum confidence required to return the word decoded using OCR. Integer range: 0 - 100, default: 75.

Viewfinder – Specify whether preview to be enabled / disabled. This parameter is shown only when input source is set to Imager. For Camera, preview is always shown.

OCR Wedge

OCR Wedge uses machine learning to enable fine-tuned, use-case specific models to extract data in real-time via the Zebra Android device camera without the need for a data connection. Supported configurations:


    
         
           
        License Plates (See supported countries/states.)
    
    
         
           
        Identification Documents (See supported document types by state, country, province.)
    
    
         
           
        Vehicle Identification Number (VIN) 
    
    
         
           
        Tire Identification Number (TIN) 
    
    
         
           
        Shipping Container ID 
    
    
         
           
        Meter Reading
    




Main features:


Automatic text data capture using trained machine learning models

Visual feedback provided to guide users during data capture

On-device processing of data being captured


More information on each configuration follows in the sections below. To learn more, see OCR Wedge.

Region/Country of origin: US, EU. See list of states/countries supported.

Dark text on brighter background

Vehicle Identification Number (VIN)

Meter

Meter OCR Wedge supports the automatic recognition of most analog, dial, and digital meter readings. 
Read utility meters, such as gas, electricity, or water meters, while automatically detecting half-digits, decimal points and changing values (in digital meters).


Field service meter reading


    
        
            
            
        
          
        
            
            
        
          
        
            
            
        
    


Samples of analog, dot matrix (digital), and electric (digital) meters




Video demonstrating meter readings



Meter types supported:


Analog – commonly electricity, gas or water meters



Optimal performance up to 3 decimal digits and 4-10 pre-decimal digits.

Supports black and white backgrounds.


Digital – commonly heat meters:



Read from LCD and LED displays

Typically, 7-segment display with at least 3 digits

Dot matrix display – automatic comma detection for commas displayed as a separate character

Heat meter with 4-6 pre-decimal digits and up to 3 decimal digits


Dial – commonly electricity meters



Supports 4 and 5 main dials and up to 1 (red) decimal dial (labeled with numbers)

Only numeric values are returned

Read black or red dials on white background.

The dials are not required to be in a straight line and can be arranged in an arc or slightly shifted.

Dials arranged in a circle are not supported.



Performance may be impacted by contributing factors such as reflections, lighting conditions, debris (e.g., dirt), scratches, etc.

Free-Form Image Capture

Free-Form Image Capture allows an image of any form (not restricted to a document or label) to be captured by either the built-in internal imager or camera with the option to highlight and/or decode any barcode present. The capability for the internal imager to capture an image is useful if there is no built-in camera on the device. When capturing images from the camera, the image resolution is 1920 x 1080.

How it works:


The initial trigger press (soft button or hard trigger) on the device initiates a session; the preview frame appears. As barcodes are being read, they are highlighted to let the user know they have been detected.

The next trigger press captures the image and displays it in the preview.

If Decode and Highlight Barcodes option is enabled, it returns the image and decodes the barcodes that were highlighted.

Imager Frames Streaming

Imager Frame Streaming allows applications to capture continuous image frames directly from the device imager, enabling simultaneous processing, display, and barcode capture within a unified workflow. Frame data is delivered to the application via Intent Output utilizing Content URIs, empowering apps to reconstruct full frames and process them with low latency.

The streaming behavior is dictated by the configured Image Capture Mode:


Image Capture Only: Streams continuous raw image frames directly to the application.

Image Capture and Decode: Streams image frames while simultaneously identifying and decoding barcodes in real-time. The application receives both the raw image data and the decoded barcode. Feedback for successful decodes is configurable for audio, haptic, and LED feedback.


How it works:


Session Initiation: A trigger event (software button or hardware trigger) initiates the continuous streaming session. If the Preview feature is enabled, a live viewfinder is displayed to the user.

Data Delivery: Frame data is streamed continuously to the application based on the selected Image Capture Mode (Image Capture Only or Image Capture and Decode).

Real-Time Feedback: During an Image Capture and Decode session, successful decodes trigger immediate, configurable feedback mechanisms (audio, haptics, and LED indicators) without interrupting the video stream.

Targeting Assistance: The hardware Aimer and Illumination settings can be configured to enhance frame quality and targeting accuracy during the active stream.

Session Termination: The streaming session remains active until the user releases the trigger, the defined Session Timeout limit is reached, or the application explicitly issues a termination command.


 Performance Recommendation: When utilizing Intent Output with a content provider to receive frames, Zebra recommends requesting the next frame only after the current frame is fully processed by the application. This prevents data backlogs and ensures optimal stability.

Scan and Snap

The Scan And Snap workflow enables users to read a barcode at a distance and to capture a color image of the scene during a single trigger session using the AC670 scan engine (imager). When this workflow is enabled, pressing the trigger starts the session, and releasing the trigger ends it.



Requirements


Supported Zebra Devices: Zebra mobile computer devices equipped with the AC670 scan engine running Android 15 (or higher) on the QC6690 platform (such as the TC201, TC501, and TC701). For a list of supported devices by platform, refer to the Zebra Mobile Computer Device Platform guide.

Scanning Framework version: 43.63.44.0 or higher

DataWedge version: 15.0.90 or higher
