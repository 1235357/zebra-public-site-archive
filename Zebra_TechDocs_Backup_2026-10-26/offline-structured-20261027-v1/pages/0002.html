Developer Tools and Guides

Build apps for Zebra mobile computers, scanners and printers for data capture and other applications using Zebra device APIs.

[Image: no alt text | https://techdocs.zebra.com/images/products/ai-dc-sdk.png]

AI Data Capture SDK

The SDK features ready-to-use AI models that streamline AI vision integration into enterprise applications, enhancing everyday tasks across a wide variety of industries. 

Go to section:
[Image: no alt text | https://techdocs.zebra.com/images/products/android.png]

Android Versions A-to-Z

Reports from the Android and Zebra development communities describing changes to Android versions from Lollipop to the present, and their effect on Zebra devices and apps. 

[Image: no alt text | https://techdocs.zebra.com/images/products/mdna.png]

Android 11+ Migration

Moving to Android 11, 13 or beyond? There are changes to the platforms that run most Zebra devices. These guides explain what's changing and why, when each change is happening and how to adapt. 

Go to section:
[Image: no alt text | https://techdocs.zebra.com/images/products/dcs_scanner.png]

Barcode Scanner Software

Software Development Kits (SDKs) for building data-capture apps that use Zebra's dedicated barcode scanners.


Go to section:
[Image: no alt text | https://techdocs.zebra.com/images/products/bluetooth-mgmt.png]

Bluetooth Insights

An Android library that gives device apps visibility into Bluetooth peripheral activities.


Go to section:
[Image: no alt text | https://techdocs.zebra.com/images/products/datawedge.png]

DataWedge

An app included with Zebra Android mobile computers that provides data capture and processing services for virtually any other app on the device.

Go to section:
[Image: no alt text | https://techdocs.zebra.com/images/products/emdk-for-android.png]

EMDK For Android

The Enterprise Mobility Developer Kit for building Java apps for Zebra Android mobile computers includes Java sample projects using EMDK APIs for data capture.

Go to section:
[Image: no alt text | https://techdocs.zebra.com/images/products/emdk-for-xamarin.png]

EMDK For MAUI/Xamarin

The Enterprise Mobility Developer Kit for building MAUI/Xamarin apps for Zebra Android mobile computers includes sample projects using C# APIs for data capture.

Go to section:
[Image: no alt text | https://techdocs.zebra.com/images/products/enterprise-browser.png]

Enterprise Browser

A platform for building apps that work with virtually any Zebra mobile computer using standard web technologies such as HTML5, CSS3 and JavaScript.

Go to section:
[Image: no alt text | https://techdocs.zebra.com/images/products/mobile-parcel.png]

Mobile Parcel

Facilitates contactless, on-demand parcel dimensioning with integrated time-of-flight sensors.


Go to section:
[Image: no alt text | https://techdocs.zebra.com/images/products/oemconfig.png]

OEMinfo

Standards-based APIs through which apps can acquire information about Zebra device capabilities and settings.


Go to section:
[Image: no alt text | https://techdocs.zebra.com/images/products/link-os.png]

Printer SDK

The Link-OS SDK makes creating powerful printer apps for label, receipt and card printing simple and straightforward.


[Image: no alt text | https://techdocs.zebra.com/images/products/rfid.png]

RFID SDK

Software development kits, guides, code samples and powerful tools to take full advantage of Zebra RFID readers.


Go to section:
[Image: no alt text | https://techdocs.zebra.com/images/products/data-security.png]

Secure Storage Manager

Securely store data to be exchanged between apps and optionally persist data across an enterprise reset.


Go to section:
[Image: no alt text | https://techdocs.zebra.com/images/products/emdk-for-android.png]

VAS SDK

An Android library built on top of the Android NFC APIs and VAS protocol for reading NFC-enabled passes.

Go to section:
[Image: no alt text | https://techdocs.zebra.com/images/products/emdk-for-android.png]
