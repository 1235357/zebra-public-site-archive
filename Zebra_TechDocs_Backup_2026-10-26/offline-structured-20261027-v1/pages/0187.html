Set Up USB Host Manager

Zebra USB Host Manager 1.0

Overview

Zebra USB Host Manager (UHM) is an Android app available from the Zebra Support Portal (link below), and is installed just like any other Android app.

Requirements

  • USB Host Manager app from Zebra Support Portal. Download now.
  • At least one supported device on which to create device-usage rules. See supported devices and OS versions.
  • One or more target devices with Android 11 (or later) and MX 11.6 (or later) on which to test rules.
  • If using Zebra Workstation Connect: Requires ZWC 1.6 (or later) installed on target device(s).
    Download Workstation Connect from:
    • Google Play
    • Zebra Support Portal
