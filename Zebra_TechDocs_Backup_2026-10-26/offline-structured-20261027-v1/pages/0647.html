Manage Profiles

DataWedge 15.0

Overview

DataWedge can be associated with any app on the device and called upon to acquire barcode, mag-stripe or other data, to process the data in a specified way, and to pass it to one or more apps. Therefore, each Profile must specify these three things:

  1. Input device determines whether to acquire data from barcodes, a magnetic stripe, RFID (radio-frequency identification) tags, a serial port, voice or SimulScan.

  2. Process options manipulate the acquired data using Basic or Advanced data formatting processes.

  3. Output method specifies whether to pass data as keystrokes, within an intent and/or over an IP network.

See DataWedge Profiles for more information.

Create a New Profile

To create a new profile (device screens may vary depending on device system and DataWedge version):

The launcher icon for DataWedge 7.x is shown below. Locate the DataWedge icon and tap it to begin.

[Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/1_datawedge_launcher.png]

Launcher icon for DataWedge

On a new installation, the DataWedge Profiles screen appear similar to that of the image below, showing the three included (visible) Profiles. White text indicates enabled Profiles. Also shown is a fourth, disabled Profile (grey text) that's not present out-of-the-box. [Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/2_profile_screen.png]

Note: If DataWedge had been opened previously, it will reopen to the last screen used. If necessary, press BACK until the Profiles screen appears.

2. Tap the "hamburger" menu and select -> New profile.
[Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/3_options_menu.png]

3. Enter a name for the new Profile and tap OK. The Profiles list appears, similar to the image in Step 4, below.
[Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/4_name_profile.png] Zebra recommends that Profile names be unique, contain alpha-numeric characters, and be short in length to avoid possible import/export profile issues.

Associate the Profile with App(s) and/or Activities:

4. Tap the Profile to be associated: [Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/5_profile_list.png]

5. From the Profile screen, tap the "Profile enabled" checkbox to enable it, then tap "Associated apps" to link it with an app or activity: [Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/6_enable_profile.png]

6. Tap the menu and select -> New app/activity. A list appears with all apps and activities installed on the device. [Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/7_associate_menu.png]

7. From the device apps/activities list, select the app or activity to associate with the Profile being edited. When an app is selected, its activities list appears (see Step 8). [Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/8_select_app_to_associate.png]

8. From the app activities list, tap the asterisk to associate all app activities with the Profile, or tap on an indvidual activity to use DataWedge for that specific activity only: [Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/9_pick_asterisk.png]

9. The app now appears in the Profile associations list as below. Repeat Steps 6-9 until all desired apps and/or activities are associated. [Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/10_confirm_association.png] :. When finished adding associations, tap the back button to return to the Profile screen.
;. Confirm that the "Profile enabled" checkbox is checked for the new profile created.
<. If needed, check that Barcode Input and Keystroke Output are enabled.

Configure a Profile for Input, Processing and Output:

10. From the Profile screen, enable the desired Input device (scrolling down as necessary). For example, the Barcode Input displays an option for Scanner selection: [Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/11_enable_new_profile.png]

11. From the Scanner selection screen, select the desired scanner or imager. Tap BACK to return to the Input screen. [Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/12_select_input.png] Note: Lists such as the one above display only devices that are present on (or connected to) the unit being configured. For related information, see Scanner Selection in the Barcode Input guide.

12. From the Decoders screen (accessible from the Input screen), select only the decoders required by the application to optimize scanning performance. Tap BACK to return to the Input screen. For more information about configuring Decoder parameters, see the Barcode Input Guide. [Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/13_select_decoders.png]

13. From the Profile screen, select the desired Output method (scrolling down as necessary). For example, the image below shows that Keystroke Output is enabled:

[Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/14a_select_output.png]       [Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/14b_select_output.png]

Note: Output sections contain selectors for configuring "Basic data formatting" and "Advanced data formatting." These are the data processing options.

14. Select the Basic data formatting for options on inserting special keystrokes or adding text before (prefix) and/or after (suffix) the collected data:
[Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/15_basic_data_formatting.png]

See Basic Data Formatting and Advanced Data Formatting sections for more information about processing of acquired data.

The app now uses DataWedge for barcode data acquisition.

Editing Profiles

To modify, rename, delete or clone a profile:

1. Long-press the Profile name to bring up its Context menu.

2. Tap on the desired action: [Image: no alt text | https://techdocs.zebra.com/datawedge/latest/guide/createprofile/profile_context_menu.png]
Editing a Profile also can be started by tapping the Profile name in the Profile list.
