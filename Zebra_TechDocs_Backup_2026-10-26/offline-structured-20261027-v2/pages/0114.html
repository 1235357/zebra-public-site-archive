Demo

Zebra VAS SDK 4.1

Overview

The NFC Ticket Demo application demonstrates how to read Apple VAS, Google Smart Tap, Samsung Wallet passes, and other NFC tags on Zebra devices that support ECP 1.0 and ECP 2.0. To read an NFC pass from the Apple or Google Wallet, the application utilizes a specific collector ID for configured for Zebra pass integration across mobile devices.

Requirements

See Requirements. The VAS SDK download includes the NFC Ticket Demo application and Zebra VAS Service.

Installation

There are 2 main components for this demo:

  1. Zebra VAS Pass stored in one of the following:
    • Apple Wallet on the iPhone
    • Google Wallet on the Android phone
    • Samsung Wallet on the Android phone
  2. Zebra NFC Ticket Demo application installed on the certified Zebra Android mobile computer, see the Zebra Support Portal for supported devices

Store VAS Pass

This section explains how to retrieve and save a Zebra VAS Pass in Apple or Google Wallet.

Note: Samsung Wallet passes must be obtained from the Samsung Developer site.

For Apple Wallet (iPhone):

  1. Connect the iPhone to the internet.
  2. Swipe down from the right top corner of the home screen.
  3. Tap on the scanner icon.
  4. Scan the following QR code: [Image: no alt text | https://techdocs.zebra.com/nfc-vas/latest/guide/demo/qrcode.jpg]
  5. A URL opens on the iPhone, connecting to the database for Pass setup.
  6. When prompted, enter the required information in the fields (e.g. name, email address, phone number).
  7. Follow the on-screen instructions to complete the pass installation.

For Google Wallet (Android):

  1. Connect the Android phone to the internet.
  2. Swipe down from the right top corner of the home screen.
  3. Tap the scanner icon.
  4. Scan the following QR code: [Image: no alt text | https://techdocs.zebra.com/nfc-vas/latest/guide/demo/qrcode.jpg]
  5. A URL opens on the Android device, connecting to the database for Pass setup.
  6. When prompted, enter the required information in the fields (e.g. name, email address, phone number).
  7. Follow the on-screen instructions to complete the pass installation.

Install Zebra VAS Demo

  1. Extract the files from the Zebra VAS SDK downloaded from Zebra Support Portal
  2. Connect the certified Zebra mobile computer to the host computer.
  3. Copy the service and demo app .APK files to the mobile computer.
  4. Run the Zebra VAS Service .APK to install the Zebra VAS Service.
  5. Run the NFC Ticket Demo app .APK to install the demo app.

Using the Demo

Follow this procedure to operate the demo.

Note: The application versions shown in the screenshots may vary.

  1. Open NFC Ticket Demo on the certified Zebra mobile computer. [Image: no alt text | https://techdocs.zebra.com/nfc-vas/latest/guide/demo/app-main-screen.png]

  2. Activate the pass stored in the mobile wallet.

    [Image: no alt text | https://techdocs.zebra.com/nfc-vas/latest/guide/demo/ios-demo-1.jpg]     [Image: no alt text | https://techdocs.zebra.com/nfc-vas/latest/guide/demo/android-demo.jpg]
    Pass displayed in Apple Wallet           Pass displayed in Google Wallet

  3. Move the iPhone or Android device in close proximity towards the NFC reader on the Zebra mobile computer to read the VAS pass.

    • If the read is successful, a green check enclosed in a green circle is displayed on the Zebra mobile computer and the data is displayed on the Zebra mobile computer.

      [Image: no alt text | https://techdocs.zebra.com/nfc-vas/latest/guide/demo/read-success.png]           [Image: no alt text | https://techdocs.zebra.com/nfc-vas/latest/guide/demo/ios-demo-2.jpg]           [Image: no alt text | https://techdocs.zebra.com/nfc-vas/latest/guide/demo/android-demo.jpg]
      Zebra mobile computer successful read           Apple iPhone successful read           Google Android phone successful read

    • If the read is unsuccessful, the message "Scan Failed, Try Again" is displayed with a red cross on the mobile computer. [Image: no alt text | https://techdocs.zebra.com/nfc-vas/latest/guide/demo/read-fail.jpg]
