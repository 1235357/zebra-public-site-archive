Wireless Insights Agent

Wireless Insights 3.0

Overview

The Wireless Insights (WI) Agent Agent captures wireless data from the Wireless Insights service and transmits it to Zebra DNA Cloud for dashboard visualization to help administrators ensure optimal wireless network performance. This guide provides instructions to install and configure the Wireless Insights Agent, tailored to the specific Enterprise Mobility Management (EMM) system in use or using Zebra DNA Cloud for deployment.

Software Update Required
The legacy Wireless Insights server is scheduled to be decommissioned on August 24, 2026, rendering Wireless Insights agent apps prior to v3.0.5 inoperable. To avoid service disruption, all customers must install or upgrade to Wireless Insights v3.0.5 (or later) prior to this date.

Requirements

Core Requirements

  • Upgrade Required: Install Wireless Insights Agent v3.0.5 or higher before August 24, 2026, to prevent service disruption due to legacy server decommissioning.
  • Supported Device and Operating System: The device model and its Android/OS version must be listed on Compatible Hardware on the Zebra support portal.
    Warning: Using an older OS version may result in suboptimal performance and require extra setup steps. For instructions, see Setup - EMMs Without Auto Options.
  • Delegation Scope (Conditional): Certain configurations require an additional Delegation Scope .xml to authorize the agent on the device. Whether this step is required depends on the device build; see “Compatible Hardware” table in Requirements to confirm, and refer to (Optional) Deploy Delegation Scope XML - EMMs Without Auto Options for instructions.
  • Wireless Insights License:
    • A valid license is required; see Licensing for details.
    • For Zebra Professional-series devices a Mobility DNA (MDNA) enterprise license is required.

Feature-Specific Requirements

Wi-Fi VoIP Analysis: This feature supports the SIP-RTP protocol.

Configuration for Non-Standard SIP Ports: If a SIP port other than 5060 is used, the following steps are required for initial setup:

  1. Send the intent to stop Voice Analysis.
  2. Send the intent to start Voice Analysis, specifying the custom SIP port.

Unsupported Technologies for Wi-FI VoIP Analysis:

  • Protocol: WebRTC or similar cloud-based protocols.
  • VoIP Apps: Zebra Work Cloud Sync, Microsoft Teams, Zoom Phone.

Limitations

The Wireless Insights Agent is not compatible with devices configured for an Android Enterprise Work Profile, (formerly Corporate-Owned, Personally Enabled (COPE) Mode). This mode, which creates separate work and personal profiles on a single device, prevents the agent from functioning properly.

Prerequisites

Prerequisites for deploying Wireless Insights:

  • Download Agent for EMM Deployment: If deploying the Wireless Insights Agent via an Enterprise Mobility Management (EMM) system, the .apk must first be downloaded. It is available from the Zebra support portal or the Google Play Store.
  • Establish Network Connectivity: The device must be configured with a network profile that allows a connection to Wi-Fi and/or cellular.

Setup: ZDNA Cloud

This section offers guidance for the installation and configuration of the Wireless Insights Agent using Zebra DNA Cloud.

Note: When using Zebra DNA Cloud to setup the Wireless Insights Agent, the entire installation and configuration process is managed directly within the platform.

I. Enable Wireless Insights Service

Activate the Wireless Insights service to allow the agent to collect wireless data. This configuration is required only once. In the Zebra DNA Cloud console, enable Wireless Insights.

After enabling the service, from the My Service screen, copy the Wireless Insights Enrollment Configuration for use in a later step. [Image: no alt text | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/service_enable.jpg]

Create and apply a policy to install the Wireless Insights Agent and configure it through Managed Configurations.

  2. Click Next. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/zdna-2.png]

  3. If desired, enter a description. Click Next. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/zdna-3.png]

  4. If desired, edit the App Setup Name. Click Apply Now. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/zdna-4.png]

  5. Select the target device(s). Click Apply. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/zdna-5.png]

III. Apply License

To activate the Wireless Insights license in production environments (not required for trials), apply the license using any standard Zebra software license installation method. Detailed procedures are available in the Zebra License Manager User Guide.

For testing or small-scale installations, use Zebra’s StageNow tool to generate a barcode or XML from the license parameters. See the Activate License via StageNow section for an example StageNow profile. The resulting .xml file can also be deployed using an EMM.

Follow these steps to apply Wireless Insight licenses:

  1. Follow steps to Activate License via StageNow.
  2. In the ZDNA Cloud web console, go to My Devices in the left menu and choose one of the following actions:
         • Locate the target device from the list, click the options menu at the end of the row, and select Submit XML.
         • For multiple devices(s), select the target device(s), click Bulk Actions, and then click Submit XML.
    [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/zdna-8.png]
  3. Paste the License xml file content from step 1, then click Submit. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/zdna-9.png]

IV. Check Agent Connection

To verify the successful deployment and operation of the Wireless Insights Agent, follow these steps to check its connection status on both the device and within the ZDNA Cloud platform.

Device

Ensure that the Wireless Insights Agent is connected to the ZDNA Cloud server by checking the following statuses in the Wireless Insights Agent:

  • Feature Running: Voice is Running

  • ZDNA Connection (under External Connections):

    • Connected - Indicates the Wireless Insights Agent is successfully deployed
    • Activated - Indicates the Wireless Insights license is applied

    [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/agent-check.png]

ZDNA Cloud

In the ZDNA Cloud web console, go to Support Tools > Wireless Insights from the left menu. Verify that the device status, whether in its assigned group or unassigned group, shows "Active." This confirms successful enrollment.

[Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/zdna-device-active.png]

II. Install and Configure Agent

Install the Wireless Insights Agent on the enrolled devices and apply the configuration through Managed Configurations. Two methods are provided below — select one based on the organization’s app-distribution policy.

Method 1: Install via Google Play Store (Recommended)

The recommended method for installing Wireless Insights Agent is through the Google Play Store.

  1. In the SOTI MobiControl web console, go to APPS > ADD APP > Android > Android Enterprise. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-1.png]
  2. Enter a name for the app policy, then click the APPS tab. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-2.png]
  3. Click +. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-3.png]
  4. For App Source, select Managed Google Play. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-4-googleplay.png]
  5. Search for "Zebra Wireless Insights" and click Select. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-5-googleplay.png]
  6. Click the three-dot menu icon and select Configure. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-6-googleplay.png]
  7. Click Installation Options. Select Mandatory for Deployment Type and enable Launch App After Installation. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-7-googleplay.png]
  8. Click Managed App Config. Toggle on Enable Managed App Config. For WI API Request, paste the Wireless Insights Enrollment Configuration copied from ZDNA Cloud in step I. Click Save. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-8-googleplay.png]
  9. The policy is created. Click Save and Assign. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-9-googleplay.png]
  10. Search for the enrolled device and select it. Click Assign. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-11.png]

Method 2: Install via APK

Instructions for Wireless Insights Agent installation via APK using SOTI MobiControl.

  1. In the SOTI MobiControl web console, go to APPS > ADD APP > Android > Android Enterprise. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-1.png]
  2. Enter a name for the app policy, then click the APPS tab. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-2.png]
  3. Click +. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-3.png]
  4. For the App Source dropdown, select Enterprise. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-4.png]
  5. By default, Import is selected for the Source. Click Browse File and select the Wireless Insights .APK file. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-5.png]
  6. After the file is uploaded, click Configure. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-6.png]
  7. Click Installation Options. Deployment Type is set to Mandatory by default. Toggle to enable Launch App After Installation and click Managed App Config. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-7.jpg]
  8. Toggle on Enable Managed App Config. For WI API Request, paste the Wireless Insights Enrollment Configuration copied from ZDNA Cloud in step I. Click Save. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-8.png]
  9. Click Add. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-9.png]
  10. The policy is created. Click Save and Assign. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-10.jpg]
  11. Search for the enrolled device and select it. Click Assign. [Image: image | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/soti-11.png]

The Wireless Insights Agent is installed to all devices in the group and the Managed Configuration is applied to enroll the device to the ZDNA Cloud.

Activate License via StageNow

Use Zebra's StageNow tool to create staging profiles for license deployment. A profile can either generate a barcode to scan with the StageNow client or export an XML file for mass deployment via an Enterprise Mobility Management (EMM) system.

Upon license procurement, a confirmation email is sent containing the "Badge ID" and "Product Name" parameters required for activation.

To create a StageNow profile:

  1. Open StageNow. Click Create new Profile from the left-hand menu. Select MX version 10.2 or higher to match the MX version on the device. Select Xpert Mode and click Create. [Image: no alt text | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/stagenow-1.jpg]

  2. Enter a profile name and click Start. [Image: no alt text | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/stagenow-2.jpg]

  3. Scroll down and click LicenseMgr. It appears on the right side of the window. Click Add. [Image: no alt text | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/stagenow-3.jpg]

  4. Under LicenseMgr, fill in the following and click Continue to activate the license using Badge ID:

    • License action type: Perform Zebra license action
    • Zebra license action: Activate License using Badge ID
    • Cloud Server Type: Production Cloud
    • Badge ID: [Enter the Badge ID received in Zebra's license confirmation email.]
    • Product Name: [Enter the Product Name received in Zebra's license confirmation email.] [Image: no alt text | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/stagenow-4.png]

  5. Click Complete Profile to finish creating the StageNow profile. [Image: no alt text | https://techdocs.zebra.com/wireless-insights/latest/guide/agent/stagenow-5.jpg]

Deployment options:

  • Barcode: Generate the barcode from the StageNow profile, launch the StageNow client on the target device, and scan the barcode(s).
  • XML: Export the XML from the StageNow profile. Do not modify the XML file to prevent unexpected behavior. Deploy the file to the devices via EMM (consult the EMM guide) or Zebra DNA Cloud.

Start Voice Analysis

Use the following intent to start voice analysis, replacing both instances of 5060 values with your desired port number:

    "am broadcast -a 'com.zebra.wirelessinsights.agent.ACTION_EXTERNAL_COMMANDS' --es 'message' '{ \"message_type\": \"command\", \"message\": { \"action\": \"start\", \"feature\": \"voice\", \"filter\": [\"warning\", \"error\"], \"configuration\": [ { \"key\": \"activityMode\", \"value\": \"PASSIVE_MODE\" }, { \"key\": \"sessionName\", \"value\": \"wi\" }, { \"key\": \"reportLevel\", \"value\": \"INFO\" }, { \"key\": \"voicePktFilterRule\", \"value\": \"TCP:5060,UDP:5060\" }, { \"key\": \"dynamicCodec\", \"value\": true }, { \"key\": \"port\", \"value\": 4556 } ] } }'"

Assign Group Name

Assigning a group name to devices helps organize them when displayed in the Wireless Insights dashboard within ZDNA Cloud. Use the intent below to assign a group name to the device, replacing Zebra_group with your desired group name. This intent should be sent after the Wireless Insights Agent is installed and configured.

    "am broadcast -a 'com.zebra.wirelessinsights.agent.ACTION_EXTERNAL_COMMANDS' --es 'message''{\"message_type\":\"command\",\"message\":{\"action\":\"set\",\"feature\":\"server_config\",\"configuration\":[{\"key\":\"groupName\",\"value\":\"Zebra_group\"}]}}'"
