About Color Camera SDK for Linux

Overview

This document provides installation and programming information that allow MP7 color camera enabled application development for Linux.

Supported Devices

For the compatible devices list, please visit following page.

https://www.zebra.com/us/en/support-downloads/software/developer-tools/bioptic-color-camera-sdk-for-linux.html

Supported Linux Distributions

Color Camera SDK for Linux supports the following Linux Distributions.

  • Ubuntu 18.04 (64bit)
  • CentOS 7 (64bit)

Version History

Version 1.0.0-39 - 01/2026

  1. Exposed "IsRedIlluminationPresent" API to detect the presence of red spots in the captured image frames.
  2. Exposed "GetFrame" API for the user to request adjacent frames of a given frame.
  3. Enhanced memory management.
  4. Bug fix - Resolved the issue of decode events not getting triggered for SP72 device.

Version 1.0.0-34 - 07/2024

  1. Added Multi PID detection capability.
  2. Added weight data and weight unit for the produce event.
  3. Bug fix - Resolved the issue on multiple images saving which persisted with the save button.

Version 1.0.0-22 - 04/2024

  1. Optimized Camera SDK by exposing only the required symbols to the end user.
  2. Implemented proper usage of SPD log within the Camera SDK.

Version 1.0.0-21 - 10/2020

  1. Bug fix - firmware update failed in camera after detaching while updating firmware.

Version 1.0.0-17 - 06/2020

  1. Initial release.
