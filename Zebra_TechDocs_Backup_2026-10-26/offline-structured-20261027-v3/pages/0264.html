RFID

Developer resources for building and integrating RFID solutions with Zebra Fixed and Handheld readers, including SDKs, APIs, and tools.


RFID SDK for Android

  • 2.0.5.292
  • 2.0.5.275
  • 4.0.0.9

Android SDK (.aar library) for building RFID applications on Zebra handheld readers, mobile computers, and fixed readers. Includes API reference, programming guides, tutorials, and sample projects.

RFID SDK for iOS

  • 1.0.0.000

The Zebra RFID SDK for iOS allows developers to create native applications that connect to and manage Zebra RFID readers via Bluetooth on iOS devices.

About Getting Started Tutorials

  • 1.0.0.000

Windows desktop developer guides for building RFID applications with Zebra handheld readers. Includes RFID SDK and CoreScanner COM API documentation.

  • 1.0.0.000

JavaPOS (UPOS-compliant) RFID scanner drivers for the FXP20 fixed reader, enabling integration with retail point-of-sale applications on Windows and Linux.
