Can the docs answer this?

We check a real question against the official docs and record what still needs an answer.

This is a fixed example, not live search or AI. We have not tested a device.

  1. Ask a real question.

    Can a web app start and stop scanning with an on-screen button?

    A developer wants to control scanning from a web app and would prefer to use Chrome.

  2. Find the relevant official guide.

    DataWedge 15.0 · Soft Scan Trigger ↗

    We checked this guide. It describes commands that start, stop or toggle scanning.

  3. Try to answer the question.

    The guide answers part of the question. It documents START_SCANNING and STOP_SCANNING, which require Barcode Input to be enabled in the active profile. The scanner must also be ready.

    These are Android commands. We have not verified how a button in Chrome would send them.

  4. Record why the answer is incomplete.

    We still need to verify how Chrome connects to the Android commands. The installed DataWedge version is unknown.

    Next, we need to confirm the installed version and the connection from Chrome, then test on the target device.

    This records an unresolved question, not a confirmed documentation gap.
